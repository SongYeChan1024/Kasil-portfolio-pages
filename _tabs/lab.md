프로젝트와 별개로 직접 만든 도구, 실험, 재사용 코드를 모읍니다.

## Kasil Game Foundation

여러 Unity 프로젝트에서 같이 쓰는 최소 기반 패키지입니다.

- `InputBlockRegistry`: 메뉴·연출 등 여러 시스템의 입력 차단 요청을 이유별로 관리합니다. 하나가 풀려도 다른 차단은 유지됩니다.
- `IInteractable`: 상호작용 대상과 결과를 같은 형식으로 주고받는 규약입니다.
- `SceneReference`: 인스펙터에서 씬 파일을 끌어다 지정합니다.

게임 고유의 입력·전투·UI는 넣지 않고, 패키지가 게임 코드를 참조하지 않게 유지합니다.

## 앞으로 채울 것

새로 만든 도구나 실험은 개발일지에 먼저 기록하고, 정리되면 여기에 추가합니다.
