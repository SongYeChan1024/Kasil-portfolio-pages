블로그 글을 작성하거나 기존 글과 이미지를 관리합니다. 저장소에 쓰기 권한이 있는 작성자만 사용할 수 있습니다.

**[블로그 관리 열기]({{ '/admin/' | relative_url }})**

처음에는 편집기 로그인 화면의 **처음 사용하는 경우: 토큰 만들기** 안내에 따라 이 블로그 저장소에만 `Contents: Read and write` 권한을 준 GitHub Fine-grained token을 만드세요. 토큰은 채팅이나 글 본문에 넣지 말고 로그인 입력창에서 사용하세요.

로그인 후 **블로그 글 → 새 글**에서 제목, 작성일, 카테고리, 태그와 본문을 입력할 수 있습니다. 캡처 이미지는 본문의 원하는 위치에서 **Ctrl+V**로 붙여 넣으세요. Rich Text·Markdown 모드 모두 지원하며, 한 장당 10MB까지 가능합니다. 글을 저장하면 이미지도 함께 업로드됩니다. 기존 이미지 업로드 메뉴도 사용할 수 있습니다.

저장·발행하면 GitHub에 커밋되고 사이트가 자동으로 배포됩니다. 저장 완료와 블로그 공개 사이에는 잠시 차이가 있을 수 있습니다. 글이 보이지 않으면 [배포 상태](https://github.com/SongYeChan1024/Kasil_DevLog/actions)를 확인해 주세요. 작성일이 미래이면 해당 시각 이후 사이트가 다시 빌드되어야 공개됩니다.

개인 PC에서는 로그인 화면의 **이 브라우저에 로그인 유지**를 선택하면 다음 접속 때 자동으로 로그인합니다. 토큰은 해당 브라우저에 보관되므로 공용 PC에서는 선택하지 마세요. **로그아웃**하면 저장한 토큰도 지워집니다. 토큰이 만료되거나 폐기되면 새 토큰을 입력해야 합니다.

로그인 유지를 선택하지 않으면 새로고침하거나 창을 닫은 뒤 다시 토큰을 입력해야 합니다. 작성 중인 글은 화면을 닫기 전에 저장해 주세요.
