3D Puzzle Adventure with AI NPC

mos.A.I.c

AI NPC와 대화하며 흩어진 기억을 복원해 나가는 에피소드형 3D 퍼즐 어드벤처

mos.A.I.c는 잃어버린 기억을 가진 주인공이 기억 공간을 탐색하며 퍼즐과 대화를 통해 삶의 조각을 복원해 나가는 팀 프로젝트입니다. 이야기, 퍼즐, 사운드, AI NPC 상호작용이 따로 놀지 않도록 한 흐름 안에 묶는 데 초점을 두고 설계되었습니다.

Overview

프로젝트 개요

플레이어는 기억을 잃은 주인공이 되어 기억 공간을 탐험하고, 각 에피소드에서 AI NPC와의 대화와 퍼즐 풀이를 통해 삶의 단편을 하나씩 되찾아갑니다. 퍼즐을 푸는 행위 자체보다 기억이 선명해지는 감정선과 관계의 복원이 함께 전개되도록 구조를 잡은 점이 이 프로젝트의 핵심입니다.

Narrative

에피소드 구성

  • EP.0 미지로의 발돋움: 기억 여행의 시작을 여는 도입부
  • EP.1 별을 헤는 소녀: 어린 시절의 기억을 별과 발판 퍼즐로 복원
  • EP.2 사라진 그림: 색과 시점을 활용해 잊힌 창작의 기억을 연결
  • EP.3 멈춰버린 노래: 소리와 리듬을 단서로 사랑의 기억을 되짚기
  • EP.4 뒤섞인 이야기: 앞선 조각들을 하나의 기억으로 다시 엮는 마무리

AI NPC

대화 시스템 구성

NPC 대화는 단순 텍스트 출력이 아니라 각 캐릭터의 프로필과 진행 상황을 바탕으로 반응하도록 구성했습니다. PromptBuilder, ChatNPCManager, ServerChat, GameDialogueDatabase 구조를 통해 JSON 기반 NPC 정보, 프롬프트 생성, 응답 요청, UI 출력 흐름이 연결되며 기억 복원이라는 주제를 상호작용 안으로 끌어왔습니다.

Puzzle Design

대표 퍼즐 구성

  • EP.1: 별을 수집하고 색을 기억해 올바른 발판을 선택하는 퍼즐
  • EP.1: 빙판길 위에서 축 고정과 정지 판정을 이용한 슬라이딩 퍼즐
  • EP.2: 색을 혼합해 같은 색 발판에 착지하는 색상 매칭 퍼즐
  • EP.2: 시점 방향을 맞춰 조각을 결합하는 공간 퍼즐
  • EP.3: 소리를 듣고 악보 조각을 찾는 수집형 퍼즐과 리듬 점프 맵
  • EP.4: 조각과 색을 맞추며 최종 기억 완성도를 계산하는 통합 퍼즐

System Design

사운드와 진행 관리

프로젝트 전반의 사운드는 SoundManager, SoundProfile, SoundController, SoundTrigger, UISoundTrigger로 나누어 중앙 집중식으로 관리했습니다. 저장과 불러오기는 JSON 데이터 구조를 기반으로 설계해 체크포인트, NPC 상태, 엔딩 조건과 태그 점수까지 이어지도록 구성했습니다.

Troubleshooting

대표 트러블슈팅

에피소드 2 로비 복귀 컷신에서 이미지 컷신과 텍스트 컷신이 겹치며 마우스 커서 잠금 UI가 중간에 풀리는 문제가 있었습니다. 원인은 이미지 컷신 종료 시점에 CutsceneMode가 해제되지만 텍스트 컷신은 아직 끝나지 않는 흐름 충돌이었습니다. 이를 해결하기 위해 해당 퍼즐 복귀 컷신에서는 이미지 컷신이 CutsceneMode를 해제하지 않도록 별도 bool 조건을 추가했고, 그 결과 컷신 흐름과 UI 상태가 안정적으로 유지되도록 정리했습니다.

Project Meaning

이 프로젝트에서 보여준 점

mos.A.I.c는 퍼즐 하나하나를 따로 나열한 게임이 아니라, 기억 복원이라는 주제를 시스템으로 번역해 보려는 시도가 강한 프로젝트였습니다. AI 대화, 에피소드 구조, 퍼즐, 사운드, 저장 데이터를 하나의 감정선 안에서 묶어내려 했다는 점이 이 작업의 가장 큰 특징입니다.
