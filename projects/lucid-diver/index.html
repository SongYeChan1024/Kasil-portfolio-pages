침몽도시:
루시드 다이버

서브컬처 캐릭터 애착 루프와 PvE 익스트랙션 루프를 결합한 Unity 팀 프로젝트

플레이어가 침몽도시에 진입해 전투와 파밍을 진행하고, 탈출 성공 후 회수한 보상이 캐릭터 기록 해금과 다음 출격 준비로 이어지는 P0/P0.5 버티컬 슬라이스입니다. 저는 PM으로 일정과 산출물을 관리하면서, 튜토리얼·VFX·아이템·에너미 흐름의 기획 및 구현을 함께 담당했습니다.

Core Loop

검증 목표

최종 P0의 핵심 질문은 “익스트랙션 플레이로 회수한 보상이 캐릭터 애착 보상과 다음 출격 준비로 이어지는가”입니다. 이를 위해 기억 파편, 동조율, 개인 심상 기록, 창고 저장, 소지품 장착이 하나의 플레이 사이클 안에서 연결되도록 범위를 고정했습니다.

Project Management

PM 업무

  • 마스터 일정, 주간 마일스톤, 일별 일정표 기준 정리
  • 작업 보드와 티켓 생성, 블로커 기록, 진행률 관리
  • P0/P0.5 범위 통제, 기능 동결 기준과 수정 가능 항목 문서화
  • QA 시트 운영, 버그 우선순위 분류, RC 빌드 체크리스트 작성
  • 발표 자료 취합, 시연 동선 체크리스트와 백업 자료 관리

Game Design

기획 산출물

  • P0 최종 정의서와 시스템 명세서 기준 정리
  • 로비, 출격 준비, 인게임, 결과창, 창고로 이어지는 화면 전이 흐름 정리
  • 기억 파편, 동조율, 개인 심상 기록 해금 루프 설계
  • 마나석, 회복약, 아티팩트, 아이템 박스 루팅 구조 정리
  • 튜토리얼 6단계 안내 흐름과 조건 기반 진행 방식 정리

Programming

구현 기록

  • JSON 기반 튜토리얼 안내 데이터와 로컬 Repository 구조 구성
  • TutorialManager 조건 진행, 이벤트 알림, 큐 기반 출력, 중복 출력 방지 구현
  • 데이터 기반 VFX ID, Catalog, Context, Service, Runtime Pool 구조 구축
  • 플레이어, 에너미, 아이템, 상자, 아티팩트, 탈출 이벤트 VFX 연결
  • 상자 루팅과 아이템 설명 흐름을 ItemBoxOpened 이벤트 기준으로 분리

UX Flow

전투, 파밍, 정산으로 이어지는 플레이 흐름

인게임에서는 이동, 조준, 공격, 적 조우, 아이템 박스 루팅, 탈출이 하나의 흐름으로 이어집니다. 결과창에서는 획득한 기억 파편과 소모품이 각각 서사 보상과 다음 출격 준비로 분리 정산되도록 구성했습니다.

  • Extraction Loop
  • Character Attachment
  • Inventory UX
  • Result Flow

Troubleshooting

대표 개선

  • 튜토리얼 완료 저장과 로비 이동 책임을 분리해 결과창 흐름과 충돌하지 않도록 정리
  • 베타 병합 후 최신 튜토리얼 구조가 이전 카탈로그 구조로 되돌아갈 수 있는 디그레이션 감지
  • VFX 풀 반환 오류를 확인하고 Runtime Pool 기준으로 재사용 흐름 안정화
  • TutorialScene 전용 NavMesh를 구성해 LevelDesignScene과의 참조 충돌 가능성 축소

Documentation

문서화 기준

  • 최상위 SSOT 문서를 기준으로 구현 범위와 제외 범위를 고정
  • 시스템 명세, 구현 명세, QA 체크리스트, 일정표를 분리 관리
  • 개인 개발일지에 목표, 완료 작업, 결정 사항, 블로커를 일자별로 기록
  • 코드 변경 기록과 비교 문서를 남겨 병합 전후 변경 원인을 추적
