01 · Final Result

기획에서 최종 시연까지

초기 P0 검증에 머물지 않고 전투·파밍·탈출, 결과 정산, 튜토리얼, 적 AI까지 연결한 최종 빌드를 완성했습니다. 전체 시연 영상과 대표 구현인 꿈식자 AI 영상을 통해 실제 플레이 결과를 먼저 확인할 수 있습니다.

최종 시연 영상

꿈식자 AI 완성 결과

랜덤 순찰, 감지, 조사, 추격, 2단 돌진 공격, 재탐색과 복귀가 이어지는 동작을 보여줍니다.

02 · Contribution

세 역할, 하나의 결과

PM은 일정과 협업을 운영한 별도 트랙이며, 꿈식자 AI는 기획자·개발자로서 수행한 작업입니다. 역할을 섞어 표현하지 않고, 각 위치에서 어떤 결과를 만들었는지 구분했습니다.

01

PM

팀이 같은 우선순위와 일정을 바라보도록 업무 지도를 운영했습니다.

  • 전체 일정·주간 마일스톤·일별 일정 연결
  • 우선순위와 이월 항목, 블로커 관리
  • 일일·주간 개발 기록을 통한 업무 공유
  • 시연 범위와 발표 자료 취합
02

기획자

익스트랙션 장르 안에서 적이 플레이어를 실제로 사냥하는 존재가 되도록 설계했습니다.

  • 꿈과 기억을 먹는 포식자 ‘꿈식자’ 컨셉
  • 기본 적 2~3마리의 무리 배회와 길목 압박
  • 세계관 → 행동 → 플레이 경험 연결
  • 프로젝트 초기 컨셉·캐릭터·원화 가이드 초안
03

개발자

컨셉을 실제 플레이에서 읽히는 상태와 피드백으로 구현했습니다.

  • 꿈식자 FSM과 감지·조사·추격·공격 로직
  • 튜토리얼 런타임과 단계 진행
  • 체스트·픽업·인벤토리 연동
  • 총구 화염·HDR·인벤토리 슬롯 강조

PM이기 때문에 AI를 만든 것이 아니라, PM 업무를 병행하면서 별도의 기획자·개발자 역할로 꿈식자를 설계하고 구현했습니다.

03 · Representative Work

꿈을 먹는 포식자를
행동하는 AI로

꿈식자를 단순한 이동 장애물이 아니라 악몽 속을 돌아다니며 플레이어의 꿈을 먹는 포식자로 정의했습니다. 그래서 기본 적이더라도 2~3마리가 서로 다른 경로로 배회하고, 감각 정보를 바탕으로 조사와 추격을 이어가며, 놓친 뒤에도 재탐색과 개별 복귀를 수행하도록 설계했습니다.

Worldview → Behavior → Experience

플레이어를 방해하는 적이 아니라, 플레이어를 사냥하는 존재

테스트용 더미 에너미를 기초로 삼아 실제 제작용 FSM을 설계하고 구현했습니다. 스폰 포인트와 패트롤 루트를 기반으로 움직이되 NavMesh 위 임의 지점을 선택해 매번 다른 순찰선을 만들고, 시야나 소리로 플레이어의 흔적을 얻으면 조사·추격·공격으로 상태를 전환합니다.

  • 루트의 범위를 지키면서도 반복적으로 보이지 않는 랜덤 순찰
  • 플레이어가 아닌 소음 앵커를 따라가는 조사
  • 이동 방향을 예측해 길목을 압박하는 추격
  • 전조 후 두 번 연속 돌진하는 공격과 피격 패널티
  • 타깃 상실 시 재탐색 후 가장 가까운 개별 루트로 복귀

01 · SPAWN

스폰 포인트에서 개별 순찰 시작

스폰 포인트에 연결된 패트롤 루트를 각 개체의 기준 경로로 저장하고, 2~3마리가 서로 다른 순찰을 시작합니다.

스폰 직후 같은 좌표로 뭉치지 않도록 개체별 시작 위치와 루트 기억을 분리합니다.

07 · Troubleshooting

보이는 현상보다
행동의 원인을 수정

AI가 멈추거나 여러 개체가 겹치는 문제를 단순 속도 조정으로 덮지 않고, 좌표 보정·접근점 분산·복귀 기준을 분리해 상태 전환 자체가 안정적으로 이어지도록 수정했습니다.

Case 01

조사 좌표 Stuck

문제 소음 좌표가 이동 불가능한 지점이면 조사 상태가 종료되지 않았습니다.

해결 좌표를 NavMesh 위로 보정하고 조사 제한 시간을 추가해 다음 상태로 전환되게 했습니다.

Case 02

군집 겹침

문제 여러 개체가 같은 목표 좌표에 몰려 실루엣과 길목 압박이 무너졌습니다.

해결 개체별 접근 위치를 분산해 무리의 존재감은 유지하고 겹침은 줄였습니다.

Case 03

상실 이후 복귀

문제 타깃을 잃은 개체가 공통 지점으로 몰리거나 즉시 순찰로 돌아가 부자연스러웠습니다.

해결 재탐색을 거친 뒤 가장 가까운 개별 루트 지점으로 복귀하도록 기억 기준을 분리했습니다.
