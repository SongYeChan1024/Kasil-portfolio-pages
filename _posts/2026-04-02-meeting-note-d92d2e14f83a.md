<b>취업 및 프로젝트 진행 상담</b> 2026-04-02

## 요약

### 실행 항목

- [ ] 송카실: Notion 포트폴리오 업데이트 후 링크 공유 
- [ ] 송카실: "게임 잡는 사람" 등에서 채용 공고 유심히 확인 
- [ ] 송카실: Notion에 프로젝트 중 막힌 문제와 해결 방법 추가 
- [ ] 송카실: Notion에 향후 게임에 추가할 기능 아이디어 작성 
- [ ] 코치: 프로젝트 종료 후 Unity MCP 연결 및 Claude Code 사용법 교육 

### 취업 전략 및 타임라인

- 취업 목표 시기는 올해 또는 내년까지 - 이번 대학생까지가 채용 끝물이라는 전망 
- 내년 상반기까지는 신입 채용이 있을 것으로 예상되나, 이후에는 채용이 크게 줄어들 전망 
- 빠른 취업 준비가 필요한 상황 

### 개발자 역할의 변화

- 요즘 트렌드: "개발자"에서 "기발자"(기획자+개발자)로 역할 확대 
- AI가 코딩을 상당 부분 해주기 때문에 기획 능력이 더욱 중요해짐 
- 1인 개발이 대세가 될 것으로 전망 - 아트, 기획, 프로그래밍, 마케팅까지 혼자 진행   
- 창작(시나리오, 컨셉 디자인) 영역에 집중하면 오래 살아남을 수 있음 

### AI 도구 활용

- Claude와 MCP(Model Context Protocol) 연결을 통해 Notion, GitHub, Unity 등을 관리 가능   
- Claude를 통해 Notion 페이지 생성, GitHub 작업(push, fetch 등), 홈페이지 제작까지 가능   
- NCP(네이버 클라우드 플랫폼)로 Notion 내용 전달 가능 

### 면접 시 AI 활용에 대한 답변 전략

- "AI가 다 해줬다"는 식의 답변은 금물 
- 올바른 답변 방식:
  - 기획: "내가 기획했고, Claude에게 조언을 얻어 개선했다" 
  - 코딩: "기본 구조는 내가 짰고, 질문과 답변을 통해 완성했다" 
- 글쓰기 비유: 본인이 먼저 작성하고 AI에게 첨삭을 받는 것이 정답 

### Notion 포트폴리오 중요성

- Notion을 수준 이상으로 만들어야 연락이 옴 
- 회사에서 Notion을 매우 중요하게 봄 
- 현재 포트폴리오는 문서가 예쁘게 잘 되어 있음 
- 추가 필요 사항:
  - 프로젝트 중 발생한 문제와 해결 과정 
  - 향후 추가할 기능 아이디어 

### 기타 필수 역량

- 코딩 능력: AI가 코드를 생성하지만, 할루시네이션과 오류를 검수할 능력 필요 
- 사무 능력: Excel, PPT 등 - 회사 업무는 AI가 범용적으로만 처리하므로 회사에 맞게 조정하는 능력 필요  
- 업무 흐름 파악 능력이 중요 

### 프로젝트 계획

- 현재 2차 프로젝트 진행 중 - 프로젝트를 거듭할수록 기획과 프로그래밍 실력 향상 
- 수동 개발 vs AI 개발 비교: 같은 프로젝트를 수동과 AI로 각각 만들어보는 것 권장 
- 프로젝트 종료 후 Unity MCP 연결하여 Claude Code로 개발해보는 실습 예정 

### 산업 동향

- 신입 채용 감소: 1-2년 전까지는 신입을 많이 뽑았으나 요즘은 감소 추세 
- 시니어 개발자들도 AI 도구를 잘 다루지 못하면 어려움 겪는 상황  
- 채용 공고를 보고 회사마다 원하는 요건을 파악하는 것이 중요
