## 한눈에 보기

이 문서는 <b>AI NPC 대사(힌트/격려/개입 타이밍)를 “성격 키워드”로부터 일관되게 생성</b>하기 위한 규칙표다.

핵심은 <b>키워드 → 파라미터(1\~5) → 상황(실패/정체) 보정 → 최종 대사 스타일</b> 순서로 만든다는 것.

---

## 1) 핵심 개념: 성격을 숫자로 만든다(파라미터화)

같은 힌트라도 NPC 성격에 따라

- 언제 말하는지(자주/드물게)
- 얼마나 직설적인지(추상/명령형)
- 실패했을 때 어떤 톤인지(격려/무덤덤)

가 달라진다.

그래서 키워드를 바로 “문장”으로 바꾸지 말고, 먼저 아래 파라미터를 계산한다.

## 2) 공통 운용 규칙(팀 합의용)

### 기본값(디폴트)

모든 NPC는 시작할 때 아래 기본값에서 출발한다.

| 파라미터 | 기본값 |
| --- | --- |
| Hint Frequency | 3 |
| Hint Directness | 3 |
| Initiative | 3 |
| Comfort | 3 |
| Emotional Expression | 3 |

### 보정(클램프)

키워드 영향치를 다 더한 뒤 아래처럼 자른다.

- 최소 1
- 최대 5

---

## 3) 키워드 → 파라미터 영향치 매핑 방식(원리)

키워드 1개가 파라미터에 +/− 영향을 준다.

### 예시 키워드 5종(설명용)

- 수줍은
  - Hint Frequency -1
  - Initiative -2
  - Hint Directness -1
  - 말투: “아마…”, “저기…” 같이 조심스럽게
- 장난기 있는
  - Hint Frequency +1
  - Initiative +1
  - 말투: 가볍게 분위기 완화, 툭 던지는 힌트
- 분석적인
  - Hint Directness +2
  - Memory Style = 구조형
  - 말투: 규칙/순서/구조를 정확하게 설명
- 감정으로 떠올리는
  - Hint Directness -1
  - Initiative +1
  - Memory Style = 감정형
  - 말투: “이쪽이 더 자연스러워” 같은 느낌 중심
- 본질을 짚는
  - Hint Frequency -1
  - Hint Directness +1
  - 말투: 군더더기 없이 핵심 요약

## 4) 실제 적용(추천 파이프라인)

### 추천 순서(운영용)

1. 성격 키워드 선택
2. 파라미터 계산(기본값 3에서 시작)
3. 현재 상황(정체/실패)에 따라 힌트 강도 보정
4. 최종 파라미터에 맞춰 대사 생성

### 조합 예시(팀 설명용)

- 소녀 성격 조합: 수줍은 + 기다려주는 + 장면으로 떠올리는
  - 힌트 빈도 2 / 직설도 2 / 선제개입 2 / Memory Style 장면형
  - 톤: 부드럽고 조심스럽게, “분위기/장면”으로 힌트
- 화가 성격 조합: 무뚝뚝한 + 묵묵히 챙기는 + 분석적인
  - 힌트 빈도 2 / 직설도 4 / 선제개입 2 / Memory Style 구조형
  - 톤: 말수는 적지만 말하면 정확
- 음악가 성격 조합: 애틋한 + 마음을 숨기는 + 흐름을 중시하는
  - 힌트 빈도 2 / 직설도 2 / 선제개입 1 / Memory Style 흐름형
  - 톤: 조용하지만 감정이 실린 힌트

## 5) 직설도 예시(같은 정답, 다른 말)

상황: “오른쪽 발판부터 밟아야 다음 길이 열린다”

- 매우 추상: “저쪽이 더 자연스럽게 이어질 것 같아.”
- 약간 추상: “오른쪽 흐름을 먼저 따라가 보면 길이 열릴지도 몰라.”
- 중간: “왼쪽보다 오른쪽부터 보는 게 맞아 보여.”
- 직설: “오른쪽 발판을 먼저 밟아야 다음 발판이 나와.”
- 매우 직설: “오른쪽부터 시작하고, 그다음 중앙으로 이동해.”

## 6) 힌트 빈도/개입 타이밍 예시(언제 말할지)

플레이어가 <b>15초 이상 같은 구역에서 정체</b>하거나 <b>실패 횟수가 누적</b>되면 NPC별로 개입 기준을 다르게 할 수 있다.

- Initiative 높은 캐릭터: 먼저 말을 꺼냄
- Initiative 낮은 캐릭터: 더 오래 기다림
- Hint Frequency 낮은 캐릭터: 실패 횟수 임계값이 높음

운영에서 조절 가능한 것들:

- 자동 힌트 발동 시간(정체 시간)
- 실패 횟수 임계값
- 같은 힌트 반복 간격

## 8) 최종 성격 계산 방식(정리)

각 NPC는 다음처럼 뽑는다.

- 감정 표현 키워드 1개
- 관계 반응 키워드 1개
- 퍼즐 태도 키워드 1개

그리고 기본값 3에서 시작해서 표의 수치를 더해 최종 파라미터를 만든다.

---

## 9) 운영 주의점(게임 편의성 우선)

성격 때문에 힌트 품질이 너무 떨어지면 안 된다.

추천 원칙:

- 초반에는 성격 반영을 많이 한다
- 실패 횟수/정체 시간이 누적되면 <b>Hint Directness는 반드시 상승</b>
- 아무리 수줍고 감성적이어도, 누적 실패가 커지면 최소한 기능 힌트는 제공한다

즉 성격은 분위기를 바꾸되, <b>게임 진행 편의성을 해치지 않게</b> 설계한다.
