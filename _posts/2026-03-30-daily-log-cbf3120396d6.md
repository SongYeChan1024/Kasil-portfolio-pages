## 오늘 한 일(요약)

- 플레이어 스폰/씬 전환 스폰 구조 정리
- 리듬 퍼즐(발판) 스폰 로직 개선 및 유령 콜라이더 이슈 대응
- 악보 조각 수집 로직/연출 분리(수집 시 이펙트 복제본 생성)
- PuzzleComplete 비활성화 코루틴 에러 원인 파악 및 구조 수정

## 구현한 것

- PlayerSpawn 정리
  - 인스펙터 기반 spawnPoint/playerPrefab 사용
  - SceneManager.sceneLoaded 구독으로 씬 전환 시 자동 검사/스폰
- PlatformSpawner 스폰 로직 개선
  - 비트 기반 위치 결정, beatSpacing / minPlatformDistance 적용
  - 충돌 검사 개선 및 겹침 시 풀로 안전 반환(유령 콜라이더 문제 대응)
- PieceSpawner / PieceCollect 개선
  - 생성 시 X축 회전(기본 90도), 스폰 포인트 자식으로 배치
  - 충돌/입력 기반 수집 처리로 수정
  - 수집 시 CollectFlyEffect 프리팹 인스턴스화
  - collectEnableDelay로 수집 직후 오탐 방지
- CollectFlyEffect
  - 연출용 독립 프리팹으로 분리
  - 스케일 증가(useScaleUp) 우선 적용하도록 단순화
- Ep3\_1Manager / PuzzleComplete
  - 모든 조각 수집 시 onAllPiecesCollected 이벤트 호출
  - 연출(악보 활성화·스포트라이트·완성 오디오)과 씬 전환 제어 분리
  - 비활성 루트 코루틴 문제 방지를 위해 SetVisualActive로 시각 요소만 토글

## 배운 것(개념/정리)

- 테스트 플레이용 플레이어 구조를 입력/이동/카메라/상호작용/디버그로 분리하는 방향이 유지보수에 유리함
- Audio Listener는 한 씬에 1개만 유지해야 안정적임(컷신 카메라 추가 시에도 구조 분리 필요)
- 스크립트가 붙은 오브젝트(로직 실행 주체)와 켜고 끄는 비주얼 오브젝트(연출 대상)는 분리해야 함
- 수집 연출 스크립트(CollectFlyEffect)는 원본 프리팹에 상시 부착하면 안 되고, 수집 순간 생성되는 복제본에만 적용해야 함

## 이슈/버그

- 내용: <code>Coroutine couldn't be started because the game object 'Sheet_Puzzle' is inactive!</code>
- 원인/가설: 비활성화된 오브젝트에서 StartCoroutine 호출
- 해결/시도:
  - PuzzleComplete를 항상 활성 상태인 오브젝트 쪽으로 이동
  - 스크립트/비주얼 대상 분리, 시각 요소만 토글(SetVisualActive)
- 다음 액션:
  - PuzzleComplete가 붙은 오브젝트가 비활성화되지 않도록 씬 구조 재점검
