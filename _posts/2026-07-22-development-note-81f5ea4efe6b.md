## 2. 문제 현상

인게임 세션 플레이 중 인벤토리에서 아이템을 드롭하여 인게임 신에 버렸을 때, 드롭한 아이템의 위치에 출력하는 스프라이트 이미지가 비대하게 출력되었다.

## 3. 원인 분석

아이템을 드롭했을 때 Game 화면에 출력되는 이미지 크기를 확인하였을 때, 500 × 500 크기의 스프라이트를 사용하는 ‘회복약’, ‘기묘한 사탕’ 및 512 × 512 크기의 스프라이트를 사용하는 ‘굳어버린 구급 봉투’에서 해당 현상이 발생하는 것으로 확인됨.

100 × 100 크기의 스프라이트를 사용하는 ‘기억 조각’ 아이템을 드롭했을 때에는 아이템 아이콘이 비대하게 출력되지 않는 것을 확인함.

## 4. 확인한 내용

| 확인 항목 | 결과 |
| --- | --- |
| DropItem 컴포넌트 확인 | Visual 오브젝트에서 Sprite Renderer 확인 - 스프라이트 출력 크기를 조절하는 기능 없음 |
| DropItem 스크립트 확인 | 아이콘 출력 렌더러를 지정하는 itemIconRenderer 변수에는 AddressableLoader로부터 아이템 iconAddress를 받아 출력하는 기능만 존재했음 |
| 최종 원인 | DropItem에서 드롭하는 아이템의 스프라이트를 RefreshIconAsync() 사이즈 보정 없이 전달함 |

## 5. 수정 방향

AddressableLoader에서 받아온 아이템 아이콘 스프라이트의 bounds.size 크기를 읽어온다. (pixels per unit이 적용된 값으로 출력됨)

<p>
bounds.size의 x, y 각 길이에 역수를 취한 값을 내부 변수 <code>배율</code> 값으로 지정하고, itemIconRenderer.transform.localScale에 해당 배율 값을 곱하여 스프라이트가 인게임 세션에서 출력되는 크기를 일정하게 보정한다. 
</p>
