<b>제페토(ZEPETO) 월드 개발 기초 - Build it + Unity</b> 2026-06-01


## 요약


### 오늘 수업 핵심 요약

- <b>제페토(ZEPETO) 월드 개발 환경 구축</b> 방법을 배웠다. Unity 2022.3.9f 버전과 제페토 Build-it 툴을 설치하고, 제페토 계정과 Unity를 연동하여 실시간으로 캐릭터를 테스트하는 전체 워크플로우를 학습했다. 
- <b>Build-it 오브제 활용과 순수 Unity 개발 방식의 차이점</b>을 이해했다. Build-it은 코딩 없이 미리 제작된 오브제로 빠르게 제작할 수 있지만 카툰 스타일로 제한되며, 순수 Unity로 개발하면 실사 그래픽을 사용할 수 있지만 TypeScript 코딩이 필요하다. 
- <b>메타버스 포트폴리오 제작 전략</b>을 배웠다. 학원 포트폴리오처럼 보이지 않으려면 양으로 승부하고 근성을 보여주며, 트렌드에 맞는 중심재미 요소를 구현해야 한다. 전 세계 5억 명이 사용하는 플랫폼이므로 실무 경험으로 가치가 있다. 
- 원시트 게임 기획서 작성 실습을 진행했으며, 제페토 인기 맵을 분석하고 자신만의 메타버스 컨텐츠를 기획하는 과제를 받았다. 

---

### 주요 개념 정리

- <b>ZEPETO (제페토)</b>
  - 설명: 전 세계 약 5억 명이 사용하는 메타버스 플랫폼 (2022년 기준 4억, 현재 추정 5억) 
  - 사용되는 상황: 메타버스 월드 제작, 아바타 커스터마이징, 소셜 활동
  - 중요한 점: YG, 하이브(BTS) 등 엔터테인먼트 기업들이 공식 월드를 운영할 정도로 파급력이 있음 
- <b>Build-it (빌드잇)</b>
  - 설명: 제페토에서 제공하는 Unity 전용 오브제 패키지 및 템플릿 시스템
  - 예시: 포탈, 점프 발판, 자동차 컨트롤, 상호작용 부스 등 미리 만들어진 오브제 제공 
  - 장점: 코딩 없이 심시티처럼 배치만으로 월드 제작 가능 
  - 단점: 카툰 스타일로 제한되며 전체적인 그래픽 컨셉이 정해져 있음 
- <b>TypeScript (타입스크립트)</b>
  - 설명: 제페토 전용 프로그래밍 언어로, 순수 Unity 개발 시 필요 
  - 학습 기간: 하루 2시간씩 3\~5일 정도면 기본 습득 가능 (바닐라 코딩 수준) 
  - 사용되는 상황: Build-it 없이 FBX 파일과 Unity만으로 제페토 월드를 만들 때, 캐릭터 움직임, 상호작용, 워프 등 기능 구현에 필요 
  - 헷갈릴 수 있는 점: AI를 활용하면 라이브 코딩으로도 충분히 작업 가능

### 수업 흐름별 정리

### 1. 제페토 개발 환경 구축

- 설명: Unity와 제페토 계정을 연동하여 실시간 테스트 환경을 구성하는 과정 
- 필요한 것:
  1. Unity 2022.3.9f (리티 맵 전용 버전) 
  2. Build-it Unity 전용 오브제 설치 
  3. 제페토 스튜디오에서 월드 도메인 설정 
  4. Unity에서 계정 연동 (캐릭터 출현 확인) 
- 중요한 이유: 계정 연동이 되어야 내 캐릭터가 Unity 플레이 모드에서 나타나며, 이것이 제대로 작동해야 개발 진행 가능 

### 2. 제페토 스튜디오 월드 세팅

- 설명: 제페토 스튜디오 웹사이트에서 월드를 생성하고 도메인을 설정하는 과정 
- 단계:
  - 제페토 스튜디오 로그인 → 만들기 → 월드 생성 
  - 월드 이름과 월드 아이디(도메인) 신중하게 결정 
  - 월드 아이디, 계정 정보를 메모장에 정리 보관 
- 중요한 이유: Unity와 연동할 때 이 정보가 필요하며, 나중에 변경하기 어려움 

### 3. Unity 계정 연동 및 테스트

- 설명: Unity 에디터에서 제페토 계정 정보를 입력하여 연동하고, 플레이 모드에서 캐릭터가 나타나는지 확인 
- 문제 해결:
  - 캐릭터가 나타나지 않을 경우: 여러 번 시도, 리프레쉬, 오브제 재설치, Unity 재시작 등 필요 
  - 10명이 같은 방법으로 해도 안 되는 사람이 있을 수 있음 - 끈기있게 재시도 필요 
- 성공 기준: Unity 플레이 모드에서 내 제페토 캐릭터가 빌드잇 맵 안에서 움직임 

### 4. Build-it 오브제 활용

- 설명: 제페토에서 제공하는 미리 만들어진 오브제를 배치하여 월드 제작 
- 오브제 종류:
  - 포탈 (A↔B 이동) 
  - 점프 발판 
  - 자동차 선택/조작 부스 
  - 멘트(UI) 버튼 
- 활용 예시: 오징어 게임, 달리기 게임 등 
- 중요한 이유: 코딩 없이 게임 메커니즘 구현 가능

### 5. FBX 파일 활용 및 Unity 순수 개발

- 설명: 무료 FBX 사이트에서 3D 모델을 다운받아 Unity에 임포트하고 배치 
- 단계:
  1. FBX 파일 다운로드 (무료 사이트: `Free3D.com` 등) 
  2. Unity Content 폴더에 임포트
  3. 씬에 배치 및 크기 조정 (QWER 키 사용) 
  4. 머티리얼 적용 
  5. 콜라이더 설정 (안 하면 캐릭터가 뚫고 지나감) 
- 중요한 이유: 실사 그래픽을 사용하고 싶을 때 필수적이며, 포트폴리오 차별화 가능 

### 6. 제페토 파일 변환 및 업로드

- 설명: Unity에서 만든 아이템을 제페토 전용 형식으로 변환하여 월드에 업로드 
- 단계: 퍼블리싱 마크 버튼 클릭 → .zepeto 파일 생성 → 월드에 업로드 
- 중요한 이유: Unity에서 제작한 커스텀 오브젝트를 제페토 월드에서 사용하기 위한 필수 과정

### 실습 / 작업 순서

<b>제페토 개발 환경 세팅 체크리스트:</b>

1. Unity 2022.3.9f (리티 맵 전용 버전) 설치 완료 
2. Build-it Unity 전용 오브제 설치 완료 
3. 제페토 스튜디오에서 월드 생성 및 도메인 설정 
4. Unity에서 제페토 계정 연동 및 캐릭터 출현 확인 
5. 플레이 모드에서 캐릭터가 정상 작동하는지 테스트 

<b>Build-it 플러스 Unity 월드 제작 순서:</b>

1. 제페토 공식 문서 및 튜토리얼 영상 참고 
2. Build-it 오브제 배치 (포탈, 점프대, 상호작용 요소 등) 
3. Unity 플레이 모드에서 테스트
4. 빌드 및 제페토에 업로드
5. 멀티플레이 테스트 (최대 24명 동시접속) 

<b>순수 Unity + FBX 월드 제작 순서:</b>

1. 무료 FBX 사이트에서 3D 모델 다운로드
2. Unity에 FBX 임포트 및 배치
3. 머티리얼 및 콜라이더 설정
4. TypeScript로 기능 구현 (이동, 상호작용 등) 
5. 제페토 파일로 변환 (.zepeto) 
6. 제페토 월드에 업로드 및 테스트

### 예시와 활용 사례

- <b>예시 1: 대구 두루공원 갤러리 메타버스</b> 
  - 상황: 대구 메타버스 공모전 프로젝트
  - 설명: 제페토로 두루공원을 메타버스화하여 은상 수상
  - 왜 이 예시를 사용했는지: 실제 공모전 수상 사례로 포트폴리오 가치를 입증 
- <b>예시 2: YG 뮤직비디오샵, BTS 하이브 월드</b> 
  - 상황: 엔터테인먼트 기업의 공식 제페토 월드
  - 설명: 연예인 캐릭터 관람, 뮤직비디오 시청, 음반 구매 링크 연동
  - 왜 이 예시를 사용했는지: 기업들이 제페토를 마케팅 채널로 활용하는 이유를 설명 (파급력) 
- <b>예시 3: 오징어 게임, 달리기 게임</b> 
  - 상황: Build-it 오브제를 활용한 게임 제작
  - 설명: 점프 발판, 포탈 등을 조합하여 미니게임 구현
  - 왜 이 예시를 사용했는지: 코딩 없이 게임 메커니즘을 만들 수 있음을 보여줌
- <b>예시 4: 부가티 자동차 월드</b> 
  - 상황: 학생 작업 예시
  - 설명: FBX로 부가티 모델을 가져오고 Build-it 자동차 템플릿으로 작동
  - 왜 이 예시를 사용했는지: Build-it과 FBX를 혼합하여 사용하는 방법 시연

### 헷갈릴 수 있는 부분

- <b>헷갈리는 개념: Build-it 사용 vs 순수 Unity 개발</b>
  <ul>
  <li>
  헷갈리는 이유: 두 방식 모두 Unity를 사용하지만 작업 방식과 결과물이 완전히 다름
  </li>
  <li>
  구분 방법: 

  - Build-it = 코딩 불필요 + 카툰 스타일 + 빠른 제작
  - 순수 Unity = TypeScript 필수 + 실사 가능 + 자유도 높음
  </li>
  </ul>
- <b>헷갈리는 개념: Unity 버전</b>
  - 헷갈리는 이유: 제페토 맵과 아이템 제작 시 Unity 버전이 서로 다름 
  - 구분 방법: 제페토 월드는 Unity 2022.3.9f 필수, 다른 프로젝트와 혼용 불가
- <b>헷갈리는 개념: 계정 연동 성공 여부</b>
  - 헷갈리는 이유: 계정 입력만으로는 연동 확인 불가, 캐릭터가 나타나야 성공 
  - 구분 방법: Unity 플레이 모드에서 내 제페토 캐릭터가 맵에 등장하면 연동 성공
