## 오늘 할 일(우선순위)

1. 체크포인트 선택 → 해당 위치 스폰까지 연결
   - 스테이지 선택 후 체크포인트를 고르면, 해당 Transform/좌표로 플레이어가 정확히 스폰되는지 확인
   - 전환 직후 플레이어 상태/카메라/입력 잠금 해제 타이밍까지 한 번에 점검
2. Ep.3-2 리듬 발판 퍼즐 최소 플레이 루프 완성
   - 발판 생성 → 정답 발판 점등(Preview/Judge 분리) → 판정(Wrong/Miss/Success)까지 연결
   - 중복 판정 방지 플래그(hasJudgedCurrentBeat/wasJudgedThisBeat) 정상 동작 확인
   - 점수/콤보/실패 카운트 최소 버전으로라도 붙이기
3. 퍼즐별 플레이어 기능/애니메이션 요구사항 정리해서 공유
   - 예: 레버 조작, 조사/줍기, 버튼, 퍼즐 오브젝트 상호작용 등
   - “필수/있으면 좋은 것/나중”으로 우선순위 표기
4. 공간 퍼즐 맵 연출 보강(짧게라도 체감 개선)
   - 성공/실패 피드백(사운드/파티클/조명) 1차 적용
   - 플레이어가 다음 목표를 유추할 수 있게 시선 유도 요소 추가
5. 엔딩 씬 전환/게임 흐름 1차 연결
   - 스테이지 선택 기능과 연결해서 엔딩 씬 진입 → 타이틀/게임 종료 흐름의 뼈대 구현
   - UI는 임시라도 동작 확인용으로 배치
