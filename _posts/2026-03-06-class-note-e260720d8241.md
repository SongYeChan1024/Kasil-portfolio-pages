## 2026-03-06 유니티 애니메이션 실습 강의 정리본

### 1) 전체 주제/목표

Mixamo(또는 다른 무료 사이트)에서 캐릭터와 애니메이션을 가져와서, 플레이어의 이동(WASD) / 공격(마우스 클릭) / 스킬(스페이스) 애니메이션까지 연결한 뒤 프로젝트를 완성해 제출한다.

### 2) 과제 요구사항(제출 기준)

- 캐릭터 + 애니메이션 에셋 다운로드 및 Unity 임포트
- WASD로 전후좌우 이동 구현
- 스페이스바로 스킬 구현
- 마우스 클릭으로 공격 구현(공격 애니메이션 2개 활용)
- 완성본 제출
- 작업 루틴: 50분 작업 + 10분 휴식(가이드)

### 3) 수업 절차(요약 + 받아쓰기 핵심 합본)

### A. 프로젝트 생성

- Unity 2022, 3D Built-in Render Pipeline
- 프로젝트명 예시: Unity Animation EX (Exercise의 약자)

### B. Mixamo에서 에셋 다운로드(핵심 포인트)

1. 캐릭터

- 예시: 칼 든 여전사 “Maria”
- T-pose로 다운로드(리깅/아바타 세팅에 유리)
- FBX for Unity로 다운로드

1. 애니메이션(필수 구성)

- Idle(Combat 카테고리의 칼 든 대기 자세)
- Forward Walk / Backward Walk / Right Walk / Left Walk
- 공격 애니메이션 2개(예: Standing Melee Attack Combo, Sword Out Slash 등)

1. 가장 중요한 옵션: In Place

- 걷기(이동) 애니메이션은 반드시 “In Place” 체크
- 애니메이션이 캐릭터를 실제로 이동시키면 안 됨
- 실제 이동은 스크립트(또는 물리)로 제어해야 함

### C. Unity 임포트 및 씬 구성

- 다운로드한 FBX 파일들을 Assets 폴더에 임포트
- 폴더 정리(예: Maria Character 폴더 생성, Animation 폴더 생성)
- 씬에 바닥(Plane) 생성 → Scale X/Z = 10
- Material 만들어서 색 지정(예: 노란색) 후 Ground에 적용

### D. 캐릭터/리깅(Avatar) 세팅

1. 텍스처/머티리얼 문제 해결(깨져 보일 때)

- Inspector에서 Materials 설정:
  - Location → Use External Materials (Legacy)
  - Fix Now 또는 현재 버전으로 변환(셰이더 버전 불일치 가능)

1. Rig 설정

- Maria 모델 선택 → Rig 탭
- Animation Type: Generic → Humanoid
- Avatar Definition: Create From This Model
- 본 구조 확인(예: Right Hand Index 1 쪽에 칼이 위치)

1. Optimize Game Object(본 노출/최적화)

- 필요 시 본 구조 확인을 위해 체크 해제
- 필요한 본만 남기고 최적화(예: Maria Sword, Right Hand Index 1 등)
- Hierarchy에 본 구조가 “전부 보이게 두면 안 됨”(최적화 필요)

### E. Animator Controller 구성

- Animator Controller 생성(예: Maria\_Controller)
- 캐릭터의 Animator 컴포넌트에 Controller 연결
- Idle(예: Wait Sword Idle)을 기본 상태(Entry)로 연결
- Idle/Walk 등 반복 동작은 Loop Time 체크
  - Loop Time을 켜지 않으면 애니메이션이 중간에 끊겨 보임
- 플레이 모드에서 발목 꼬임/부자연스러움 등 문제 없는지 검증

### 4) 붙여둔 스크립트 정리(역할 중심)

### 4-1. MariaInput (입력 수집 + 이벤트 발행)


<details markdown="1">
<summary>MariaInput 스크립트 토글</summary>


```cs
using System;
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem; // 새로운 입력 시스템을 사용하기 위해 추가
// 플레이어의 입력을 처리하는 클래스를 만들어 보자
// 필요한 것: 이동, 공격, 스킬 등에 필요한 변수
//1. 이동방향벡터 2. 카메라 시점 벡터 3.공격버튼 입력 여부 4. 스킬버튼 입력 여부 등등
public class MariaInput : MonoBehaviour
{
    public Vector3 moveDir = Vector3.zero; // 이동 방향 벡터
    public Vector2 lookDir = Vector2.zero; // 카메라 시점 벡터, 플레이어가 바라보는 방향을 나타내는 벡터
    public bool isAttack = false; // 공격 버튼 입력 여부
    public bool isSkill = false; // 스킬 버튼 입력 여부

    public event Action AttackEvent; // 공격 입력이 발생했을 때 호출되는 이벤트
    public event Action SkillEvent; // 스킬 입력이 발생했을 때 호출되는 이벤트

    public void OnMove(InputAction.CallbackContext context)
    {
        if (context.canceled)
        {
            moveDir = Vector3.zero;
            return;
        }

        Vector2 dir = context.ReadValue<Vector2>(); // 입력된 이동 방향 벡터를 읽어옴

        // 아주 작은 값은 0으로 처리
        if (dir.magnitude < 0.1f)
            dir = Vector2.zero;

        moveDir = new Vector3(dir.x, 0f, dir.y); // 2D 입력 벡터를 3D 이동 방향 벡터로 변환
    }
    public void OnLook(InputAction.CallbackContext context)
    {
        lookDir = context.ReadValue<Vector2>(); // 입력된 카메라 시점 벡터를 읽어옴

    }
    public void OnAttack(InputAction.CallbackContext context)
    {
        if (isSkill) return; // 스킬이 활성화된 상태에서는 공격 입력을 무시하도록 조건 추가
        if (context.performed) // 공격 버튼이 눌렸을 때만 로그를 출력하도록 조건 추가
        {            
            //isAttack = true; // 공격 버튼이 눌렸음을 나타내는 변수 설정
            Debug.Log("공격 버튼이 눌렸습니다!"); // 디버그 로그로 공격 입력 상태 출력
            AttackEvent?.Invoke(); // 공격 이벤트가 구독되어 있다면 호출하여 공격 입력이 발생했음을 알림
        }
        else if (context.canceled) // 공격 버튼이 떼어졌을 때 공격 상태를 false로 설정
        {
            //isAttack = false; // 공격 버튼이 떼어졌음을 나타내는 변수 설정               
        }
        
    }
    public void OnSkill(InputAction.CallbackContext context)
    {
        if (context.performed) // 스킬 버튼이 눌렸을 때만 로그를 출력하도록 조건 추가
        {
            //isSkill = true; // 스킬 버튼이 눌렸음을 나타내는 변수 설정
            Debug.Log("스킬 버튼이 눌렸습니다!"); // 디버그 로그로 스킬 입력 상태 출력
            SkillEvent?.Invoke(); // 스킬 이벤트가 구독되어 있다면 호출하여 스킬 입력이 발생했음을 알림
        }
        else if (context.canceled) // 스킬 버튼이 떼어졌을 때 스킬 상태를 false로 설정
        {
            //isSkill = false; // 스킬 버튼이 떼어졌음을 나타내는 변수 설정
        }
        
    }
}

```

</details>


- 이동 입력을 Vector3 moveDir로 변환
- 시점/회전 입력을 Vector2 lookDir로 저장
- 공격/스킬 입력 시 event(Action)로 외부에 알림
  - AttackEvent, SkillEvent
- 공격 입력: 스킬 중이면 공격 무시, performed일 때 이벤트 호출
- 스킬 입력: performed일 때 이벤트 호출

### 4-2. MariaCTRL (이동/회전 + 이동 애니메이션 파라미터)


<details markdown="1">
<summary>MariaCTRL 스크립트 토글</summary>


```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem; // 새로운 입력 시스템을 사용하기 위해 추가
// 마리아 캐릭터의 움직임과 애니메이션을 제어하는 클래스
// 필요한 것
//1. 애니메이터 2.리지드바디 3.트랜스폼 4.이동속도 5. 회전속도 6. 입력 클래스 등등
public class MariaCTRL : MonoBehaviour
{
    private Animator anim; // 1. 애니메이터
    private Rigidbody rb; // 2. 리지드바디
    private Transform tr; // 3. 트랜스폼
    public float moveSpeed = 5f; // 4. 이동속도
    public float rotSpeed = 60f; // 5. 회전속도
    private MariaInput input; // 6. 입력 클래스
    void Awake()
    {
        input = GetComponent<MariaInput>(); // MariaInput 컴포넌트를 가져와서 input 변수에 할당
        anim = GetComponent<Animator>(); // Animator 컴포넌트를 가져와서 anim 변수에 할당
        rb = GetComponent<Rigidbody>(); // Rigidbody 컴포넌트를 가져와서 rb 변수에 할당
        tr = GetComponent<Transform>(); // Transform 컴포넌트를 가져와서 tr 변수에 할당
    }
    private void Update()
    {
        Rotate(); // 매 프레임마다 회전 처리
    }
    private void FixedUpdate()
    {
        Move();
    }

    private void Move()
    {
        
            anim.SetFloat("MoveX", input.moveDir.x, 0.1f, Time.deltaTime);
            // 이동 방향 벡터가 0이 아니면 isRun 파라미터를 true로 설정하여 달리는 애니메이션 재생
            anim.SetFloat("MoveY", input.moveDir.z, 0.1f, Time.deltaTime);
        if (input.moveDir != Vector3.zero) // 이동 방향 벡터가 0이 아닌 경우에만 이동과 회전을 처리하도록 조건 추가
        {
            Vector3 moveVector = (tr.forward * input.moveDir.z + tr.right * input.moveDir.x).normalized;
            // 이동 방향 벡터 계산
            rb.MovePosition(rb.position + moveVector * moveSpeed * Time.fixedDeltaTime); // 이동 처리
        }
    }

    private void Rotate()
    {
        float mouseX = input.lookDir.x; // 카메라 시점 벡터의 x값을 MouseX 변수에 할당
        
        tr.Rotate(Vector3.up * mouseX * rotSpeed * Time.deltaTime); // y축을 기준으로 회전 처리
    }
}

```

</details>


- Animator 파라미터:
  - MoveX = input.moveDir.x
  - MoveY = input.moveDir.z
- Rigidbody 기반 이동:
  - 입력이 0이 아닐 때 moveVector 계산 후 MovePosition
- Transform 회전:
  - lookDir.x(마우스 X)로 y축 회전

### 4-3. MariaAttack (공격/스킬 트리거 + 쿨타임)


<details markdown="1">
<summary>MariaAttack 스크립트 토글</summary>


```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem;
// 마리아 캐릭터의 공격과 스킬을 구현하는 클래스
//필요한것 1. 애니메이터 2. 공격 쿨타임 3.스킬 쿨타임
public class MariaAttack : MonoBehaviour
{
    private MariaInput Input; // 플레이어 입력을 처리하는 컴포넌트
    private Animator anim; // 1. 애니메이터
    public float atkCooldown = 1f; // 2. 공격 쿨타임
    public float skillCooldown = 3f; // 3. 스킬 쿨타임
    private float atkTimer = 0f; // 공격 쿨타임 타이머
    private float skillTimer = 0f; // 스킬 쿨타임 타이머
    private bool isAttack = false; // 공격 중인지 여부를 나타내는 변수
    private bool isSkill = false; // 스킬 사용 중인지 여부를 나타내는 변수
    private readonly int hashAttack = Animator.StringToHash("Attack"); // 공격 애니메이션 트리거의 해시값
    private readonly int hashSkill = Animator.StringToHash("Skill"); // 스킬 애니메이션 트리거의 해시값
    private WaitForSeconds attackWs; // 공격 애니메이션이 끝날 때까지 대기하는 WaitForSeconds 객체
    private WaitForSeconds skillWs; // 스킬 애니메이션이 끝날 때까지 대기하는 WaitForSeconds 객체
    void Awake()
    {
        Input = GetComponent<MariaInput>(); // PlayerInput 컴포넌트를 가져와서 Input 변수에 할당
        anim = GetComponent<Animator>(); // Animator 컴포넌트를 가져와서 anim 변수에 할당
        attackWs = new WaitForSeconds(0.5f); // 공격 애니메이션이 끝날 때까지 대기하는 WaitForSeconds 객체를 0.5초로 초기화
        skillWs = new WaitForSeconds(1f); // 스킬 애니메이션이 끝날 때까지 대기하는 WaitForSeconds 객체를 1초로 초기화
    }

    private void OnEnable()
    {
        Input.AttackEvent += Attack; // AttackEvent에 Attack 함수를 구독하여 공격 입력이 들어올 때 Attack 함수가 호출되도록 설정
        Input.SkillEvent += Skill; // SkillEvent에 Skill 함수를 구독하여 스킬 입력이 들어올 때 Skill 함수가 호출되도록 설정
    }
    private void OnDisable()
    {
        Input.AttackEvent -= Attack; // AttackEvent에서 Attack 함수를 구독 해제하여 공격 입력이 들어올 때 Attack 함수가 호출되지 않도록 설정
        Input.SkillEvent -= Skill; // SkillEvent에서 Skill 함수를 구독 해제하여 스킬 입력이 들어올 때 Skill 함수가 호출되지 않도록 설정
    }
    private void Update()
    {
        if (atkTimer > 0) // 공격 쿨타임 타이머가 0보다 큰 경우
        {
            atkTimer -= Time.deltaTime; // 공격 쿨타임 타이머를 감소시킴                       
        }
        if (skillTimer > 0) // 스킬 쿨타임 타이머가 0보다 큰 경우
        {
            skillTimer -= Time.deltaTime; // 스킬 쿨타임 타이머를 감소시킴                      
        }
    }
    void Attack()
    {
        if (atkTimer > 0 || isAttack) return; // 공격 쿨타임이 남아있거나 이미 공격 중인 경우 함수를 종료
        if (isSkill) return; // 스킬 쿨타임이 남아있거나 이미 스킬 사용 중인 경우 함수를 종료
        isAttack = true; // 공격이 시작되었음을 나타내는 변수 설정
        atkTimer = atkCooldown; // 공격 쿨타임 타이머를 공격 쿨타임으로 초기화
        anim.SetTrigger(hashAttack); // 공격 애니메이션 트리거를 설정하여 공격 애니메이션 재생
        StartCoroutine(AttackCoroutine()); // 공격 애니메이션이 끝날 때까지 대기하는 코루틴 시작
    }
    IEnumerator AttackCoroutine()
    {
        yield return attackWs; // 공격 애니메이션이 끝날 때까지 대기
        isAttack = false; // 공격이 끝났음을 나타내는 변수 설정
    }
    void Skill()
    {
        if (skillTimer > 0 || isSkill) return; // 스킬 쿨타임이 남아있거나 이미 스킬 사용 중인 경우 함수를 종료
        if (isAttack) return; // 공격 쿨타임이 남아있거나 이미 공격 중인 경우 함수를 종료
        isSkill = true; // 스킬 사용이 시작되었음을 나타내는 변수 설정
        skillTimer = skillCooldown; // 스킬 쿨타임 타이머를 스킬 쿨타임으로 초기화
        anim.SetTrigger(hashSkill); // 스킬 애니메이션 트리거를 설정하여 스킬 애니메이션 재생
        StartCoroutine(SkillCoroutine()); // 스킬 애니메이션이 끝날 때까지 대기하는 코루틴 시작                            
    }
    IEnumerator SkillCoroutine()
    {
        yield return skillWs; // 스킬 애니메이션이 끝날 때까지 대기
        isSkill = false; // 스킬 사용이 끝났음을 나타내는 변수 설정
    }

}
```

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem; // 새로운 입력 시스템을 사용하기 위해 추가
// 마리아 캐릭터의 움직임과 애니메이션을 제어하는 클래스
// 필요한 것
//1. 애니메이터 2.리지드바디 3.트랜스폼 4.이동속도 5. 회전속도 6. 입력 클래스 등등
public class MariaCTRL : MonoBehaviour
{
    private Animator anim; // 1. 애니메이터
    private Rigidbody rb; // 2. 리지드바디
    private Transform tr; // 3. 트랜스폼
    public float moveSpeed = 5f; // 4. 이동속도
    public float rotSpeed = 60f; // 5. 회전속도
    private MariaInput input; // 6. 입력 클래스
    void Awake()
    {
        input = GetComponent<MariaInput>(); // MariaInput 컴포넌트를 가져와서 input 변수에 할당
        anim = GetComponent<Animator>(); // Animator 컴포넌트를 가져와서 anim 변수에 할당
        rb = GetComponent<Rigidbody>(); // Rigidbody 컴포넌트를 가져와서 rb 변수에 할당
        tr = GetComponent<Transform>(); // Transform 컴포넌트를 가져와서 tr 변수에 할당
    }
    private void Update()
    {
        Rotate(); // 매 프레임마다 회전 처리
    }
    private void FixedUpdate()
    {
        Move();
    }

    private void Move()
    {
        
            anim.SetFloat("MoveX", input.moveDir.x, 0.1f, Time.deltaTime);
            // 이동 방향 벡터가 0이 아니면 isRun 파라미터를 true로 설정하여 달리는 애니메이션 재생
            anim.SetFloat("MoveY", input.moveDir.z, 0.1f, Time.deltaTime);
        if (input.moveDir != Vector3.zero) // 이동 방향 벡터가 0이 아닌 경우에만 이동과 회전을 처리하도록 조건 추가
        {
            Vector3 moveVector = (tr.forward * input.moveDir.z + tr.right * input.moveDir.x).normalized;
            // 이동 방향 벡터 계산
            rb.MovePosition(rb.position + moveVector * moveSpeed * Time.fixedDeltaTime); // 이동 처리
        }
    }
```
