# 에피소드별 사운드 연출 핵심 정리

## 전체 방향

- <b>EP.0</b>: 거의 무음, 존재가 흐릿한 소리
- <b>EP.1</b>: 추억은 돌아오지만 소리는 아직 멂
- <b>EP.2</b>: 작업실의 질감은 조금 들리지만 여전히 먹먹함
- <b>EP.3</b>: 소리를 되찾으며 선명하게 열림

즉,

앞 에피소드들은 일부러 <b>“잘 안 들리게”</b> 만들고,

EP.3에서 \*\*“이제 들린다”\*\*를 느끼게 해야 해.

# 유니티에서 쓸 핵심 요소 4개

## 1. Low Pass

- 고음을 깎아서 <b>먹먹한 느낌</b>을 만듦
- 물속 같거나, 먼 기억 같거나, 막혀 있는 느낌에 좋음

## 2. Reverb

- <b>멀리서 울리는 공간감</b>을 만듦
- 빈 공간, 홀, 꿈속, 기억 속 잔향 표현에 좋음

## 3. 3D Audio

- 소리가 <b>멀리서 들리는 느낌</b>을 만듦
- 특정 오브젝트나 목소리에 거리감을 줄 때 사용

## 4. Audio Mixer Snapshot

- 에피소드별로 다른 사운드 상태를 저장해두고
- 장면 전환 때 자연스럽게 바꾸기 좋음

- <b>Reverb 길게</b>

### 효과음

- 별 조각은 살짝 더 또렷하게

### 추천 톤

- EP.0보다 조금 선명
- 하지만 여전히 먹먹함 유지

### 느낌

“소리는 존재하지만 안개 너머에 있는 상태”

## EP.2

### 목표

색과 작업 감각은 돌아오지만 소리는 아직 완전하지 않다

- 작업실 나무 바닥
- 종이, 천, 굳은 물감 주변의 건조한 질감

- Reverb는 약하게

“창문이 조금 닦였지만 아직 선명하지 않음”

- Low Pass 거의 해제
- Reverb는 공간감용으로만 사용
- 중요한 소리는 선명하게

“닫혀 있던 귀가 열리는 순간”

# 2. 유니티에서 사용할 핵심 기능

## Audio Low Pass Filter

- 고음을 깎음
- 먹먹하고 답답한 느낌
- 물속, 벽 너머, 기억 저편 같은 느낌 만들기 좋음

## Audio Reverb Filter

- 멀리서 울리는 공간감 추가
- 빈 홀, 먼 공간, 꿈속 잔향 느낌 만들기 좋음

## 3D Audio

- 소리가 실제 공간 어딘가에서 들리는 느낌
- 멀리서 들리는 목소리, 웃음, 피아노 등에 적합

## Audio Mixer + Snapshot

- 에피소드별 사운드 상태를 저장
- 장면 전환 시 자연스럽게 분위기 전환 가능
