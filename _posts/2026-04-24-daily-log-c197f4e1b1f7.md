# 일일회고록

## 1) 오늘 한 일

- <b>EP.3-2 탑다운 리듬 퍼즐 프리팹 연결 문제 해결</b>
  - 노트가 발판 프리팹이 아니라 기본 큐브처럼 보이던 원인을 확인했다.
    - <code>noteVisualPrefab</code> 참조가 비어 있어 기본 형태로 생성되고 있었음
  - 3-2 씬에서 프리팹/스케일을 아래처럼 연결·조정했다.
    - <code>noteVisualPrefab</code> → <code>Platform_Small_B.prefab</code>
    - <code>lanePadPrefab</code> → <code>Platform_Big_B.prefab</code>
    - <code>noteScale</code> → (1, 1, 1)
    - <code>lanePadScale</code> → (1.15, 1, 1.15)
- <b>프리팹 인스턴스화 오류(InvalidCastException) 수정</b>
  - 탑다운 퍼즐 코드가 프리팹을 <code>GameObject</code>로만 엄격하게 처리하면서 캐스팅 예외가 발생했다.
  - <code>Ep3_2TopDownRhythmPuzzle.cs</code>에서 프리팹을 <code>UnityEngine.Object</code> 기준으로 받아 처리하도록 수정해,
    <p>
    프리팹이 <code>GameObject</code>든 <code>Component</code>든 안전하게 인스턴스화되도록 정리했다.
    </p>
- <b>3-2 씬에서 잘못 실행되던 컷씬(로비/3-1 인트로) 문제 정리</b>
  - 3-2 씬에서 실행되면 안 되는 컷씬 컨트롤러가 <code>playOnStart</code>로 자동 실행되며,
    <p>
    <code>GameManager.Instance</code>가 null인 상태에서 <code>CutsceneMode(true)</code>가 호출되어 <code>NullReferenceException</code>이 발생했다.
    </p>
  - 대응 작업
    - <code>Ep3LobbyIntroCutsceneController</code>에 <code>GameManager</code> null 방어 코드 추가
    - 3-2 씬에서 잘못 자동 실행되던 컷씬 컨트롤러 <code>playOnStart</code> 비활성화
    - 컷씬 시작/종료 시 <code>GameManager</code>가 없으면 오류 대신 경고 로그만 출력하도록 변경
- <b>EP.3 컷씬 저장 키(bool) 충돌 해결(컷씬별 상태 분리)</b>
  - 여러 컷씬이 동일 저장 키를 공유해, 하나를 보면 다른 컷씬도 이미 본 것으로 처리되는 문제가 있었다.
  - 컷씬별로 bool 값을 분리해 서로 영향이 없도록 정리했다.
    - <code>Played_EP3_LobbyIntro</code>
    - <code>Played_EP3_Stage3_1Intro</code>
    - <code>Played_EP3_Stage3_1Completion</code>
    - <code>Played_EP3_Stage3_2Intro</code>
    - <code>Played_EP3_ReturnedLobbyIntro</code>
- <b>컷씬 반복 테스트 편의 기능 추가(인스펙터 오버라이드)</b>
  - 세이브 데이터 삭제 없이도 컷씬을 반복 재생해 확인할 수 있도록 인스펙터용 오버라이드 옵션을 추가했다.
    - <code>useInspectorPlayedStateOverride</code>
    - <code>inspectorPlayedState</code>
- <b>컷씬 자막이 안 보이던 문제 해결(캔버스/우선순위/레이아웃)</b>
  - 시네머신은 정상 작동했지만 자막 텍스트가 보이지 않는 문제를 확인했다.
  - 해결 방향
    - EP3 컷씬 전용 자막 오버레이 추가 및 우선순위 정리
    - <code>forceStandaloneSubtitleOverlay</code> 추가
    - <code>Canvas_Cutscene</code>을 <code>Canvas_NPC_Chat</code>보다 우선 사용하도록 수정
    - sorting order를 높여 화면에 확실히 보이도록 조정
  - 자막이 세로로(한 글자씩) 줄바꿈되던 현상은 TMP 폭/레이아웃 문제로 판단해 레이아웃 코드를 수정했다.
- <b>리듬 퍼즐 노트 속도(리드타임) 조정</b>
  - 노트가 너무 빠르게 느껴져 <code>previewLeadTime</code>을 조정했다.
    - 1.3 → 2.1
  - 표시 타이밍을 앞당겨 플레이어 반응 시간을 확보했다.
- <b>EP.3-2 리뉴얼 작업 복구(브랜치/커밋 기반 복구)</b>
  - 작업 도중 3-2 리뉴얼이 되돌아간 것처럼 보이는 상황을 확인했다.
  - <code>origin/Ep_3Renewal</code> 브랜치의 특정 커밋에 남아 있던 중간본을 기준으로 관련 파일을 복구했다.
    - <code>Ep3_2TopDownRhythmPuzzle.cs</code>
    - <code>Ep3_2RhythmLaneNote.cs</code>
    - <code>Ep3_2Manager.cs</code>
    - <code>RhythmAudioManager.cs</code>
    - <code>BeatMapData.cs</code>
    - <code>Ep3_2_Scene.unity</code>
  - 복구 후 탑다운 리듬 퍼즐 구조와 <code>useTopDownRhythmPuzzle</code>, 프리팹 연결 상태를 다시 살렸다.

---

## 2) 느낀 점

- 오늘은 단순 오류 수정이 아니라, <b>씬 구조 / 저장 데이터 / 컷씬 실행 조건 / UI 출력 경로</b>가 얼마나 강하게 연결되어 있는지 체감한 날이었다.
- “컷씬이 안 나온다” 같은 문제도 실제로는
  - 저장 키 충돌,
  - <code>playOnStart</code> 설정 잔존,
  - <code>GameManager</code> null 접근,
  - 캔버스 우선순위/소팅,
  - 레이아웃 폭

  <p>
  같이 여러 레이어의 문제로 나타날 수 있다는 걸 다시 확인했다.
  </p>
- 이번에 컷씬 bool을 분리하고, 인스펙터 오버라이드로 반복 테스트가 가능해진 건 앞으로 연출 작업 속도를 크게 올려줄 것 같다.
- 퍼즐 쪽도 프리팹 참조 하나가 빠지면 “큐브로 보인다”처럼 완전히 다른 증상으로 보일 수 있어서, 참조/타입 처리의 안정성이 중요하다는 걸 배웠다.

---

## 3) 아쉬운 점

- 오류 해결과 복구에 시간이 많이 들어가서, 3-2 퍼즐의 <b>플레이 감/연출 완성도(노트 속도, 레인 색상, 자막 위치 등)</b>까지 충분히 다듬진 못했다.
- 리뉴얼 작업이 되돌아간 것처럼 보이는 상황이 있었던 만큼,
  - 큰 구조 수정 전후 커밋 지점과
  - 씬 파일 변경 기록

  <p>
  을 더 명확히 남기는 습관이 필요하다고 느꼈다.
  </p>
