<b>데일리 로그 기본 템플릿</b>

(오늘 작성한 일일 회고록 내용을 템플릿에 맞춰 정리)

<b>기본 정보</b>

- 날짜: 2026년 4월 1일 → 2026년 4월 1일
- 프로젝트: MosAIc / Episode 3
- 작성자: @송카실

<b>오늘 한 일(요약)</b>

- 에피소드 3-2 리듬 퍼즐 파트 로직/연출 전반 점검 및 마감 정리
- 낙하 복구 시스템을 “최근 안전 위치 복귀 + 복구 횟수 소진 시 시작 지점 리셋” 흐름으로 정비
- 퍼즐 완료 후 이동을 “자동 다음 씬 전환” → “도착 지점 문 상호작용으로 이동”으로 수정
- 최종 로비맵 상호작용(악보 상호작용 시 랜덤 음악 재생) 기반 기능 구현

<b>구현한 것</b>

- 리듬 퍼즐 생성/진행 흐름을 BPM·재생 시간 기반으로 다시 점검하고, 판정 흐름(정답/미스/오답/콤보 점수)을 플레이 감각에 맞게 조정
- 정답 표시 이펙트/성공 이펙트(링, 노트 이펙트 등) 연출이 플레이 중 자연스럽게 이어지도록 수정
- 낙하 복구 시스템
  - 낙하 시 즉시 리셋이 아닌, 최근 안전 위치로 복귀
  - 복구 횟수 소진 후 재낙하 시 시작 지점으로 돌아가 퍼즐 재시작
  - <code>MissCollider</code>와 플레이어 복귀 로직 연결로 실수 처리 흐름 개선
- 퍼즐 완료 후 진행 동선 개선: 퍼즐 클리어 후 문 상호작용으로 다음 씬 이동하도록 전환
- 로비맵 상호작용 요소 기반 작업: 피아노 위 악보 상호작용 시(컷신 전 단계) 두 곡 중 하나 랜덤 재생 기능 구현

<b>배운 것(개념/정리)</b>

- “기능 추가”보다 “플레이 흐름(입력-판정-피드백-회복-다음 진행)”이 자연스럽게 이어지도록 마감 단계에서 구조/연출을 함께 다듬는 것이 완성도에 크게 영향을 줌
- 실패(낙하) 처리도 게임 경험의 일부라서, 즉시 리셋보다 “복구(관용) → 최종 리셋(명확한 규칙)” 같은 단계적 설계가 체감 난이도와 몰입에 도움

<b>이슈/버그</b>

- 내용: 리듬 퍼즐에서 실수(미스) 처리/복귀 흐름이 기존에는 즉시 리셋이라 체감이 가혹하고 플레이 흐름이 끊김
- 원인/가설: 낙하/미스 이벤트와 플레이어 복귀 로직이 단순 리셋 중심으로 설계되어, 완충 장치(세이프 포인트/복구 횟수)가 없음
- 해결/시도:
  - 최근 안전 위치 복귀 방식 도입
  - 복구 횟수 소진 후 재낙하 시 시작 지점으로 돌아가 퍼즐 재시작하도록 흐름 설계
  - <code>MissCollider</code>와 복귀 로직을 연결해 실수 처리 과정을 자연스럽게 정리
- 다음 액션:
  - 복구 횟수/세이프 포인트 기준이 체감 난이도에 적절한지 플레이 테스트로 추가 조정
  - 리듬 퍼즐 판정/이펙트 타이밍(시각 피드백)이 템포와 완전히 정렬되는지 최종 확인

<b>내일 할 일</b>

- 에피소드 3 전체 패키지 통합 전, EP3-2 리듬 퍼즐 플레이 테스트로 밸런스/연출 디테일 최종 점검
- 퍼즐 완료 후 문 상호작용 이동 흐름의 UX(상호작용 안내/연출) 보강 여부 검토
- 로비맵 악보 상호작용 기능을 향후 컷신 연결 구조로 확장 가능하게 정리(트리거/상태 관리 설계)
