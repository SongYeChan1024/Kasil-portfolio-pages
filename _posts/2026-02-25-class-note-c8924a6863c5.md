### UGUI 3대 필수 요소

- <b>Canvas (캔버스)</b>: 모든 UI 요소가 그려지는 도화지로, 모든 UI는 반드시 Canvas의 자식이어야 화면에 표시됨 
- <b>EventSystem (이벤트 시스템)</b>: 클릭, 드래그, 터치 등의 입력을 감지하고 UI 요소에 전달하는 역할, 씬에 하나만 존재해야 함  
- <b>RectTransform (렉트 트랜스폼)</b>: 일반 GameObject의 Transform을 UI용으로 확장한 것으로, 위치와 크기뿐만 아니라 Anchors와 Pivot 개념이 추가됨    

### Canvas 렌더 모드

- <b>Screen Space - Overlay</b>: 카메라 없이 화면 최상단에 바로 표시되는 방식으로, 가장 가볍고 많이 사용되며 HUD에 적합함 (모니터에 메모지를 붙이는 방식) 
- <b>Screen Space - Camera</b>: 특정 카메라를 통해 렌더링하며, UI에 깊이감을 표현할 수 있고 월드와 연동이 필요할 때 사용 (UI가 많을 경우 UI 전용 카메라를 별도로 배치) 
- <b>World Space</b>: UI가 3D 공간에 배치되는 방식으로, 몬스터 머리 위 HP 바 등에 사용 

### Canvas Scaler 설정

- <b>Scale with Screen Size</b>를 선택하고 Reference Resolution을 1920x1080 (Full HD)으로 설정하는 것이 권장됨    
- 요즘 대부분의 핸드폰이 Full HD를 지원하기 때문 
- Constant Pixel Size는 픽셀 단위로 고정하는 방식 
- Constant Physical Size는 물리적 크기에 따라 UI 요소를 조정하지만 거의 사용하지 않음 

### Image vs Raw Image

- <b>Image</b>: UI 스프라이트에 최적화되어 있으며 일반적인 UI 제작에 주로 사용  
- <b>Raw Image</b>:  
  - Texture를 직접 출력하는 컴포넌트
  - 큰 배경 이미지나 메인 화면에서 한 번만 사용하는 대형 이미지에 사용 
  - RenderTexture 출력 가능 (미니맵, CCTV 화면 등) 
  - Sprite Atlas에 포함되지 않음
  - 배경이 무한 반복으로 이동할 때는 텍스처의 Wrap Mode를 Repeat으로 설정해야 깨지지 않음    
  - UV Rect의 X, Y 값으로 이미지 위치 조정 가능 
  - Set Native Size로 원래 이미지 크기로 복원 가능  

### 최적화 기법

- <b>Canvas Split (캔버스 나누기)</b>:     
  - UI 요소 중 하나만 바뀌어도 해당 Canvas 전체를 Rebuild하여 다시 그림
  - 자주 바뀌는 UI (체력바, 타이머)와 고정된 UI (배경, 메뉴)를 별도의 Canvas로 분리해야 함
  - 캔버스도 드로우콜이 많이 발생하므로 분리가 중요
- <b>Raycast Target 끄기</b>:  
  - 클릭할 필요가 없는 단순 이미지나 텍스트는 Raycast Target 옵션을 꺼서 불필요한 연산을 줄여야 함
  - 광선을 쏴서 감지하는 방식이므로 반응할 필요 없는 요소는 체크 해제  
  - 실습에서 Blood Screen과 HP Bar 이미지에 적용함    
- <b>Sprite Atlas</b>: 여러 이미지를 하나의 큰 이미지로 합쳐서 드로우콜을 획기적으로 줄임  
- <b>Mask 최적화</b>: RectMask2D가 일반 Mask보다 가벼우며, 과도한 마스크 중첩은 피해야 함

### Anchors와 Pivots (반응형 UI)

- <b>Anchors (앵커)</b>: UI 요소가 부모(주로 Canvas)의 어느 지점을 기준으로 고정될지 결정  
  - 앵커를 네 귀퉁이로 벌리면 부모 크기에 따라 UI가 같이 늘어남
  - Shift + Alt로 앵커 설정 가능
  - 부모 크기를 변경하면 자식도 같이 늘어남
- <b>Pivot (피벗)</b>: UI 요소 자체의 중심점으로, 회전이나 크기 조절의 기준 (보통 0.5, 0.5로 설정) 
- 다양한 화면 비율(16:9, 21:9 등)에 대응하기 위해 이 개념을 완벽히 이해해야 함 

### TextMeshPro

- Unity의 기본 Text 컴포넌트보다 고급 기능을 제공 
- 더 선명한 텍스트 렌더링, 그라디언트, 외곽선 등의 효과 제공 
- 프로토타입에서는 레거시 Text를 사용하고, 출시를 앞두고 TextMeshPro로 변경하는 것이 일반적인 추세 
- 한글 폰트 사용 시 신중해야 하며, 특정 폰트는 깨질 수 있음 

### EventSystem 구조

- <b>Standalone Input Module</b>: 마우스, 키보드, 터치 입력을 자동으로 처리  
- <b>Graphic Raycaster</b>: 2D UI 요소를 감지  
- <b>Physics Raycaster</b>: 월드 공간(World Space)의 UI 요소와 3D 오브젝트 상호작용을 감지 
- New Input System 사용 시 Input Module 교체 필요 (추후 진행 예정)  

### 마스크(Mask) 기능

- UI 요소를 특정 영역 밖으로 넘어가지 않도록 가리는 기능  
- 스크롤 가능한 콘텐츠를 만들 때 사용 (예: 방 목록에서 스크롤바로 내려야 보이는 영역)  
- RectMask2D가 일반 Mask보다 가벼움

### Occlusion (오클루전)

- <b>카메라의 Occlusion</b>: 카메라에 보이는 부분만 렌더링하고 카메라 뒤나 안 보이는 부분은 렌더링하지 않아 자원을 절약    
- <b>UI의 Clipping</b>: 마스크와 클리핑을 사용해 화면에 보이지 않는 UI 요소를 렌더링하지 않도록 설정  
- FPS 게임에서 총기가 화면에 너무 가깝게 나타날 때 Clipping으로 조정했던 사례 언급 

### 실습: Blood Screen 구현

Blood Screen은 플레이어가 피격당했을 때 화면이 빨갛게 번쩍이는 효과 (Left 4 Dead의 체력 저하 시 화면 효과와 유사) 

<b>구현 과정:</b>

- Canvas 메인 UI에 Image 추가하고 이름을 Image\_BloodScreen으로 설정  
- Blood Screen 스프라이트 적용  
- Shift + Alt + Stretch로 화면 전체에 맞춤 
- 색상을 빨간색(RGB: 255, 0, 0)으로 설정하고 Alpha 값을 0으로 설정 (평상시 투명)     
- TPS\_Damage 스크립트에 코드 추가:  
  - <code>using UnityEngine.UI;</code> 추가   
  - <code>public Image bloodScreen;</code> 변수 선언  
  - <code>IEnumerator ShowBloodScreen()</code> 코루틴 생성  
  - Alpha 값을 0.2\~0.5 사이 랜덤 값으로 설정  
  - 0.125초 대기 후 Alpha 값을 0으로 되돌림   
  - 피격 시 <code>StartCoroutine(ShowBloodScreen())</code> 호출  
- Inspector에서 Blood Screen 이미지 연결   
- Raycast Target 체크 해제 권장 (추후 설명 예정)   

### 실습: HP Bar 구현

<b>구현 과정:</b>

- Canvas 메인 UI에 Panel 추가  
- Panel의 Anchor를 Top Left로 설정  
- Panel 이름을 HP\_Bar로 변경하고 크기 설정 (Width: 200, Height: 50, Pos X: 20, Pos Y: -20)   
- Panel의 색상을 파란색 또는 하늘색으로 변경 (배경)  
- Panel에 Text(Legacy) 추가하고 이름을 HP\_Bar로 변경  
- Text 내용을 "HP"로 설정하고 가운데 정렬 
- 폰트를 Open Sans Bold로 변경  
- Overflow 설정 (텍스트가 영역을 넘어갈 수 있도록) 
- 폰트 크기를 20으로 조정 
- Raycast Target 체크 해제  
- HP\_Bar Panel에 Image 추가  
- HP Bar 스프라이트 적용 (Sprite 타입은 미리 Sprite (2D and UI)로 설정되어 있어야 함)  
- Image Type을 Filled로 설정하고 Fill Method를 Horizontal로 설정 
- Raycast Target 체크 해제  

### Canvas 초기 설정

- Canvas 생성 시 자동으로 EventSystem도 함께 생성됨 
- Canvas의 Render Mode를 Screen Space - Overlay로 설정  
- Canvas Scaler를 Scale with Screen Size로 설정하고 1920x1080 입력   
- Pixel Perfect 체크 (안티 앨리어싱으로 픽셀이 뭉개지지 않도록)   
- RectTransform에는 일반 Transform과 달리 Width, Height, Anchors, Pivot이 있음 

### Layout Group (추후 실습 예정)

- <b>Horizontal Layout Group</b>: 수평 방향으로 UI 요소 간격을 자동으로 맞춤  
- <b>Vertical Layout Group</b>: 수직 방향으로 UI 요소 간격을 자동으로 맞춤 
- <b>Grid Layout Group</b>: UI 요소를 격자 형태로 배치 
- 손으로 배치하면 간격이 정확하지 않으므로 Layout Group 사용 권장 

### Content Size Fitter

- UI 요소의 크기를 내용물에 맞춰 자동으로 조정  
- 서버 게임에서 방 개수가 동적으로 늘어날 때 유용 (스크롤바와 함께 사용)  
- 상황이나 조건에 맞게 UI 크기를 늘렸다 줄였다 할 수 있음 

### Aspect Ratio Fitter

- 비율을 유지하며 UI 크기를 조정 (예: 16:9 비율 유지) 

### 기타 컴포넌트 (추후 실습 예정)

- <b>Button</b>: OnClick() 이벤트로 함수 연결 
- <b>Slider, Toggle, Scroll Rect</b>: 복잡한 상호작용 담당 
- <b>Dropdown Button</b>: 드롭다운 메뉴 생성 
- <b>Input Field</b>: 회원가입, 로그인 시 아이디/비밀번호 입력 

### 드로우콜(Draw Call)

- CPU가 GPU에게 "그려라"는 명령을 내리는 것 
- UI가 많아지면 CPU와 GPU에 부담을 주므로 드로우콜 관리가 중요  
- 동일한 텍스처를 사용하는 UI 요소는 자동으로 배치(batch)되어 드로우콜 감소 

### 텍스트 최적화

- <b>Dynamic Font</b>: 텍스트를 실시간으로 생성하므로 메모리를 많이 사용 
- <b>Static Font</b>: 텍스트가 고정되어 있어 성능이 더 효율적

## 언제 사용하는가?

<h3>
 배경 이미지처럼 큰 이미지일 때
</h3>

큰 이미지를 Sprite Atlas에 넣으면:

- Atlas 전체가 메모리에 로드됨
- 작은 UI 스프라이트와 함께 묶이면 비효율 발생
- 드로우콜은 줄어들 수 있지만 메모리 낭비 가능

따라서,

<blockquote markdown="1">

메인 화면에서 한 번만 사용하는 대형 이미지

또는 Atlas에 넣기 애매한 큰 텍스처일 경우 RawImage 사용

</blockquote>

<b>Unity UI 시스템 구현 강의</b> 2026-02-25

## 요약

이 강의에서는 Unity를 사용하여 게임의 여러 UI 요소들을 구현하는 방법을 다루었습니다. BloodScreen 효과부터 인벤토리 시스템까지 단계별로 구현 과정을 설명했습니다.

### BloodScreen 구현

- TPSDamage 스크립트에 BloodScreen 이미지를 할당하여 피격 시 빨간색 반투명 효과를 표시하도록 구현  
- <code>ShowBloodScreen()</code> 코루틴을 사용하여 0.1초 동안 랜덤 투명도(0.3\~0.5)의 빨간 화면을 표시한 후 투명하게 변경  
- 피격 시마다 <code>StartCoroutine(ShowBloodScreen())</code>을 호출하여 효과 실행 

### HP Bar 생성

- Image UI 컴포넌트를 사용하여 HP Bar 구현  
- <code>fillAmount</code> 속성을 사용하여 현재 HP 비율에 따라 바의 길이 조절: <code>hpBar.fillAmount = curHp / initHp</code>  
- HP 비율에 따른 색상 변경 로직 구현:
  <ul>
  <li>
  30% 이하: 빨간색
  </li>
  <li>
  50% 이하: 노란색  
  </li>
  <li>
  그 외: 초록색  
  </li>
  </ul>
- Text에 outline 효과를 추가하여 가독성 향상  

### 탄창 정보 UI 및 재장전 로직

- 텍스트 UI를 사용하여 "현재탄창/최대탄창" 형식으로 표시  
- HTML 색상 코드를 사용한 텍스트 색상 지정: <code>&lt;color=#FF0000&gt;</code> 형식 사용  
- Rich Text 기능을 체크하여 HTML 마크업 문법 사용 가능하도록 설정   
- 이미지를 사용한 시각적 탄창 표시 구현:
  - 빈 탄창 이미지(Magazine)와 채워진 탄창 이미지(Magazine\_Full)를 겹쳐서 배치  
  - Fill 타입을 Horizontal로 설정하여 탄약 소모에 따라 이미지가 줄어들도록 구현   
- 발사 시마다 <code>remainingBullet</code> 감소 및 UI 업데이트  
- 재장전 로직:
  - <code>remainingBullet</code>이 0이 되거나 <code>currentBullet</code>이 0이 될 때 재장전 시작  
  - 재장전 시 탄창 이미지의 fillAmount를 1로, remainingBullet을 maxBullet으로 복원  
- <code>String.Format</code>을 사용하여 텍스트 업데이트: 탄약 정보를 <code>$"&lt;color=#FF0000&gt;{remainingBullet}/&lt;color=#FFFFFF&gt;{maxBullet}"</code> 형식으로 표시  

### 무기 교체 UI

- Panel과 Button을 사용하여 무기 교체 버튼 생성  
- 무기 아이콘 이미지를 배열로 관리하여 교체 시 아이콘 변경  
- Resources.Load를 사용한 스프라이트 로딩 방법 소개: <code>Resources.Load&lt;Sprite[]&gt;("weapon-icons")</code>   
- <code>OnChangeWeapon()</code> 메서드에서 무기 타입을 토글하고 해당 아이콘으로 UI 업데이트  
- UI 터치 이벤트 방지를 위한 처리:
  - <code>EventSystem.current.IsPointerOverGameObject()</code>를 사용하여 UI 위에 마우스가 있을 때 총알 발사 방지  
  - BloodScreen의 RaycastTarget을 해제하여 UI 상호작용 충돌 방지   

### 일시정지 기능 UI

- Panel과 Button을 사용한 일시정지 버튼 생성  
- GameManager에서 일시정지 상태 관리:
  - <code>isPaused</code> bool 변수로 상태 관리  
  - 일시정지 시 <code>Time.timeScale = 0</code>, 해제 시 <code>Time.timeScale = 1</code>  
  - 플레이어의 모든 MonoBehaviour 스크립트를 비활성화/활성화  
- Canvas Group을 사용한 무기 교체 버튼 차단:
  - Panel\_Weapon에 Canvas Group 컴포넌트 추가  
  - Block Raycast 옵션으로 일시정지 중 무기 교체 버튼 반응 차단  

### 인벤토리 UI 구현 (진행 중)

- Grid Layout Group을 사용한 슬롯 자동 정렬:
  - Cell Size와 Spacing으로 슬롯 크기 및 간격 조정  
  - Padding으로 여백 설정  
- Mask 컴포넌트를 사용하여 인벤토리 영역 밖으로 아이템이 보이지 않도록 제한  
- 드래그 기능 구현:
  - IDragHandler 인터페이스를 상속받아 OnDrag 구현  
  - 드래그 시 아이템이 마우스 포지션을 따라가도록 설정  
  - Grid Layout Group이 드래그를 방해하는 문제 해결: 드래그 시작 시 부모를 Item\_List에서 Inventory로 변경  
- 드롭 기능 구현 (진행 중):
  - IDropHandler 인터페이스 사용  
  - 슬롯에 자식이 없을 때만 드롭 허용  
  - Canvas Group을 사용하여 드래그 중 다른 이벤트 차단  

### 주요 Unity 개념

- <b>RaycastTarget</b>: UI 요소가 이벤트를 받을지 결정하는 옵션. 상호작용하지 않는 UI는 체크 해제하여 성능 향상 및 충돌 방지   
- <b>Canvas Group</b>: UI 그룹의 상호작용, 투명도, Block Raycast 등을 제어  
- <b>Grid Layout Group</b>: UI 요소를 격자 형태로 자동 정렬하는 컴포넌트  
- <b>Event System</b>: Unity UI의 이벤트 처리 시스템. <code>IsPointerOverGameObject()</code>로 UI 터치 감지  
- <b>Find의 사용 주의</b>: Find 계열 함수는 성능 부하가 크므로 특히 Update에서 사용 금지. 가능하면 Inspector에서 직접 할당 

### 캔버스 분리 전략

- DrawCall 최적화를 위해 캔버스를 기능별로 분리 권장:
  - 정적 UI (HP바, 탄약 정보 등)
  - 동적 UI (무기 교체, 일시정지 등)
  - 인벤토리 UI 

### 코드 구조 관련 참고사항

- 프로젝트가 복잡해질수록 Scriptable Object 사용을 고려하여 무기별 속성(발사 간격, 재장전 시간, 사운드 등)을 전역으로 관리  
- MonoBehaviour 상속: Unity 클래스가 되기 위해 필수. 없으면 일반 C# 클래스

```cs
        bloodScreen.color = Color.clear; // 투명하게 설정
    }
}
```

<details markdown="1">
<summary>탄창 UI와 발사·재장전 연결</summary>

총을 쏠 때마다 탄창을 소모해서 텍스트와 이미지가 줄어들도록 구현하기 위해서 TPSFire\_M스크립트에 이미지와 텍스트를 할당하고 파이어 함수와 리로드 함수에 총을 쏘고 리로드할 때 탄창 이미지와 텍스트를 업데이트하도록 구현

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.UI;
//1.총알
//2.발사위치
//3.발사 간격
//4.발사 사운드
//5.애니메이터
//6. 나중에 무기 교체를 위한 Enum 구조체(Structure)에 총알 사운드 배열 선언
[System.Serializable]
public struct PlayerSFX_M //총알 발사와 재장전 오디오 클립을 저장할 구조체
{
    public AudioClip[] Fire; //발사 소리
    public AudioClip[] Reload; //재장전 소리
}
public class TPSFire_M : MonoBehaviour
{
    private int maxBullet = 10; //총알 최대 수 변수
    private int curBullet = 10; //현재 총알 수 변수, 초기값은 maxBullet과 동일하게 설정
    private readonly int hashReload = Animator.StringToHash("Reload");
    private readonly float reloadTime = 1.5f; //재장전 시간 변수
    private WaitForSeconds wsReload;
    private Animator animator;
    private bool isReload = false;
    public enum WeaponType { RIFLE = 0, SHOTGUN = 1 } //열거형 상수
    public WeaponType curWeapon = WeaponType.RIFLE;
    public ParticleSystem muzzleFlash; //총구 화염 효과 변수

    public PlayerSFX_M playerSFX;
    //플레이어가 현재 들고 있는 무기의 종류를 저장 할 변수
    public Transform firePos; //발사 위치
    public GameObject bulletPrefab; //총알 프리팹
    private TPSInput input; //TPSInput 스크립트 변수
    [Header("사운드 관리")]
    [SerializeField] private AudioSource source; //오디오 소스 컴포넌트 변수
    //[SerializeField]private AudioClip fireClip; //발사 사운드 클립 변수
    private float timer = 0f; //타이머 변수
    private float fireRate = 0.1f; //발사 간격 변수

    [Header("탄창 이미지와 관리")]
    public Image megazineImg; //탄창 이미지 변수
    public Text megazineText; //남은 총알 수 텍스트 변수
    public int remainingBullets = 10; //남은 총알 수 변수

    [Header("무기 교체 관리")]
    public Sprite[] weaponIcons; 
    //교체할 무기 이미지 UI
    public Image weaponImage; //현재 무기 아이콘 변수
    private void Awake()
    {
        wsReload = new WaitForSeconds(reloadTime);
        animator = GetComponent<Animator>();
        weaponIcons = Resources.LoadAll<Sprite>("WeaponIcons");
        //Resources.LoadAll() 메서드를 사용하여 "WeaponIcons" 폴더에서 모든 Sprite 리소스를 로드하여 weaponIcons 배열에 할당.
        //이렇게 하면 "WeaponIcons" 폴더에 있는 모든 스프라이트가 weaponIcons 배열에 저장되어 무기 아이콘으로 사용할 수 있게 됨.
    }
    private void OnEnable() //오브젝트가 활성화될 때 호출되는 함수
    {
        input = GetComponent<TPSInput>(); //TPSInput 스크립트 가져오기
        input.FireEvent += Fire; //발사 이벤트에 발사 함수 등록
                                 //이벤트화 할때는 ()를 붙이지 않는다.
        muzzleFlash.Stop(); //총구 화염 효과 중지
    }
    
    private void OnDisable() //오브젝트가 비활성화될 때 호출되는 함수
    {
        input.FireEvent -= Fire; //발사 이벤트에서 발사 함수 해제
    }                      //이벤트화 할때는 ()를 붙이지 않는다.
    void Fire() //발사 함수    
    {
        //UI 터치 이벤트 감지 /무기 교체 버튼을 누를때 총알이 발사되는 것을 방지하기 위해 추가
        if (EventSystem.current.IsPointerOverGameObject()) //현재 터치가 UI 요소 위에서 발생했는지 확인하는 조건문
            return; //UI 요소 위에서 터치가 발생한 경우 발사하지 않고 함수 종료

        //뛰는 중에는 발사하지 않도록
        if (input.isSprint || isReload) //뛰는 중이거나 재장전 중이면
            return; //발사하지 않고 함수 종료

        if (Time.time < timer) // 현재 시간이 타이머보다 작으면
            return; // 발사하지 않고 함수 종료

        --remainingBullets; //남은 총알 수 감소
        megazineImg.fillAmount = (float)remainingBullets / maxBullet; //탄창 이미지의 fillAmount를 남은 총알 비율로 설정
        UpdateBulletText(); //남은 총알 수 텍스트 업데이트 함수 호출하여 UI에 남은 총알 수를 표시.

        isReload = (--curBullet % maxBullet == 0);
        if (isReload && remainingBullets == 0 )
        {
            StartCoroutine(Reloading());
            return;//재장전 중이면 발사하지 않고 함수 종료
            
        }
        timer = Time.time + fireRate; // 타이머 갱신

        var _bullet = Instantiate(bulletPrefab, firePos.position, firePos.rotation);
        //총알 프리팹을 발사 위치와 회전값으로 생성
        Destroy(_bullet, 3f); //3초 후에 총알 오브젝트 제거
        muzzleFlash.Play(); //총구 화염 효과 재생
        Invoke("muzzleFlashDisable", 0.1f);
        //총구 화염 효과를 0.1초에서 0.3초 사이의 랜덤 시간 후에 중지하는 함수 호출
        FireSFX(); //발사 사운드 재생
    }
    void muzzleFlashDisable() //총구 화염 효과 중지 함수
    {
        muzzleFlash.Stop(); //총구 화염 효과 중지
    }
    void FireSFX()
    {
        var _sfx = playerSFX.Fire[(int)curWeapon];
        //현재 무기 종류에 해당하는 발사 사운드 클립을 playerSFX에서 가져와 _sfx 변수에 할당
        source.PlayOneShot(_sfx, 1.0f); //발사 사운드 재생
    }
    IEnumerator Reloading() //재장전 과정을 수행하는 코루틴.
    {
        isReload = true;
        //isReload를 true로 설정하여 재장전 중임을 나타냄. 이 동안 발사 함수에서 발사를 막기 위해 사용.
        var sfx_R = playerSFX.Reload[(int)curWeapon];
        //현재 무기 종류에 해당하는 재장전 사운드 클립을 playerSFX에서 가져와 sfx_R 변수에 할당
        animator.SetTrigger(hashReload);
        //animator.SetTrigger() 메서드를 사용하여 "Reload" 트리거를 활성화, 재장전 애니메이션을 재생.
        //hashReload는 "Reload" 문자열의 해시값으로, 애니메이터에서 해당 트리거를 식별하는 데 사용.
        source.PlayOneShot(sfx_R, 1.0f);
        //source.PlayOneShot() 메서드를 사용하여 reloadClip 오디오 클립을 1.0f 볼륨으로 재생.
        //이는 재장전 소리를 재생하는 역할을 함.
        yield return wsReload;
        //yield return을 사용하여 wsReload(2초 동안 대기하는 WaitForSeconds 객체)를 반환하여 재장전 대기 시간을 설정.
        //이 동안 코루틴은 일시 중지, 대기 시간이 끝나면 다시 실행.
        curBullet = maxBullet;
        //curBullet를 maxBullet로 설정하여 총알을 다시 채움.
        isReload = false;
        //재장전이 완료된 후 isReload를 false로 설정하여 다시 총을 발사할 수 있도록 함.
        megazineImg.fillAmount = 1.0f; 
        //탄창 이미지의 fillAmount를 1로 설정하여 탄창이 가득 찬 상태로 표시.
        remainingBullets = maxBullet;
        //남은 총알 수를 maxBullet로 설정하여 총알 수를 초기화.
        UpdateBulletText(); //남은 총알 수 텍스트 업데이트 함수 호출하여 UI에 남은 총알 수를 표시.
    }
    void UpdateBulletText() //남은 총알 수 텍스트 업데이트 함수
    {
        //남은 총알 수 / 최대 총알 수 표시
        megazineText.text = string.Format($"<color=#ff0000>{remainingBullets}</color> / {maxBullet}");
        //string.Format() 메서드를 사용하여 남은 총알 수와 최대 총알 수를 형식화된 문자열로 만들어 megazineText.text에 할당.
    }
    public void OnChangeWeapon() //무기 변경 함수
    {
        curWeapon = (WeaponType)(((int)++curWeapon) % 2);
        //curWeapon를 WeaponType 열거형으로 변환하여 다음 무기로 변경. 현재 무기가 2종류이므로 0과 1 사이에서 순환 함
        weaponImage.sprite = weaponIcons[(int)curWeapon]; //현재 무기 아이콘을 weaponIcons 배열에서 curWeapon에 해당하는 아이콘으로 설정
    }
}
```

<details markdown="1">
<summary>무기 교체를 위한 UI 이미지를 만들고 이전에 만들었던 TPS\_Fire\_M 에 있던 배열을 사용해서 구현</summary>

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.EventSystems;
using UnityEngine.UI;
//1.총알
//2.발사위치
//3.발사 간격
//4.발사 사운드
//5.애니메이터
//6. 나중에 무기 교체를 위한 Enum 구조체(Structure)에 총알 사운드 배열 선언
[System.Serializable]
public struct PlayerSFX_M //총알 발사와 재장전 오디오 클립을 저장할 구조체
{
    public AudioClip[] Fire; //발사 소리
    public AudioClip[] Reload; //재장전 소리
}
public class TPSFire_M : MonoBehaviour
{
    private int maxBullet = 10; //총알 최대 수 변수
    private int curBullet = 10; //현재 총알 수 변수, 초기값은 maxBullet과 동일하게 설정
    private readonly int hashReload = Animator.StringToHash("Reload");
    private readonly float reloadTime = 1.5f; //재장전 시간 변수
    private WaitForSeconds wsReload;
    private Animator animator;
    private bool isReload = false;
    public enum WeaponType { RIFLE = 0, SHOTGUN = 1 } //열거형 상수
    public WeaponType curWeapon = WeaponType.RIFLE;
    public ParticleSystem muzzleFlash; //총구 화염 효과 변수

    public PlayerSFX_M playerSFX;
    //플레이어가 현재 들고 있는 무기의 종류를 저장 할 변수
    public Transform firePos; //발사 위치
    public GameObject bulletPrefab; //총알 프리팹
    private TPSInput input; //TPSInput 스크립트 변수
    [Header("사운드 관리")]
    [SerializeField] private AudioSource source; //오디오 소스 컴포넌트 변수
    //[SerializeField]private AudioClip fireClip; //발사 사운드 클립 변수
    private float timer = 0f; //타이머 변수
    private float fireRate = 0.1f; //발사 간격 변수

    [Header("탄창 이미지와 관리")]
    public Image megazineImg; //탄창 이미지 변수
    public Text megazineText; //남은 총알 수 텍스트 변수
    public int remainingBullets = 10; //남은 총알 수 변수

    [Header("무기 교체 관리")]
    public Sprite[] weaponIcons; 
    //교체할 무기 이미지 UI
    public Image weaponImage; //현재 무기 아이콘 변수
    private void Awake()
    {
        wsReload = new WaitForSeconds(reloadTime);
        animator = GetComponent<Animator>();
        weaponIcons = Resources.LoadAll<Sprite>("WeaponIcons");
        //Resources.LoadAll() 메서드를 사용하여 "WeaponIcons" 폴더에서 모든 Sprite 리소스를 로드하여 weaponIcons 배열에 할당.
        //이렇게 하면 "WeaponIcons" 폴더에 있는 모든 스프라이트가 weaponIcons 배열에 저장되어 무기 아이콘으로 사용할 수 있게 됨.
    }
    private void OnEnable() //오브젝트가 활성화될 때 호출되는 함수
    {
        input = GetComponent<TPSInput>(); //TPSInput 스크립트 가져오기
        input.FireEvent += Fire; //발사 이벤트에 발사 함수 등록
                                 //이벤트화 할때는 ()를 붙이지 않는다.
        muzzleFlash.Stop(); //총구 화염 효과 중지
    }
    
    private void OnDisable() //오브젝트가 비활성화될 때 호출되는 함수
    {
        input.FireEvent -= Fire; //발사 이벤트에서 발사 함수 해제
    }                      //이벤트화 할때는 ()를 붙이지 않는다.
    void Fire() //발사 함수    
    {
        //UI 터치 이벤트 감지 /무기 교체 버튼을 누를때 총알이 발사되는 것을 방지하기 위해 추가
        if (EventSystem.current.IsPointerOverGameObject()) //현재 터치가 UI 요소 위에서 발생했는지 확인하는 조건문
            return; //UI 요소 위에서 터치가 발생한 경우 발사하지 않고 함수 종료

        //뛰는 중에는 발사하지 않도록
        if (input.isSprint || isReload) //뛰는 중이거나 재장전 중이면
            return; //발사하지 않고 함수 종료

        if (Time.time < timer) // 현재 시간이 타이머보다 작으면
            return; // 발사하지 않고 함수 종료

        --remainingBullets; //남은 총알 수 감소
        megazineImg.fillAmount = (float)remainingBullets / maxBullet; //탄창 이미지의 fillAmount를 남은 총알 비율로 설정
        UpdateBulletText(); //남은 총알 수 텍스트 업데이트 함수 호출하여 UI에 남은 총알 수를 표시.

        isReload = (--curBullet % maxBullet == 0);
        if (isReload && remainingBullets == 0 )
        {
            StartCoroutine(Reloading());
            return;//재장전 중이면 발사하지 않고 함수 종료
            
        }
        timer = Time.time + fireRate; // 타이머 갱신

        var _bullet = Instantiate(bulletPrefab, firePos.position, firePos.rotation);
        //총알 프리팹을 발사 위치와 회전값으로 생성
        Destroy(_bullet, 3f); //3초 후에 총알 오브젝트 제거
        muzzleFlash.Play(); //총구 화염 효과 재생
        Invoke("muzzleFlashDisable", 0.1f);
        //총구 화염 효과를 0.1초에서 0.3초 사이의 랜덤 시간 후에 중지하는 함수 호출
        FireSFX(); //발사 사운드 재생
    }
    void muzzleFlashDisable() //총구 화염 효과 중지 함수
    {
        muzzleFlash.Stop(); //총구 화염 효과 중지
    }
    void FireSFX()
    {
        var _sfx = playerSFX.Fire[(int)curWeapon];
        //현재 무기 종류에 해당하는 발사 사운드 클립을 playerSFX에서 가져와 _sfx 변수에 할당
        source.PlayOneShot(_sfx, 1.0f); //발사 사운드 재생
    }
    IEnumerator Reloading() //재장전 과정을 수행하는 코루틴.
    {
        isReload = true;
        //isReload를 true로 설정하여 재장전 중임을 나타냄. 이 동안 발사 함수에서 발사를 막기 위해 사용.
        var sfx_R = playerSFX.Reload[(int)curWeapon];
        //현재 무기 종류에 해당하는 재장전 사운드 클립을 playerSFX에서 가져와 sfx_R 변수에 할당
        animator.SetTrigger(hashReload);
        //animator.SetTrigger() 메서드를 사용하여 "Reload" 트리거를 활성화, 재장전 애니메이션을 재생.
        //hashReload는 "Reload" 문자열의 해시값으로, 애니메이터에서 해당 트리거를 식별하는 데 사용.
        source.PlayOneShot(sfx_R, 1.0f);
        //source.PlayOneShot() 메서드를 사용하여 reloadClip 오디오 클립을 1.0f 볼륨으로 재생.
        //이는 재장전 소리를 재생하는 역할을 함.
        yield return wsReload;
        //yield return을 사용하여 wsReload(2초 동안 대기하는 WaitForSeconds 객체)를 반환하여 재장전 대기 시간을 설정.
        //이 동안 코루틴은 일시 중지, 대기 시간이 끝나면 다시 실행.
        curBullet = maxBullet;
        //curBullet를 maxBullet로 설정하여 총알을 다시 채움.
        isReload = false;
        //재장전이 완료된 후 isReload를 false로 설정하여 다시 총을 발사할 수 있도록 함.
        megazineImg.fillAmount = 1.0f; 
        //탄창 이미지의 fillAmount를 1로 설정하여 탄창이 가득 찬 상태로 표시.
        remainingBullets = maxBullet;
        //남은 총알 수를 maxBullet로 설정하여 총알 수를 초기화.
        UpdateBulletText(); //남은 총알 수 텍스트 업데이트 함수 호출하여 UI에 남은 총알 수를 표시.
    }
    void UpdateBulletText() //남은 총알 수 텍스트 업데이트 함수
    {
        //남은 총알 수 / 최대 총알 수 표시
        megazineText.text = string.Format($"<color=#ff0000>{remainingBullets}</color> / {maxBullet}");
        //string.Format() 메서드를 사용하여 남은 총알 수와 최대 총알 수를 형식화된 문자열로 만들어 megazineText.text에 할당.
    }
    public void OnChangeWeapon() //무기 변경 함수
    {
        curWeapon = (WeaponType)(((int)++curWeapon) % 2);
        //curWeapon를 WeaponType 열거형으로 변환하여 다음 무기로 변경. 현재 무기가 2종류이므로 0과 1 사이에서 순환 함
        weaponImage.sprite = weaponIcons[(int)curWeapon]; //현재 무기 아이콘을 weaponIcons 배열에서 curWeapon에 해당하는 아이콘으로 설정
    }
}
```

<details markdown="1">
<summary>일시 정지와 UI 상호작용 제어</summary>

게임의 일시정지를 구현하기 위해 GameManager 스크립트에 Pause 버튼을 토글 하면 멈추고 다시 토글 하면 움직이게 구현 Time.timeScale 을 이용 해서 시간을 일시 정지하고 플레이어의 행동을 전부 멈추게 태그를 이용 하여 모든 스크립트를 비활성화 그 이후 다른 무기 교체 UI 도 작동하지 않도록 상호 작용 가능 여부를 설정해서 완성

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using static Codice.Client.Common.Connection.AskCredentialsToUser;
//적이 태어나게 만들어 보자, 나중에 오브젝트 풀링을 할때는 오브젝트 풀링매니저를 만들어서 옮길 예정
//순서 1.태어날 위치(SpawnPoint)
//2.적 프리팹 오브젝트
//3.적이 태어나는 시간 간격(SpawnTime)
//4.적이 태어나는 최대 수(MaxEnemyCount)
//싱글턴 디자인 패턴으로 만들어 보기
//5.게임 일시정지 기능 추가
public class GameManager : MonoBehaviour
{
    public static GameManager instance = null; //싱글턴 인스턴스 변수
    [Header("적이 태어날 위치")]
    public Transform[] points;
    public bool isGameOver = false;
    
    [Header("적 프리팹 오브젝트")]
    public GameObject[] enemyPrifab;
    
    [Header("적이 태어나는 시간 간격")]
    private float CreateTime = 3f;
    private WaitForSeconds createWs;

    [Header("적이 태어나는 최대 수")]
    private int maxEnemy = 10;

    private readonly string[] enemyTag = { "ENEMY", "SWAT" };

    [Header("게임 일시정지")]
    private bool isPaused;

    private void Awake()
    {
        if (instance == null) //인스턴스가 아직 생성되지 않은 경우
        {
            instance = this; //현재 객체를 인스턴스로 설정
        }
        else if (instance != this) //인스턴스가 이미 존재하고 현재 객체가 인스턴스가 아닌 경우
        {
            Destroy(gameObject); //현재 객체를 파괴하여 중복된 인스턴스 방지
            //다른 씬에 갔다가 원래 씬으로 돌아오면 GameManager가 또 생기는데, 그걸 방지하기 위해서 만든 코드
        }
        DontDestroyOnLoad(this.gameObject); //씬이 변경되어도 이 객체가 파괴되지 않도록 설정
    }
    void Start()
    {
        points = GameObject.Find("SpawnPoints").GetComponentsInChildren<Transform>();
        createWs = new WaitForSeconds(CreateTime);
        if (points.Length > 0 && enemyPrifab.Length > 0)
        {
            StartCoroutine(CreateEnemy());
        }
    }
    IEnumerator CreateEnemy()
    {        
        while (!isGameOver)
        {
            int enemyCount = 0; //현재 씬에 존재하는 적의 수를 세는 변수
            for (int i = 0; i < enemyTag.Length; i++) //적 태그 배열을 순회하면서
                enemyCount += GameObject.FindGameObjectsWithTag(enemyTag[i]).Length; //각 태그에 해당하는 게임 오브젝트의 수를 enemyCount에 더함
            if (enemyCount < maxEnemy) 
            {
                yield return createWs; //3초후에 태어나게
                int idx = Random.Range(1, points.Length); //0번은 SpawnPoints이므로 1부터 시작 //불규칙하게 태어나게
                Instantiate(enemyPrifab[Random.Range(0, enemyPrifab.Length)], points[idx].position, points[idx].rotation);
            }
            else
            {
                yield return null; //한 프레임 대기
            }
           
        }       
    }
    public void OnPauseClick()
    {
        isPaused = !isPaused; //토글 방식으로 일시정지 상태 변경
        Time.timeScale = (isPaused ? 0.0f : 1.0f);
        //Time.timeScale을 0으로 설정하면 게임이 일시정지되고, 1로 설정하면 게임이 정상적으로 진행

        // 플레이어가 전혀 움직이지 못하게 플레이어의 스크립트들을 비활성화
        var player = GameObject.FindGameObjectWithTag("Player");
        //GameObject.FindGameObjectWithTag("PLAYER") 메서드를 사용하여 "PLAYER" 태그가 지정된 게임 오브젝트를 찾아 player 변수에 할당
        MonoBehaviour[] scripts = player.GetComponents<MonoBehaviour>();
        //GetComponents<MonoBehaviour>() 메서드를 사용하여 플레이어 게임 오브젝트에 연결된 모든 MonoBehaviour 스크립트를 배열로 가져옴
      foreach (MonoBehaviour script in scripts)
        //foreach 루프를 사용하여 배열에 있는 각 스크립트에 대해 반복하면서,
        //script.enabled 속성을 isPaused의 반대값으로 설정하여 일시정지 상태에 따라 스크립트를 활성화하거나 비활성화
        {
            script.enabled = !isPaused; //일시정지 상태에 따라 스크립트 활성화/비활성화
        }
      var canvasGroup = GameObject.Find("Panel-Weapon").GetComponent<CanvasGroup>();
```

```cs
public class Drag : MonoBehaviour, IDragHandler, IBeginDragHandler, IEndDragHandler
//드래그 이벤트 인터페이스 구현
{
    private Transform itemTr;//드래그 할 아이템의 트랜스폼

    void Start()
    {

        //inventoryTr = GameObject.Find("Inventory").GetComponent<Transform>();
        //인벤토리의 트랜스폼 할당 근데 파인드로 할당하면 메모리를 많이 잡아먹으니까 직접 할당
        //특히 void Update()에서는 절대 할당 하면 안됨 왜냐하면 업데이트는 매 프레임마다 실행되기 때문에 메모리를 미친듯이 잡아먹음
    }
    public void OnDrag(PointerEventData eventData) //드래그 이벤트

    }
```
