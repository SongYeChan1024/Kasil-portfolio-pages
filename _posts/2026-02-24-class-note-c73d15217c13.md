<b>휴머노이드 플레이어 스프린트 및 총알 발사 구현</b> 2026-02-24


## 요약


### 액션 아이템

- [ ] TPS Fire 구현 완료하고 캡처해서 제출 
- [ ] 공모전 (컴투스 등) 검색 및 참가 고려 
- [ ] 점심 전까지 발사 시스템 완성 

### 스프린트 기능 구현

- Shift + W 키를 누르면 플레이어가 달리기 동작 수행  
- Move Speed를 Walk Speed와 Run Speed로 구분하여 설정  
- <code>isSprint</code> 변수를 통해 달리기 상태 확인  
- 달리는 중에는 발사가 안 되도록 처리 필요 
- 애니메이터에 <code>WithSprint</code> 파라미터 추가 및 트랜지션 설정 

### 애니메이션 블렌딩 설정

- SetFloat의 4개 인자 사용: 이름(ID), 값(value), 댐핑타임, 델타타임  
- 댐핑타임 0.1 설정으로 부드러운 전환 구현  
- 크로스페이드를 통한 블렌드 애니메이션 처리 
- 전진/후진, 좌/우 이동을 forward(Z)와 right(X)로 통합 

### 총알 발사 시스템 구현

- 필요한 컴포넌트 :
  - 총알 프리팹
  - 발사 위치 (FirePos)
  - 오디오 소스 및 사운드 클립
  - 발사 간격 (FireRate)
  - 애니메이터
- 무기 타입 열거형: RIFLE, SHOTGUN 
- PlayerSFX 구조체로 발사/재장전 사운드 관리  
- Muzzle Flash 파티클 효과 추가  
- 발사 간격 0.1\~0.2초로 설정하여 연사 구현  

### 재장전 애니메이션 구현

- Enemy 애니메이션 클립에서 SMG Reload 애니메이션 활용 
- Avatar Mask 생성하여 상체만 적용 (Player Reload)   
- 휴머노이드 상체만 활성화 설정 
- Animator에 새로운 레이어 추가  
- Weight 1.0, Override 모드로 설정  
- Reload 트리거 파라미터 생성 
- Has Exit Time 체크 및 전환 속도 0.03 설정  
- 10발 발사 후 재장전 로직 구현 필요 

### 레이어 시스템 설명

- Base Layer와 별개로 동작하는 레이어 생성 시 Weight를 1로 설정 
- Override 모드: 위 레이어와 독립적으로 동작할 때 사용  
- Additive 모드: 위 레이어 동작에 이어서 할 때 사용 
- Avatar Mask로 상체(어깨, 팔) 움직임만 분리 

### 디버깅 및 문제 해결

- 같은 이름의 스크립트로 인한 오류 발생 
- 스크립트 이름에 언더바M 추가하여 구분 (예: PlayerSFX\_M, TPSFire\_M)   
- Fire 애니메이션은 총알 발사 정확도 문제로 생략 
- Unity UI 버그 발생 시 탭 닫기 후 재오픈으로 해결 

### 프로젝트 구조 개선

- Mechanic 폴더 생성하여 관련 스크립트 정리   
- TPSFire\_M, TPSCtrl 등을 Mechanic 폴더로 이동 
- Resources에서 사운드 및 이펙트 리소스 관리 

### 공모전 및 취업 관련 조언

- 컴투스 공모전 추천 - 입상 시 취업에 큰 도움   
- 컴투스는 3개월 인턴십 기간 동안 모든 직군 교육 제공  
- 프로그래머의 약 50% 이상이 기획자로 전향 
- 1년에 약 60개 공모전 존재 - 프로젝트와 병행 가능 
- 취업 외에도 학원 강사로 활동 가능 (시급 2만5천\~3만5천원)   
- 배운 기술은 창업, 취업, 강의 등 다양한 분야에 활용 가능 

### 학습 방법 및 마인드셋

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
//1.총알 2.발사위치3.발사 간격4.발사 사운드 5.애니메이터
[System.Serializable]
public struct PlayerSFX_M //총알 발사와 재장전 오디오 클립을 저장할 구조체
{
    public AudioClip[] Fire; //발사 소리
    public AudioClip[] Reload; //재장전 소리
}
public class TPSFire_M : MonoBehaviour
{
    public enum WeaponType { RIFLE = 0, SHOTGUN = 1 } //열거형 상수
    public WeaponType curWeapon = WeaponType.RIFLE;
    public ParticleSystem muzzleFlash; //총구 화염 효과 변수

    public PlayerSFX playerSFX;
    //플레이어가 현재 들고 있는 무기의 종류를 저장 할 변수
    public Transform firePos; //발사 위치
    public GameObject bulletPrefab; //총알 프리팹
    private TPSInput input; //TPSInput 스크립트 변수
    [Header("사운드 관리")]
    [SerializeField] private AudioSource source; //오디오 소스 컴포넌트 변수
    //[SerializeField]private AudioClip fireClip; //발사 사운드 클립 변수
    private float timer = 0f; //타이머 변수
    private float fireRate = 0.3f; //발사 간격 변수
    private void OnEnable() //오브젝트가 활성화될 때 호출되는 함수
    {
        input = GetComponent<TPSInput>(); //TPSInput 스크립트 가져오기
        input.FireEvent += Fire; //발사 이벤트에 발사 함수 등록
                                 //이벤트화 할때는 ()를 붙이지 않는다.
        muzzleFlash.Stop(); //총구 화염 효과 중지
    }
    private void OnDisable() //오브젝트가 비활성화될 때 호출되는 함수
    {
        input.FireEvent -= Fire; //발사 이벤트에서 발사 함수 해제
    }                      //이벤트화 할때는 ()를 붙이지 않는다.
    void Fire() //발사 함수    
    {
        //뛰는 중에는 발사하지 않도록
        if (input.isSprint) //달리는 중이면
            return; //발사하지 않고 함수 종료

        if (Time.time < timer) // 현재 시간이 타이머보다 작으면
            return; // 발사하지 않고 함수 종료
        timer = Time.time + fireRate; // 타이머 갱신

        var _bullet = Instantiate(bulletPrefab, firePos.position, firePos.rotation);
        //총알 프리팹을 발사 위치와 회전값으로 생성
        Destroy(_bullet, 3f); //3초 후에 총알 오브젝트 제거
        muzzleFlash.Play(); //총구 화염 효과 재생
        Invoke("muzzleFlashDisable", 0.1f);
        //총구 화염 효과를 0.1초에서 0.3초 사이의 랜덤 시간 후에 중지하는 함수 호출
        FireSFX(); //발사 사운드 재생
    }
    void muzzleFlashDisable() //총구 화염 효과 중지 함수
    {
        muzzleFlash.Stop(); //총구 화염 효과 중지
    }
    void FireSFX()
    {
        var _sfx = playerSFX.Fire[(int)curWeapon];
        //현재 무기 종류에 해당하는 발사 사운드 클립을 playerSFX에서 가져와 _sfx 변수에 할당
        source.PlayOneShot(_sfx, 1.0f); //발사 사운드 재생
    }
}
```

Enemy가 시간 차로 생성 되게 하여 10개체 정도 생성해보기<br />A.태어날 위치 SpawnPoint

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
//적이 태어나게 만들어 보자, 나중에 오브젝트 풀링을 할때는 오브젝트 풀링매니저를 만들어서 옮길 예정
//순서 1.태어날 위치(SpawnPoint)
//2.적 프리팹 오브젝트
//3.적이 태어나는 시간 간격(SpawnTime)
//4.적이 태어나는 최대 수(MaxEnemyCount)
//싱글턴 디자인 패턴으로 만들어 보기
public class GameManager : MonoBehaviour
{
    public static GameManager instance = null; //싱글턴 인스턴스 변수
    [Header("적이 태어날 위치")]
    public Transform[] points;
    public bool isGameOver = false;
    
    [Header("적 프리팹 오브젝트")]
    public GameObject[] enemyPrifab;
    
    [Header("적이 태어나는 시간 간격")]
    private float CreateTime = 3f;
    private WaitForSeconds createWs;

    [Header("적이 태어나는 최대 수")]
    private int maxEnemy = 10;

    private readonly string enemyTag = "ENEMY";
void Start()
{
    points = GameObject.Find("SpawnPoints").GetComponentsInChildren<Transform>();
    createWs = new WaitForSeconds(CreateTime);
    if (points.Length > 0 && enemyPrifab.Length > 0)
    {
        StartCoroutine(CreateEnemy());
    }
}
IEnumerator CreateEnemy()
{
    while (!isGameOver)
    {
        int enemyCount = GameObject.FindGameObjectsWithTag(enemyTag).Length;
        //하이라키 상에서 ENEMY 태그를 가진 오브젝트의 수를 enemyCount에 대입한다.
        if (enemyCount < maxEnemy)
        {
            yield return createWs; //3초후에 태어나게
            int idx = Random.Range(1, points.Length); //0번은 SpawnPoints이므로 1부터 시작 //불규칙하게 태어나게
            Instantiate(enemyPrifab[Random.Range(0, enemyPrifab.Length)], points[idx].position, points[idx].rotation);
        }
        else
        {
            yield return null; //한 프레임 대기
        }

    }
}
}
```

```cs
public class GameManager : MonoBehaviour
{
    public static GameManager instance = null; //싱글턴 인스턴스 변수
    [Header("적이 태어날 위치")]
    public Transform[] points;
    public bool isGameOver = false;
    
    [Header("적 프리팹 오브젝트")]
    public GameObject[] enemyPrifab;
    
    [Header("적이 태어나는 시간 간격")]
    private float CreateTime = 3f;
    private WaitForSeconds createWs;

    [Header("적이 태어나는 최대 수")]
    private int maxEnemy = 10;

    private readonly string enemyTag = "ENEMY";

    private void Awake()
    {
        if (instance == null) //인스턴스가 아직 생성되지 않은 경우
        {
            instance = this; //현재 객체를 인스턴스로 설정

        else if (instance != this) //인스턴스가 이미 존재하고 현재 객체가 인스턴스가 아닌 경우
        {
            Destroy(gameObject); //현재 객체를 파괴하여 중복된 인스턴스 방지

        }

    }

        createWs = new WaitForSeconds(CreateTime);
        if (points.Length > 0 && enemyPrifab.Length > 0)

            StartCoroutine(CreateEnemy());
```

SwatAI 스크립트에서 구독 해서 적용 하였음

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
[RequireComponent(typeof(Animator))]
//상황조건에 따라 애니메이션 재생

public class SwatAI : MonoBehaviour
{
    public enum State { PATROL, TRACE, ATTACK, DIE }
    public State state = State.PATROL;
    [Header("위치와 거리")]
    [SerializeField] private Transform playerTr;
    [SerializeField] private Transform swatTr;
    public float attackDist = 5.0f;
    public float traceDist = 10.0f;
    public bool isDie = false;
    private WaitForSeconds ws;
    private SwatMoveAgent moveAgent;
    private Animator animator;
    private readonly int hashMove = Animator.StringToHash("IsMove");
    private readonly int hashSpeed = Animator.StringToHash("Speed");
    private readonly int hashDie = Animator.StringToHash("Die");
    private readonly int hashDieIDX = Animator.StringToHash("SWATDieIDX");
    private readonly int hashPlayerDie = Animator.StringToHash("PlayerDie");
    private SwatFire swatFire;
    void Awake()
    {
        swatFire = GetComponent<SwatFire>();
        animator = GetComponent<Animator>();
        moveAgent = GetComponent<SwatMoveAgent>();
        playerTr = GameObject.FindWithTag("Player").transform;
        swatTr = GetComponent<Transform>();
        ws = new WaitForSeconds(0.3f);
    }

    private void OnEnable()
    {
        StartCoroutine(CheckStat());
        StartCoroutine(Action());
        TPSDamage.OnPlayerDie += this.PlayerDie;
    }
    private void OnDisable()
    {
        TPSDamage.OnPlayerDie -= this.PlayerDie;
    }
    IEnumerator CheckStat()
    {
        while (isDie == false)
        { 
            if(state == State.DIE) yield break;
            float dist = Vector3.Distance(swatTr.position, playerTr.position);

            if (dist < attackDist)
            {
                state = State.ATTACK; break;
            }
            else if (dist <= traceDist)
            {
                state = State.TRACE;
            }
            else
            {
                state = State.PATROL;
            }
            yield return ws;
        }
    }
    IEnumerator Action()
    {
        while (!isDie)
        { 
        yield return ws;

            switch (state)
            {
                case State.PATROL:
                    swatFire.isFire = false;
                    moveAgent.patroling = true;
                    animator.SetBool(hashMove, true);
                    break;
                case State.TRACE:
                    swatFire.isFire = false;
                    moveAgent.traceTarget = playerTr.position;
                    animator.SetBool(hashMove, true);
                    break;
                case State.ATTACK:
                    swatFire.isFire = true;
                    moveAgent.Stop();
                    animator.SetBool(hashMove, false);
                    break;
                case State.DIE:
                    SwatDie();
                    break;
            }

        }
    }

    public void SwatDie()
    {
        isDie = true;
        swatFire.isFire = false;
        moveAgent.Stop();
        animator.SetInteger(hashDieIDX, Random.Range(0, 3));
        animator.SetTrigger(hashDie);
        GetComponent<Collider>().enabled = false;
        GetComponent<Rigidbody>().isKinematic = true;
        StopAllCoroutines();
        this.gameObject.tag = "Untagged"; 
        Destroy(gameObject, 3.0f);
    }
    private void Update()
    {
        animator.SetFloat(hashSpeed, moveAgent.speed);
    }
    public void PlayerDie() 
    {
        isDie = true;           
        state = State.DIE;      

        moveAgent.Stop();
        swatFire.StopFire();    

        StopAllCoroutines();
        animator.SetBool(hashMove, false);
        animator.SetTrigger(hashPlayerDie);
    }
}
```
