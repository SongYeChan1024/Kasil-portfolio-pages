# 일일회고록

## 1) 오늘 한 일

- <b>EP.3-1 퍼즐/컷씬 흐름 정리</b>
  - 악보 조각 10개를 모두 수집했을 때 <b>완성된 악보 + 음악</b>이 등장하는 흐름을 정리했다.
  - 이후 <b>피아노 상호작용 → 이미지 컷씬 재생</b>으로 이어지도록 전체 연결을 맞췄다.
  - 컷씬 이미지 출력 방식과 <b>자막이 어디에서 관리되는지</b>도 다시 확인해서, 이후 연출 수정이 쉬운 구조로 점검했다.
- <b>사운드 시스템 리팩토링 & 옵션 리셋 버그 수정</b>
  - <code>switch(scene.name)</code> 기반 하드코딩을 정리하고, <b><code>SoundProfile</code></b><b> + Dictionary 중심 구조</b>로 리팩토링했다.
  - 씬 사운드 적용 책임을 <code>SoundManager</code>로 <b>일원화</b>하고, 중복 구조였던 <code>SoundController</code>는 제거했다.
  - 옵션 팝업의 <b>오디오 Reset 버튼이 동작하지 않던 문제</b>를 해결했다.
  - Reset 시 <b>각 씬의 기본 볼륨값</b>으로 돌아가도록 기준을 정리했다.
  - 사용자가 볼륨을 직접 조절한 뒤 씬 전환 시 값이 덮어써지던 오류를 수정해, <b>사용자 설정이 유지되도록</b> 만들었다.
- <b>EP.3-2 퍼즐 리뉴얼(탑다운 리듬 퍼즐) 착수</b>
  - 기존 점프형 구상에서 방향을 바꿔 <b>W/A/S/D 기반 탑다운 리듬 퍼즐</b>로 구조를 새로 구성했다.
  - 퍼즐 시작 시 <b>카메라 탑다운 전환</b>, 플레이어는 고정 위치에서 입력으로 내려오는 노트를 판정하는 흐름으로 정리했다.
  - 비트맵 생성도 탑다운 퍼즐에 맞게 분리했고, 현재 단계에서는 복잡도를 줄이기 위해 <b>동시 생성 노트는 제외</b>하고 “한 타이밍에 1개 노트”로 정리했다.
  - 메트로놈 시작 오브젝트 기준으로 퍼즐 카메라/판정선/플레이어 고정 위치가 자동으로 맞춰지도록 세팅 구조를 손봤다.

---

## 2) 느낀 점

- 오늘은 “새 기능 추가”보다 <b>구조 정리와 연결 관계 정비</b>가 작업 효율을 크게 좌우한다는 걸 확실히 느꼈다.
- 사운드/컷씬/퍼즐처럼 여러 시스템이 연결된 영역은, 책임이 분산되어 있으면 작은 수정도 예상보다 큰 오류로 번질 수 있었다.
- 반대로 기준점(데이터 흐름, 책임 분리, 적용 순서)을 먼저 정리해두니, 이후 연출이나 수치 튜닝은 훨씬 빠르고 안전하게 진행할 수 있을 것 같다.

---

## 3) 아쉬운 점

- 리팩토링과 구조 변경이 많았던 만큼, 테스트 과정에서 확인해야 할 포인트가 늘어나 작업이 길어졌다.
- 특히 “지금은 단순화가 우선”인 구간(예: 동시 노트 생성)을 명확히 쳐내긴 했지만, 추후 난이도/리듬감 개선 단계에서 다시 확장해야 할 부분을 미리 체크리스트로 더 쌓아둘 필요가 있다.

---

## 4) 내일 할 일

- <b>EP.3-2 퍼즐 시각적 완성도 보완</b>
  - 노트 비주얼 프리팹, 레인 패드 프리팹을 실제 씬에 맞게 연결
  - 판정선 위치와 카메라 구도를 더 자연스럽게 다듬기
- <b>플레이 감(채보/난이도) 튜닝 준비</b>
  - 구간별 채보 밀도/난이도 조절
  - 음악과 입력 타이밍이 더 자연스럽게 맞물리도록 보완 방향 정리
