# 일일회고록

## 1) 오늘 한 일

- <b>사운드 시스템 구조 정리(씬 사운드 적용 방식 개선)</b>
  - 씬 이름을 직접 분기하던 방식에서 벗어나, <b>씬 이름을 키로 </b><b><code>SoundProfile</code></b><b>을 조회하는 딕셔너리 구조</b>로 정리하는 방향을 다시 확인했다.
  - <code>SoundController</code>를 제거하고, 씬 사운드 적용 책임을 <code>SoundManager</code>로 <b>일원화</b>해 구조를 단순화했다.
  - 결과적으로 씬이 늘어나더라도 코드 수정량이 줄고, 관리가 쉬운 형태로 정리됐다.
- <b>옵션 팝업 Reset 기능 수정(기본값/유지값 기준 정리)</b>
  - 초기화 기준을 “프로젝트 공통 기본값”에서 <b>각 씬 </b><b><code>SoundProfile</code></b><b>에 저장된 기본값</b>으로 되돌리는 구조로 수정했다.
  - 옵션 팝업에 Reset 버튼을 추가하고, Reset 시 <b>슬라이더 값과 실제 사운드 값이 함께</b> 기본값으로 복귀하도록 흐름을 정리했다.
  - Reset 버튼이 눌리지 않는 문제를 추적했다.
    - UI 겹침/우선순위 문제를 의심해 클릭 우선순위를 올려보기도 했지만,
    - 최종 원인은 <b>‘버튼처럼 보이는 원형 아이콘’이 실제 버튼이 아니고, 다른 위치에 진짜 버튼이 따로 남아 있던 구조 문제</b>였음을 확인했다.
    - 위쪽 아이콘을 실제 Reset 버튼으로 교체하고, 기존 버튼은 비활성화하는 방향으로 정리했다.
- <b>사용자 볼륨 설정 유지 로직 보완(씬 전환 시 값 유지)</b>
  - 씬 전환 시 기본값이 다시 적용되어 사용자가 0으로 줄인 볼륨이 원복되는 문제를 수정했다.
  - 사용자가 한 번이라도 슬라이더를 조절했다면 이후에는 <b>저장된 값 유지</b>,
    <p>
    그리고 <b>Reset 버튼을 눌렀을 때만</b> 현재 씬 기본값으로 복귀하도록 기준을 정리했다.
    </p>
- <b>에피소드 3-1 악보 조각 퍼즐 보완(힌트 사운드/스폰 구조 점검)</b>
  - 악보 조각 힌트를 <b>거리 기반(가까울수록 커지고 멀수록 작아짐)</b>으로 적용하고 3D 공간감 설정을 보완했다.
  - 악보 조각이 한 종류만 나오는 것처럼 보이던 문제를 재확인했다.
    - 실제로는 <b>1\~10번 조각이 각각 1회씩 스폰</b>되고, <b>위치만 랜덤 배치</b>되도록 구조를 정리했다.

---

## 2) 느낀 점

- 오늘은 기능 추가보다 <b>구조를 바로잡고 원인을 추적하는 디버깅 중심의 작업</b>이 많았다.
- Reset 버튼 이슈는 단순 클릭 문제처럼 보였지만, 실제로는 <b>겉으로 보이는 오브젝트와 실제 기능 오브젝트가 분리되어 있던 구조 문제</b>였다.
  - “보이는 현상”이 아니라 “실제 역할/연결”을 끝까지 확인하는 게 디버깅에서 가장 중요하다는 걸 다시 느꼈다.
- 사운드 시스템을 데이터 중심(딕셔너리 + 프로필)으로 정리하는 과정에서, 기능을 늘리는 것만큼 <b>구조를 단순화하는 작업 자체가 이후 속도와 안정성을 올려준다</b>는 점을 체감했다.

---

## 3) 아쉬운 점

- 사운드 기본값/Reset/클릭 판정/사용자 설정 유지 문제가 연달아 이어져서, 하나를 고치면 또 다른 문제가 드러나는 흐름이 있었다.
- 특히 Reset 버튼 문제는 초반에 UI 겹침으로만 가정해서 시간을 썼는데, <b>초기에 구조(오브젝트 역할/연결)를 더 빨리 검증</b>했으면 디버깅 시간을 줄일 수 있었을 것 같다.
- 씬별 기본값과 사용자 저장값의 관계도, 처음부터 “언제 기본값을 적용하고 언제 사용자 값을 유지하는가” 기준을 더 단단히 잡았으면 시행착오가 덜했을 것 같다.
