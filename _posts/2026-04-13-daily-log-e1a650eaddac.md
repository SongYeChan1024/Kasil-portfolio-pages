## 오늘 한 일(요약)

- 3-1 최초 진입 컷씬 재생 구조 분리/재설정 (로비와 플래그 분기)
- 씬 복사 후 참조 누락 이슈 점검 및 자동 연결/예외 처리 방향 정리
- 악보 조각 10개 수집 완료 시 저장 플래그 처리에서 발생한 NullReference 방어
- 퍼즐 완료 연출 흐름(음악/컷씬/문 오픈) 현재 구조 vs 목표 구조 갭 확인
- 피아노 상호작용 컷씬용 이미지(스포트라이트/악보 클로즈업 등) 준비

## 구현한 것

- 3-1 전용 컷씬 컨트롤러/NPC 세팅 분리 및 최초 1회 재생 저장 구조 정리
- Leon NPC 복사 시 플레이어 참조/상호작용 구독이 다시 연결되도록 보강
- 대화 카메라 전환 시 <code>followCam</code> 누락으로 인한 NullReference 원인 파악
- 악보 10개 완료 시 <code>SaveManager</code>/현재 데이터 null 상황을 고려한 방어 코드 방향 반영
- 컷씬 연출에 사용할 1920x1080 비율 이미지 리소스 제작

## 배운 것(개념/정리)

- 씬 복사/기능 이관은 “데이터 + 참조(카메라/오브젝트) + 저장 흐름”을 같이 점검해야 안정적이다.
- 로비에서 정상 동작하던 기능이 다른 씬에서 깨질 때는 스크립트 자체보다 “씬 내부 참조 누락”이 원인일 가능성이 높다.
- 퍼즐/연출은 “이미 있는 것”과 “내가 원하는 최종 감정선”을 분리해서 갭을 먼저 파악하면 작업 속도가 빨라진다.

## 이슈/버그

- 내용: NPC 대화 시 <code>NullReferenceException</code> 발생
  - 원인/가설: 대화 카메라 전환에 필요한 <code>followCam</code> 참조가 비어 있음
  - 해결/시도: 씬 내 참조 연결 점검, <code>ChatNPCManager</code> 자동 탐색/예외 처리 방향으로 보강
  - 다음 액션: 씬 복사 후 “카메라/참조 오브젝트 연결” 체크리스트화
- 내용: 악보 10개 수집 완료 시 <code>NullReferenceException</code> 발생
  - 원인/가설: <code>SaveManager.instance</code> 또는 <code>curData</code>가 비어 있는 상태에서 저장 플래그 접근
  - 해결/시도: 저장 매니저/데이터 null 상황을 고려한 방어 코드 추가 방향으로 수정
  - 다음 액션: 퍼즐 완료/저장 트리거 구간에 공통 방어 유틸 적용 검토

## 내일 할 일

- 3-1 퍼즐 완료 후 피아노 상호작용 컷씬을 실제 진행 흐름에 연결
- 컷씬 종료 후 문 오픈까지 연출 순서(음악→컷씬→문) 정리 및 자동 연결
