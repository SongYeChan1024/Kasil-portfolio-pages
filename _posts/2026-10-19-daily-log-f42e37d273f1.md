## 오늘의 목표

플레이어 조작을 3인칭으로 바꿀 가능성을 검토하고, 같은 데모 캐릭터와 전투 시스템을 사용하는 별도 연습장에서 이동·공격·스킬의 조작감을 비교할 수 있게 만듭니다.

## 오늘 한 일

### 3인칭 조작안 정리

- WASD 이동, 마우스 시점 회전, 좌클릭 기본 공격으로 구성했습니다.
- 스킬 8칸은 QERTZXCV, 상호작용은 F, 소모품 4칸은 1234로 구분했습니다.
- Shift는 달리기, Space는 기존 정신 집중, B/Tab은 장비·에르고 스퀘어 편집, Esc는 메뉴 닫기 또는 커서 해제입니다.
- 스퀘어와 스킬 조합은 기존 시스템을 재사용하며, 본편 조작 방식의 최종 전환은 실제 플레이 비교 후 판단합니다.

### 별도 비교 씬 구현

- ThirdPerson\_Comparison 씬에 연속 지면, 거리선, 표적 3개, 카메라 장애물과 F 보급대를 배치했습니다.
- 기존 Player\_Architect\_Demo 프리팹의 씬 인스턴스에 비교용 입력·카메라·피드백을 추가했습니다. 재생 전 루트의 Demo Player Rig에서 FSM과 실제 Animator를 확인할 수 있습니다.
- 공통 이동기에 선택형 직접 이동을 추가하고, 새 UI에는 씬별 스킬 키 표시·배정 입력을 연결했습니다. 기존 데모의 클릭 이동과 입력 자산은 유지합니다.
- 원래 3단 공격·실제 피해·스킬 비용·냉각을 재사용하고, 검 끝 잔상과 스킬 방향 가이드·표적 체력 표시를 추가했습니다.

### 시험용 구성과 소모품

- 비교용 Lv.5에서 첫 3×3과 두 번째 2×3 스퀘어를 미리 구성했습니다. 장착된 검, Q 빗자루·E 월도와 독립 코어 2개를 지급해 두 스킬을 비교할 수 있게 했습니다.
- 나머지 6개 스킬칸은 새 UI에서 자유롭게 재배정할 수 있습니다.
- 1번 회복약과 2번 정기약을 각 3개 지급하고 3·4번은 빈 예약 슬롯으로 남겼습니다. 회복량 +30과 공통 재사용 대기 2초는 비교용 가안입니다.
- 메뉴에서는 게임플레이 입력을 차단합니다. F 보급은 체력·정기·약품·표적을 회복하며 스킬 냉각은 유지합니다. 지급 상태는 이 씬의 메모리에서만 사용합니다.

## 발견한 문제와 해결

- WASD 이동과 기존 스킬 키가 겹쳤습니다. 별도 Input Actions 자산에서 실제 키만 바꾸고 슬롯 번호 계약은 유지했습니다.
- 기존 플레이어 루트의 NavMeshAgent 높이 오프셋 때문에 카메라 기준점과 시험 위치가 어긋날 수 있었습니다. 상체 기준 카메라와 NavMesh 시험 배치를 맞추고, 벽 경계 이동이 루트를 아래로 끌어내리지 않도록 수평 이동을 보정했습니다.
- Q와 E가 같은 코어를 사용하면 냉각을 공유해 비교가 어려웠습니다. 연습장 지급 구성에서만 두 공간에 독립 코어를 준비했습니다. 기존 튜토리얼 성장 규칙은 변경하지 않았습니다.

## 검증 결과

별도 Unity 6000.3.7f1에서 다음 검사를 통과했습니다.

- 편집 모드 FSM·Animator 연결과 키 바인딩 11개.
- Input System 키보드·마우스 이벤트를 통한 비교 씬 플레이 검사 45개.
- 원래 3타 연계·타격 3회·총 피해 45, 빗자루 실제 피해와 월도 실행, 소모품·F 보급·메뉴 입력 차단 확인.
- 벽 앞 이동의 NavMesh 제약·루트 높이 유지와 카메라 거리 축소 확인.
- 기존 데모의 클릭 이동·Animator·전투 회귀 검사 210개. 반복 프레임 검사를 포함합니다.
- 기존 씬·조립 프리팹·테스트/데모 플레이어·모션/Animator·입력 자산·빌드 씬 목록 등 85개 기존 자산의 해시 동일. 전달 파일 30개 기록.

자동 기능 검수와 결과 화면을 확보했습니다. 사용자의 메인 Unity에서 직접 조작감을 평가한 수동 플레이 결과는 아직 없습니다. 기존 빌드 씬 목록과 시작 씬을 교체하지 않았습니다.
