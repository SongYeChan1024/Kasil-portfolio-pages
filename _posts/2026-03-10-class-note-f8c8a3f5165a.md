### Inverse Kinematics (IK) 개념

<b>FK (Forward Kinematics) vs IK (Inverse Kinematics)</b>  

- <b>FK (전진 운동학)</b>: 부모 조인트에서 자식 조인트 순서로 움직임 적용    
  - 어깨 → 팔 → 손 순서로 움직임
  - 현실 세계의 움직임 방식
- <b>IK (역 운동학)</b>: 자식 조인트 위치를 먼저 결정하고 부모 조인트가 맞춰서 변형   
  - 손(무기) 위치 결정 → 팔이 따라 움직임 → 어깨가 따라 움직임
  - 게임에서 무기 중심 애니메이션에 사용
  - OnAnimatorIK() 메서드로 구현  

<b>게임에서의 IK 활용</b> 

- 플레이어가 총기를 정확한 위치에 장착하도록 구현
- 어떤 애니메이션을 사용하든 손이 항상 총의 손잡이 위치 유지 

### 총기 시스템 구현

<b>총알 상태 관리</b>  

<ul>
<li>
Ready: 발사 준비 완료 상태
</li>
<li>
Empty: 탄창이 빈 상태  
</li>
<li>
Reloading: 재장전 중인 상태
</li>
<li>
State를 private property로 선언하여 클래스 내부에서만 상태 변경 가능  
</li>
</ul>

<b>탄약 관리 시스템</b>   

- 전체 탄약(ammoRemain): 100발
- 탄창 용량(magCapacity): 25발
- 현재 탄창 탄약(magAmmo): 탄창에 남은 탄약 수

<b>발사 시스템 구조</b> 

- <b>Fire 메서드</b>: 발사 조건 검사 및 신호 전달
- <b>Shot 메서드</b>: 실제 발사 처리 로직
  - Raycast를 이용한 충돌 감지  
  - LineRenderer로 총알 궤적 표시    
  - 충돌 대상에 IDamageable 인터페이스를 통한 데미지 전달   

<b>발사 간격 제어</b>   

- fireRate: 0.1초 (발사 간격)
- lastFireTime으로 마지막 발사 시간 추적
- Time.time을 사용하여 발사 간격 체크

### 재장전 시스템

<b>재장전 조건</b>    

- 전체 남은 탄약이 0이거나
- 현재 탄창 탄약이 25발 미만일 때
- 탄창이 가득 찬 경우 재장전 불가

<b>재장전 로직</b>    

- IEnumerator를 사용한 코루틴으로 구현
- reloadTime: 1.8초 대기
- yield return을 사용한 시간 지연 처리

<b>탄약 채우기 로직</b>      

- 탄창에 채워야 할 탄약 수 계산: magCapacity - magAmmo
- 남은 전체 탄약과 비교하여 적은 쪽으로 채움
- 예시: 탄창에 15발 필요, 전체 탄약 10발 남음 → 10발만 채움
- 탄창 충전 후 전체 탄약에서 해당 수량 차감
