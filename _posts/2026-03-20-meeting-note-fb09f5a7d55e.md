<b>게임 개발 팀 스크럼 회의</b> 2026-03-20

## 요약

### 액션 아이템

- [ ] 3-1 스테이지 사운드 작업 완료
- [ ] 공간 퍼즐 맵 제작 진행
- [ ] UI 기반 두 번째 퍼즐 구현 검토
- [ ] 각 스테이지 기획서 완성 후 팀 공유
- [ ] 디스코드를 통해 코치님께 업데이트 내역 제출
- [ ] 추가 사용 사이트 및 에셋 출처 기획서에 업데이트

### 진행 상황 공유

<b>퍼즐 및 맵 작업</b>

- 퍼즐 기능 완료, 맵 추가 작업 진행 중
- 퍼즐마다 바닥 표시를 통해 동작 방식 표시, 퍼즐 전 맵 작업 필요
- 3-1 스테이지 제작 진행: 공연장 진입 후 MBC와 대화하며 퍼즐 수행
- 스포트라이트와 악보가 생성되는 연출 계획
- 사운드만 추가하면 3-1 스테이지 완료 예정

<b>공간 퍼즐 (슬라이딩 퍼즐)</b>

- 기술 구현 완료, 맵 제작 단계로 진입
- 마을에서 별 5개를 수집하면 동굴 입구가 열리는 구조
- 미끄럼 퍼즐 수행 후 별을 제단에 배치하는 UI 퍼즐 추가 검토 중
- 플레이 타임 확보를 위해 추가 퍼즐 연계 고려

<b>사운드 퍼즐</b>

- 맵 곳곳에 사운드를 힌트로 활용한 퍼즐 구현
- 거리에 따라 음량이 변화하고 겹쳐 들리며 공간 잔향 효과 구현

### 기술 및 도구 정리

<b>사용 기술</b>

- 사운드 퍼즐: 거리 기반 음량 조절 및 공간 잔향 효과
- 슬라이딩 퍼즐: 플레이어 조작 비활성화 시스템
- 폴라로이드 이펙트: 2D 이미지를 3D 공간에 현실화하는 시스템, 위치 및 카메라 방향 감지

<b>사용 도구</b>

- 사운드 제작 사이트
- Mixamo
- Blender 5.0.1
- Photoshop 2026
- Unity Asset Store

### 기획서 제출

- 스토리 내용, 트렐리스, 사용 기술 정리 완료
- 각 팀원의 개별 기획서는 완성 후 추가 예정
- 디스코드를 통해 코치님께 제출

### 논의 사항

- 전체 스크럼 진행 방식 확인 필요
- 현재 각자 독립적으로 작업 중이며, 통합 결과물을 아직 확인하지 못함
- 스크럼 이후 팀 협업 방식 재조정 필요

## 기획서 정리(초안)

### 1) 에피소드 3 / 3-1 씬 목표

- 부제: ‘잃어버린 음악’, ‘끝내 들려주지 못한 음악’의 분위기를 <b>퍼즐(악보 조각 복원) + 사운드 연출</b>로 전달
- 플레이 흐름: 공연장 진입 → MBC와 대화(맥락/목표 제공) → 악보 조각 퍼즐 수행 → 연출로 마무리

### 2) 3-1 퍼즐(악보 조각 복원) 핵심 규칙

- 탐색으로 흩어진 악보 조각 수집
- 조각을 복원판/악보대에 배치(필요 시 회전/재배치)
- 정답/오답 피드백을 <b>사운드(부분 멜로디의 자연스러운 연결/끊김)</b>로 제공
- 완료 조건: 모든 조각이 올바른 위치/방향으로 정렬되고, 전체 멜로디가 끊김 없이 이어짐
- 완료 연출: 피아노 스포트라이트 → 악보 생성/복원 완료 → 풀버전 멜로디 재생 → 공간 활성화/스토리 진행

### 3) 공간 퍼즐(슬라이딩) 구조

- 기술 구현 완료 → 현재는 맵 제작 단계
- 목표 흐름: 마을에서 별 5개 수집 → 동굴 입구 오픈 → 미끄럼 퍼즐 진행
- 퍼즐 이후 연계안: 별을 제단에 배치하는 <b>UI 퍼즐</b> 추가 검토(플레이 타임 확보 목적)

### 4) 사용 기술/도구 & 출처 정리(기획서에 포함할 항목)

- 사운드 퍼즐: 거리 기반 음량 변화 + 공간 잔향 효과
- 슬라이딩 퍼즐: 퍼즐 중 플레이어 조작 비활성화
- 폴라로이드 이펙트: 2D 이미지를 3D 공간에 현실화(위치/카메라 방향 감지)
- 도구/사이트: mureka(사운드/음악 생성), TRELLIS(이미지→3D), HuggingFace(모델/데모), Audacity(편집), Blender 5.0.1, Photoshop 2026, Mixamo, Unity Asset Store
