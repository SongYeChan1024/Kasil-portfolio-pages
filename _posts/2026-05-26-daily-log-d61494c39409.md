## 오늘 한 일(요약)

- 게임 기획을 “상향성(새로운 것 창조)”과 “하향성(검증된 것 기반 차별화)” 관점으로 나누어 장단점/성공·실패 사례를 정리했다.
- 제페토 스튜디오에서 2D 의상 아이템 제작(포토샵 템플릿 편집→업로드→심사 제출) 흐름을 실습했다.
- Zepeto Studio 3D 아이템의 Unity 연동 흐름(FBX→Content 폴더→Accessory 카테고리 배치→Material 커스터마이징→Export as Zepeto)을 복습했다.
- 팀 프로젝트/취업 지원 관련 안내(프로젝트 운영 방식, 멘토 배정, 포트폴리오·면접 지원 가능)를 공유받아 앞으로의 진행 방향을 의식적으로 점검했다.

## 오늘 배운 것(정리)

### 1) 게임 기획: 상향성 vs 하향성

- 상향성 기획(Bottom-up)
  - “세상에 없던 경험”을 만드는 방식이라 성공 확률은 낮지만, 성공하면 파급력이 큰 형태.
  - 사례에서 배운 포인트: 얼리액세스/피드백 루프, ‘실패 경험을 서사에 편입’ 같은 구조적 차별화가 중요.
- 하향성 기획(Top-down)
  - 검증된 장르/규칙/IP를 기반으로 가져가되, UX/규칙/플랫폼에 대한 “독보적 한 방”이 있어야 성공.
  - 단순 모방은 실패하고, “익숙하지만 새로운 것”을 만들어야 한다는 기준을 다시 잡았다.
- UI/UX의 무게
  - 작은 UX가 시장을 뒤집을 수 있다는 사례들을 통해, 기능 구현 못지않게 ‘사용자 손맛/편의’가 핵심 경쟁력이라는 점을 재확인.

### 2) 제페토 스튜디오 2D 아이템 제작(포토샵 기반)

- 전체 흐름
  - 템플릿 다운로드(상의/티셔츠 등) → 포토샵에서 영역 선택/색 채우기/패턴·텍스트 추가 → 레이어 병합 → PNG 저장 → 제페토 스튜디오 업로드 → 태그/가격 설정 → 심사 제출
- 포인트
  - 업로드용 결과물은 레이어가 복잡하면 문제가 생길 수 있어서 “배경 이미지로 병합” 후 저장이 안정적.
  - 무료 계정 기준 심사 제출 개수 제한이 있으니, “완성도 체크→제출” 순서로 관리가 필요.

### 3) Zepeto Studio 3D 아이템 제작(Unity 연동)

- 전체 흐름
  - FBX를 Unity 프로젝트 Content 폴더에 배치 → Accessory(Headwear 등) 카테고리 설정 → Material로 색/텍스처 커스터마이징 → Export as Zepeto → 웹에서 업로드
- 주의사항
  - Unity 버전 호환(지정 버전 사용)과 프로젝트 경로(한글 경로 지양)가 안정성에 큰 영향을 준다.
  - Export는 상황에 따라 성공률이 들쑥날쑥할 수 있어, 기본 원칙(Play off) + 예외 케이스(필요 시 on)까지 염두.

## 이슈/메모

- 2D 아이템 제작은 “툴 사용”보다, 결과물을 실제로 판매/업로드 가능한 상태로 만드는 ‘마감/검수 루틴’이 중요하다는 느낌을 받았다.
- 기획 파트는 앞으로 팀 프로젝트에서 “차별화 포인트를 어디에 둘지” 결정할 때 기준점으로 써먹을 수 있을 것 같다.
