## 오늘의 목표

- [x] 벽 관통/충돌 관련 핵심 이슈 원인 파악 및 수정 방향 정리
- [x] 벽/콜라이더/AI 버그를 최우선 과제로 확정하고 팀 워크플로우(버그 문서화/취합) 정리
- [x] 씬 벽 오브젝트 <code>Wall</code> 레이어 정리 필요 사항 체크(레벨 디자인과 합 맞추기)

## 진행한 작업

1. <b>벽 관통/충돌 판정 디버깅 및 코드 수정 정리</b>[\[1\]]
   - 에너미 돌진이 벽 너머 좌표를 목적지로 잡는 문제를 <b>NavMesh.Raycast + Physics.SphereCast 기반 목적지 보정</b>으로 완화.
   - 에너미 공격 데미지 적용 직전에 <b>벽 차단 검사(Linecast 등)</b>를 넣어 벽 너머 공격 판정 가능성을 차단.
   - 플레이어 구르기 중 벽 모서리 관통 이슈를 <b>구르기 중에만 SweepTest/SphereCast 보정</b> 적용하는 방식으로 제한하여 부작용(문 근처 이동/상호작용 과차단)을 피함.
   - 총격이 벽/FenceCollider 등을 맞출 때 <code>target == null</code>인데 디버그 로그에서 <code>target.EntityFaction</code>을 참조해 발생하던 <b>NullReference</b>를 <code>target != null</code> 조건으로 방지.
2. <b>Addressables 누락 이슈 조치</b>[\[1\]]
   - 에픽 아티팩트 아이콘(<code>UI_Icon_Epic_FrozenClockwork</code>)이 JSON에는 있으나 Addressables 그룹에 없어서 로드 실패 → Default Local Group에 엔트리 추가.
3. <b>프로토타입 피드백 기반 버그 우선순위 회의 내용 정리</b>[\[2\]]
   - 콜라이더 뚫림/레이 관통/AI 문제를 <b>게임 무결성 이슈로 최우선 수정 대상</b>으로 확정.
   - 벽 에셋이 쿼드 2장 구조라 얇아서 문제가 커짐 → <b>3D 입체 벽(큐브+머티리얼도 가능)로 교체</b> + <b>AI 로직 조정/콜라이더 두께 증가 투트랙</b> 접근 합의.
4. <b>버그 리포트 문서화 워크플로우 합의 정리</b>[\[2\]]
   - 팀원별 버그를 <b>개별 문서화 → 취합/중복 제거/우선순위 분류</b>로 운영.
   - Notion 개발 항목에 <b>버그 리포트 페이지 신설</b>, Git 검수 폴더에 버그 리포트 md 업로드, 작업 브랜치 <code>0.2.4</code> 사용 확인.

## 이슈 / 막힌 점

- <b>벽 차단 로직이 제대로 먹으려면 씬의 벽 오브젝트/콜라이더가 </b><b><code>Wall</code></b><b> 레이어로 정리</b>되어야 함(코드만으로는 한계).[\[1\]]
- (리스크) 악의적 플레이(벽 뒤에서 몬스터 처치 등)로 밸런스 붕괴 가능성 → 레이 관통 방지/특정 위치 장시간 체류 시 튕김 처리 등 후속 검토 필요.[\[2\]]

## 결정 / 정리

- 해결 접근: <b>AI 로직 조정 + 콜라이더/벽 에셋 수정 병행(투트랙)</b>.[\[2\]]
