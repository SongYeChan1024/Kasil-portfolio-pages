<b>게임 기획서 작성 피드백 수업</b> 2026-06-02


## 요약


### 오늘 수업 핵심 요약

- <b>게임 기획서 작성 시 시놉시스/시나리오가 필수</b>이며, 아무리 간단한 게임이라도 스토리와 세계관이 있어야 유저 몰입이 가능하다
- 게임 기획서는 <b>조각상을 만들듯 전체를 먼저 완성한 후 계속 다듬는 방식</b>으로 작성해야 하며, 하나씩 완벽하게 끝내고 넘어가면 안 된다
- <b>기획의도</b>를 명확히 가져야 하며, 예술성/상업성/트렌드 등 자신만의 관점을 설명할 수 있어야 한다
- 게임 기획서의 기본 구조는 표지, 게임 개요, 게임 시스템, 시나리오/시놉시스 순으로 구성되며, 어제 제공한 샘플 기획서를 참고하여 작성해야 한다
- IP 라이선스는 매출의 3\~15%를 로열티로 가져가며, 계약금도 상당히 높다는 점을 알아야 한다 (나루토 IP 한국판 5년: 50\~80억)

---

### 주요 개념 정리

- <b>게임 기획서 구조</b>
  - 설명: 표지 → 게임 개요 → 게임 시스템 → 시나리오/시놉시스 순서로 구성
  - 예시: 어제 배포한 "The Band" 게임 기획서 샘플 참조
  - 사용되는 상황: 포트폴리오, 면접, 실제 게임 개발 기획 단계
  - 헷갈릴 수 있는 점: 게임 기획서는 한번에 완성하는 것이 아니라 계속 수정/보완하는 문서
- <b>시놉시스 (Synopsis)</b>
  - 설명: 게임의 배경, 스토리, 세계관을 요약한 내용. 네이버 영화 정보의 줄거리 수준으로 작성
  - 예시: 마리오(공주 구출), 로스트아크(아크 쟁탈전), 스페이스 채널 5(외계인과 댄스 대결)
  - 사용되는 상황: 유저 몰입도 향상, 게임의 존재 이유 설명
  - 헷갈릴 수 있는 점: 시스템만 있고 시나리오가 없으면 유저가 몰입하기 어려움
- <b>기획의도</b>
  - 설명: 왜 이 게임을 만들려고 하는지에 대한 개발자의 철학과 목표
  - 예시: 힐링 게임 → "사람들에게 위안과 안식을 주고 싶음", 메타버스 트렌드 → "현재 트렌드에 맞는 콘텐츠 제공"
  - 사용되는 상황: 면접 시 가장 많이 받는 질문
  - 헷갈릴 수 있는 점: 단순히 "재미있게 만들고 싶다"가 아니라 예술성, 상업성, 대중성, 트렌드 등 구체적 관점 필요
- <b>IP 라이선스 계약</b>
  - 설명: 유명 IP(지적재산권)를 게임에 사용하기 위한 계약. 계약금 + 매출 로열티 방식
  - 예시: 나루토 IP 한국판 5년 계약 50\~80억원, 매출의 3\~15% 로열티 추가. KBO 1년 120\~150억, FIFA 4천억
  - 사용되는 상황: 기존 IP의 팬층을 활용하여 게임 성공 가능성 높이기
  - 헷갈릴 수 있는 점: IP 계약금만 내면 끝이 아니라, 매출이 발생하면 계속 로열티를 지불해야 함

### 수업 흐름별 정리

### 1. 게임 기획서 제출 및 피드백 안내

- 어제 만들었던 메타버스 관련 게임 기획서를 피코에 제출
- 맞춤법, 띄어쓰기, 오타는 더 이상 언급하지 않으며, 크리티컬한 부분만 피드백 예정
- 참석자: 우성혁, 송예찬, 김남희, 장수영 등

### 2. 개별 기획서 피드백

- <b>우성혁</b>: "안 메타버스" - 타이틀 의미 설명 필요, 시놉시스 추가 필요
- <b>송예찬</b>: 표지 그래픽이 실제 제페토 구현 결과물과 차이가 클 수 있으니 기대감 조절 필요. 전체적인 목차 구성은 잘함. 시나리오/스토리 추가 필요
- <b>김남희</b>: 고양이 마리오 컨셉. 고양이를 그대로 쓰면 따라한 느낌이 강하므로 캐릭터를 독창적이거나 개그 요소를 가미할 것 권장
- <b>장수영</b>: 대작 프로젝트로 보이나 3개월은 너무 긴 기간. 프로토타입 수준으로 가능성만 보여주는 것을 권장

<code>중요:</code> 게임 기획서는 시스템뿐 아니라 <b>시나리오/시놉시스가 반드시 필요</b>

### 3. 게임 기획서 작성 원칙

- 게임 기획서는 <b>전체를 먼저 완성한 후 계속 다듬는 방식</b>으로 작성
- 조각상 제작처럼: 얼굴 100% 완성 → 몸 완성이 아니라, 전체 윤곽 → 세부 다듬기
- 한 부분을 완벽하게 끝내고 넘어가지 말고, 모르더라도 끝까지 적고 계속 수정

### 4. 시나리오/시놉시스의 중요성

- 프로그래머들은 시스템/연동에 집중하지만, <b>시나리오가 없으면 유저 몰입이 어려움</b>
- 네이버 영화 정보 수준의 간단한 시놉시스라도 작성 필요
- 예시: 마리오(공주 구하기), 로스트아크(아크 쟁탈), 스페이스 채널 5(외계인과 댄스 대결)
- "The Band" 기획서에도 밴드 결성 이유와 목표 달성 과정이 20\~30페이지 시나리오로 작성됨

### 5. 기획의도의 중요성

- 면접 시 경력자들이 가장 많이 묻는 질문: <b>"기획의도가 무엇인가?"</b>
- 예술적 승화, 상업성/대중성, 트렌드 반영 등 자신만의 관점 필요
- 예시: 힐링 게임 → "전투가 아닌 위안과 안식 제공", 전체이용가 → "대중적 접근성"

### 6. IP 라이선스 사례 연구

- <b>나루토 IP + 클래시 오브 클랜 게임 기획서</b> 사례 공유
- 클래시 오브 클랜의 북유럽 그래픽 때문에 안 하는 유저들을 위해 나루토 IP 활용 기획
- 나루토의 마을 간 대립/동맹 구조가 클래시 오브 클랜 시스템과 잘 맞음
- 실제로 개발 단계까지 갔으나 나루토 IP를 못 받아와서 중단됨

### 예시와 활용 사례

- <b>예시 1: IP 라이선스 비용</b>
  - 상황: 나루토 IP를 한국에서 5년간 사용
  - 설명: 계약금 50\~80억원 + 매출의 3\~15% 로열티
  - 왜 이 예시를 사용했는지: IP 사용의 현실적 비용을 이해시키기 위함
- <b>예시 2: KBO, FIFA IP</b>
  - 상황: 마구마구(KBO) 1년 120\~150억, 피파(FIFA) 4천억
  - 설명: IP 비용은 매우 높지만 그만큼 수익성이 있다는 의미
  - 왜 이 예시를 사용했는지: 게임 산업에서 IP의 가치 이해
- <b>예시 3: 기획서 100페이지 분량</b>
  - 상황: 나루토 IP 게임 기획서
  - 설명: 전문적인 게임 기획서는 상당한 분량과 디테일 필요
  - 왜 이 예시를 사용했는지: 기획서 작성의 완성도 기준 제시

### 헷갈릴 수 있는 부분

- <b>헷갈리는 개념</b>: 게임 기획서를 처음부터 완벽하게 작성해야 한다
- <b>헷갈리는 이유</b>: 문서 작성 시 보통 앞부분을 완성하고 뒷부분으로 넘어가는 습관
- <b>구분 방법</b>: 수능처럼 1번부터 200번까지 모르더라도 일단 풀고, 조각상처럼 전체 윤곽을 먼저 잡은 후 계속 다듬기
