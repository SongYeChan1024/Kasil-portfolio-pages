## 진행한 작업

### 1. 문서 위키와 GitHub Pages

- MkDocs Material 기반 웹 뷰어와 GitHub Actions 자동 배포를 구성했습니다.
- 주요 README에 Quick Links, 상태 표와 필요한 Mermaid 흐름도를 추가했습니다.
- GitHub Pages 게시 방식을 Actions로 설정하고 공개 사이트의 정상 응답을 확인했습니다.
- 문서 구조 작업을 커밋 <code>be71088</code>로 반영했습니다.

### 2. 작성자 표기 정리

- 공개 로드맵의 Revision History에 <code>Codex</code>가 작성자로 표시된 문제를 확인했습니다.
- 79개 Markdown 문서의 작성자 표기를 <code>송예찬</code>으로 통일했습니다.
- AI·도구 이름을 작성자 칸에 기록하지 않도록 문서 규칙을 추가했습니다.
- 작성자 정리 작업을 커밋 <code>4502c0f</code>로 반영했습니다.

### 3. 튜토리얼 아이템 구현 가안

- 코어 없이 기본 공격을 학습할 임시 무기 <code>낡은 부지깽이</code>를 제안했습니다.
- 첫 장비형 파츠는 <code>낡은 빗자루</code>, 첫 스킬은 정기를 사용하는 <code>쓸어치기</code>로 구성했습니다.
- 첫 코어는 <code>낡은 정기의 혼 코어 [근접]</code>, 크기 <code>1×1</code>, 초기 자원 <code>0</code>, 고정 시드 결과를 사용합니다.
- 소형 주머니, 낡은 방어판, 응급 회복제, 코어 활성제를 튜토리얼 최소 파츠 후보로 정리했습니다.
- 기억 잔재, 도구 파편, 영혼 결박 파편과 월도 잔해의 획득 역할을 구분했습니다.
- 제안 수치는 첫 플레이 테스트를 위한 가안이며 최종 밸런스로 확정하지 않았습니다.

### 4. 드롭과 데이터 파이프라인

- 튜토리얼은 정식 드롭 구조를 사용하되 <code>TutorialOverrides</code>에서 첫 필수 획득품을 보장합니다.
- Excel은 아이템·코어·스킬·옵션·드롭 테이블의 정적 정의와 밸런스 수치를 관리합니다.
- JSON은 Unity가 읽는 생성 결과이며, 실제 드롭된 개별 <code>ItemInstance</code>는 런타임과 세이브 데이터에서 관리합니다.
- Unity 프리팹·아이콘·VFX는 JSON 경로 대신 에셋 키와 ScriptableObject 카탈로그로 연결합니다.
- 변환 단계에서 ID 중복, 잘못된 참조, 수치 범위, 확률과 자원 호환을 검증합니다.

### 5. 실제 Unity 구현 준비

- 실제 프로젝트에서 URP, Input Actions, <code>GameplayInputReader</code>와 <code>TestMap</code>이 준비된 상태를 확인했습니다.
- 플레이어 이동·카메라·회피·상호작용은 아직 구현되지 않았습니다.
- 첫 완료 목표를 <code>우클릭 지점 판정 → 장애물 우회 이동 → 아이소메트릭 카메라 추적</code>으로 정했습니다.
- 아이템 데이터는 플레이어 조작 기반이 완성된 뒤 실제 플레이로 검증하며 연결합니다.

### 6. 오늘 기록과 배포

- Git 저장소에 2026-08-17 데일리 로그와 상세 개발일지를 작성했습니다.
- 프로젝트 관리 인덱스와 MkDocs 탐색 메뉴에 두 기록을 연결했습니다.
- 기록 작업을 커밋 <code>adc5d6d</code>로 <code>main</code>과 작업 브랜치에 푸시했습니다.
