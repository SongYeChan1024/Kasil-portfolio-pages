- [ ] JSON 파일 생성 및 적용 방법 학습

### 프로젝트 진행 상황

- 어제 공유한 내용으로 전반적인 진척 상황은 팀원들에게 전달됨 
- 송해찬님이 보내준 AI 대화 관련 문서를 테이블화하는 작업 진행 중 
- 수업 강의 영상을 참고하여 AI 대화 시스템 구현 중 

### AI 대화 시스템 개발

- 대화 툴을 만들어 텍스트 입력 방식보다 에디터를 통해 직접 만들 수 있도록 할 예정 
- 데이터 테이블이 필요하며, 어제 대략적으로 작성한 내용을 팀원들에게 공유함 
- AI로 모든 대화를 생성하면 문제가 발생할 수 있어, 고정 대화에 AI 성격 변주를 주는 방식 채택 
- 성격 타입: 소녀, 화가, 음악가, 중심 존재 4가지 베이스 성격에 3가지 타입 조합 
- JSON 파일을 리소스에 넣어 스크립트에서 참조하는 방식 검토 중 

### 데이터 구조 설계

- 핵심 테이블과 성격/힌트 생성 테이블로 구분 
- 성격 키워드를 모두 작성하여 데이터 테이블 구성 예정 
- 엔딩 타입, 클리어 상태 등 일부 항목은 Boolean 값으로 변환 가능 
- 변수가 약 70개, 연결까지 고려하면 수백 개 수준의 복잡도 

### 게임 시스템 구조

- 스테이지별 미니엔딩과 최종 진엔딩/노멀엔딩 시스템 
- 퍼즐 점수 계산 테이블에 따라 점수 합산 후 각 에피소드마다 미니엔딩 분기 
- 퍼즐, 대화, 감정 재구성 세 가지 요소로 구성 
- 랜덤 생성 방식 활용 

### 현재 구현 상황

- 대화창 열기 기능 구현 완료 (2번 키로 실행) 
- 스크립터블 오브젝트에 성격, 첫인상말, 프롬프트 설정 
- AI 성격 상태(예: Angry)에 따른 대화 생성 테스트 중 
- 키워드 기반으로 AI에 추가 입력 가능 

### 미정/검토사항

- 스테이지 2, 3 NPC 이름 미정 (루나, 엘리오/엘리옷 후보) 
- 현재 구현 수준에서 더 발전시킬지 만족할지 고민 중 
- 프로젝트 기간이 남아있어 한 번만 완성하면 됨 

### 기타

- 데이터 테이블의 복잡도로 인해 팀원들이 부담감 표현 
- 처음 계획보다 범위가 확대되어 놀라움 
- 점심 식사 후 오후 스크럼 예정
