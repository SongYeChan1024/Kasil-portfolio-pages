## 진행한 작업

### 1. 에르고스퀘어 종합 기획서 작성

- 과거 <code>지구-164991</code> 메인 기획서의 장 구성을 참고하되 현재 확정된 시스템만 다시 반영했습니다.
- 게임 개요, 목표 사용자, 세계관, 핵심 플레이, UI, 맵, 개발 전략과 확장 방향을 하나의 문서로 연결했습니다.
- 메인 시나리오와 TUT-00\~08 튜토리얼 장면을 서사 본문과 기획 해설로 분리했습니다.
- 링크된 세부 시스템 문서가 실제 수치와 예외 처리의 기준이라는 SSOT 경계를 유지했습니다.

### 2. 문서 충돌 정리

- <code>Space 회피</code>를 <code>Space 정신 집중</code>으로, 기존 고정 직업을 <code>근접·투사·영역 전개 계통</code>으로 정리했습니다.
- 월도와 어둑시니를 합친 안은 채택하지 않고 튜토리얼 보스를 월도로 유지했습니다.
- 앵커 게이트 5개와 특정 신화 배치는 확정값이 아닌 후보로 되돌렸습니다.
- 서울 지하상가는 대체 도입 배경 후보로 남기고 현재 동굴형 튜토리얼 내부와 분리했습니다.
- 메타버스 거래·UGC·라이선스 경제는 현재 개발 비목표로 분류했습니다.

### 3. 세계관 전체 스토리 작성

- 이면의 상호 관측, 최초 게이트 침공, 대분기와 번호 지구 탄생부터 서술했습니다.
- 정본 지구의 정본화, 잠복 게이트 폭주, 에르고스퀘어 발현과 월도 사건을 연결했습니다.
- 허브 성장, 앵커 귀속, 최후의 게이트와 번호 지구 독립 결말까지 하나의 이야기로 정리했습니다.
- 이면의 정체와 공존 가능성 등 의도적으로 남길 장기 미스터리를 별도 표시했습니다.

### 4. 클릭형 세계관 용어집 구축

- 번호 지구, 지구 자아, 대분기, 정본화, 게이트, 이면, 현현체와 설계자 등 핵심 용어를 정리했습니다.
- 각 용어에 짧은 정의, 플레이어 공개 시점, 주의·미확정 사항과 상세 기준 문서를 연결했습니다.
- 전체 스토리에서는 같은 단어를 반복 링크하지 않고 장이나 문단의 첫 등장 위주로 연결했습니다.

### 5. 문서 웹 구조 갱신과 검증

- 프로젝트 개요, 세계관 인덱스와 MkDocs 내비게이션에 새 문서를 추가했습니다.
- 종합 기획서의 로컬 링크 26개를 확인했습니다.
- 세계관 전체 스토리와 용어집의 문서 링크 69개를 확인했습니다.
- MkDocs 준비 스크립트를 실행해 생성 소스와 모든 내비게이션 대상이 존재하는 것을 확인했습니다.

## 오늘의 결정

- 종합 기획서는 전체를 이어 읽는 입구로 사용하고 세부 규칙은 기존 시스템 명세를 우선합니다.
- 세계관 문서는 <code>전체 스토리 → 용어집 → 상세 기준 문서</code>의 3단 구조로 운영합니다.
- 용어 링크는 모든 반복 단어가 아니라 각 장 또는 문단의 첫 등장에 적용합니다.
- 안티그래비티의 새 아이디어가 기존 기준과 충돌하면 자동 채택하지 않고 <code>후보</code>, <code>TBD</code> 또는 <code>비목표</code>로 분리합니다.
- 이면의 정체와 인간화 성공 여부는 본편에서 전부 설명하지 않는 장기 미스터리로 유지합니다.

## 발생한 문제와 해결

- <b>오래된 종합 기획서와 최신 시스템 명칭이 충돌함</b> → 예전 문서는 형식만 참고하고 현재 세부 기준 문서를 우선해 통합했습니다.
- <b>안티그래비티 초안에서 튜토리얼 장소·보스·앵커 수가 확정처럼 작성됨</b> → 현재 기준과 대조하여 대안 또는 TBD로 명시했습니다.
- <b>세계관 본문에 링크를 과도하게 넣으면 가독성이 떨어짐</b> → 첫 등장만 용어집으로 연결하고 용어집에서 세부 문서로 다시 이동하게 했습니다.
- <b>로컬 환경에 MkDocs 실행 패키지가 없음</b> → HTML 빌드 대신 준비 스크립트와 생성된 내비게이션 대상 검증을 완료했습니다.
