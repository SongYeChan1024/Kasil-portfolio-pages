- Photon PUN2를 연동해 멀티플레이 개발 환경을 구성하고, <b>로비 UI / 방 목록 / 스폰 프리팹</b> 등 기본 흐름을 정리했다.
- Input System 기반 탱크 입력 처리, Rigidbody 기반 이동/회전, 궤도 텍스처 애니메이션을 구현하며 <b>전투 오브젝트 기본 동작</b>을 실습했다.

## 오늘 진행한 내용(상세)

### 1) 씬/리소스 정리

- 전투 씬을 중심으로 “어떤 오브젝트/리소스가 어디에 있고, 어떤 역할인지”가 보이도록 구조를 정리했다.
- 탱크/헬기/이펙트 등 주요 리소스를 분류해 배치하며, 이후 작업(스폰/네트워크 동기화/이펙트 재사용)을 위한 기반을 만들었다.

### 2) Photon PUN2 멀티플레이 환경 구성(기초)

- Photon PUN2 연동으로 멀티플레이 개발 환경을 준비했다.
- 로비 UI, 방 생성/방 목록(룸 리스트), 그리고 스폰에 사용할 프리팹 구성을 정리해 “접속 → 로비 → 룸 입장 → 스폰” 흐름을 잡았다.

### 3) 탱크 기본 조작/움직임 구현

- Input System으로 탱크 입력을 처리하는 흐름을 구성했다.
- Rigidbody 기반으로 이동/회전 동작을 실습하며 “물리 기반 이동”의 기본 느낌을 확인했다.
- 궤도(트랙) 텍스처 애니메이션을 적용해 움직임 시각 피드백을 보강했다.

## 배운 것(개념/정리)

- 멀티플레이는 “네트워크 코드”만의 문제가 아니라, <b>씬/프리팹 구조 + UI 흐름(로비/룸) + 스폰 설계</b>가 먼저 잡혀야 작업이 빨라진다.
- 전투 오브젝트(탱크)도 입력→물리→비주얼(트랙 애니메이션)까지 연결되면, 작은 구현이라도 “게임처럼” 보이기 시작한다.
