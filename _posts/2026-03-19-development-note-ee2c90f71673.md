# 1. 퍼즐 목표

소리가 끊긴 공연장 공간에서 흩어진 악보 조각들을 수집하고, 올바른 순서와 위치에 맞게 복원하여 하나의 멜로디 라인을 완성하는 퍼즐이다.

플레이어는 끊어진 악보를 복원하며 멈춰버린 노래의 일부를 되찾고, 최종적으로 완성된 선율을 통해 기억의 흐름을 이어 붙이게 된다.

퍼즐 완료 시 악보는 하나의 완전한 형태로 복원되며, 해당 멜로디가 재생되고 공연장 공간의 일부가 활성화된다.

# 2. 퍼즐 진행 방법

## 2-1. 퍼즐 구성

- 플레이어는 퍼즐 공간에 진입하면 붕괴된 공연장 내부를 탐색한다.
- 공간 곳곳에는 찢어진 악보 조각들이 흩어진 상태로 배치되어 있다.
- 플레이어는 각 조각 근처에 다가가면 희미하게 들리는 멜로디를 통해 조각의 존재를 파악할 수 있다.
- 수집한 악보 조각은 중앙의 악보 복원판 또는 악보대에 배치할 수 있다.
- 조각은 올바른 위치와 순서에 맞게 배치되어야 한다.
- 일부 조각은 방향이 뒤집혀 있거나 위치가 헷갈리도록 구성될 수 있다.
- 모든 조각이 정답 위치에 배치되면 하나의 악보가 완성되며 퍼즐이 완료된다.

## 2-2. 플레이어 상호작용

- 플레이어는 이동을 통해 공연장 내부를 탐색한다.
- 공연장 진입 후 <b>MBC(NPC)와 대화</b>를 통해 퍼즐의 목표/배경을 안내받고 퍼즐을 시작한다.
- 악보 조각 근처에 접근하면 해당 조각의 <b>멜로디 일부(사운드 힌트)</b>가 재생된다.
  - 거리(근접도)에 따라 음량이 변화하고, 여러 조각이 근처에 있으면 소리가 겹쳐 들릴 수 있다.
  - 공간 잔향(리버브) 느낌을 더해 ‘소리가 끊긴 공연장’ 분위기를 강화한다.
- 플레이어는 조각을 획득한 뒤 복원판에 올려놓을 수 있다.
- 조각 배치 시
  - 정답: 해당 부분 선율이 자연스럽게 이어져 ‘맞춰지고 있다’는 확신을 준다.
  - 오답: 어색하거나 끊긴 음(불협/단절)을 재생해 재배치를 유도한다.
- 필요 시 조각의 회전 또는 재배치를 통해 정답 위치를 다시 맞출 수 있다.

# 3. 퍼즐 구성

## 3-1. 공간 구조

- 퍼즐 공간은 <b>소리가 끊긴 공연장</b> 콘셉트로 구성된다.
- 중앙 무대에는 복원 대상이 되는 악보판 또는 악보대가 배치된다.
- 객석, 무대 뒤편, 조명 근처 등 공연장 내부에 악보 조각들이 흩어져 있다.
- 공간 전체에는 희미한 조명, 먼지, 잔향 효과 등을 통해 멈춰버린 공연장의 분위기를 연출한다.

## 3-2. 오브젝트 구성

- 하나의 퍼즐은 하나의 완성된 악보를 중심으로 구성된다.
- 악보는 6\~8개의 조각으로 분해되어 있으며, 각 조각에는 일부 음표와 오선지가 포함된다.
- 조각들은 서로 다른 위치에 배치되고, 일부는 회전된 상태로 존재할 수 있다.
- 복원판에는 각 조각이 들어갈 위치를 암시하는 슬롯 또는 희미한 윤곽선이 표시될 수 있다.

## 3-3. 악보 조각 복원 구조

- 각 악보 조각은 완성된 악보의 일부분을 담당한다.
- 플레이어가 조각을 복원판에 배치하면 해당 부분의 멜로디가 활성화된다.
- 정답 위치에 배치된 조각은 서로 자연스럽게 이어지며 하나의 선율 흐름을 만든다.
- 잘못된 위치에 배치된 조각은 시각적으로도 어색하고, 사운드도 불완전하게 들리도록 구성한다.
- 모든 조각이 올바르게 연결되면 완성된 악보와 완성된 멜로디가 동시에 드러난다.

## 3-4. 퍼즐 판정 조건

퍼즐은 아래 조건을 만족할 경우 완료된다:

- 모든 악보 조각이 복원판에 배치되어 있다.
- 각 조각이 정답 위치에 맞게 배치되어 있다.
- 회전이 필요한 조각은 올바른 방향으로 정렬되어 있다.
- 전체 멜로디가 끊김 없이 정상적으로 이어진다.

## 3-5. 퍼즐 완료 결과

- 흩어진 악보 조각들이 하나의 완성된 악보로 복원된다.
- 완성된 멜로디가 공연장 전체에 재생된다.
- 무대 조명 또는 공간 연출이 활성화되며 공연장이 잠시 되살아난다.
- 다음 기억 조각 또는 스토리 진행 요소가 해금된다.
- 플레이어는 멈춰버린 노래의 일부를 되찾았다는 서사적 진전을 얻게 된다.

# 4. 연출 요소

- 퍼즐 진행 중:
  - 바닥 표시/윤곽선 등으로 ‘어디에 놓여 있는지’ 최소한의 암시를 제공할 수 있다.
  - 조각 근처 접근 시 사운드 힌트가 점진적으로 커지며 탐색을 유도한다.
- 퍼즐 성공 시:
  - <b>피아노(또는 무대 중심 오브젝트)에 스포트라이트</b>가 비친다.
  - 흩어진 악보 조각이 빛나며 하나의 형태로 정렬되고, <b>완성 악보가 생성/복원</b>된다.
  - 끊겨 있던 멜로디가 자연스럽게 이어지며, 최종적으로 <b>풀버전 멜로디</b>가 재생된다.
  - 공연장 조명이 점차 밝아지며 무대(공간 연출)가 활성화된다.
  - 조각 주변에 음표 파티클/잔향 이펙트가 발생한다.
  - 음악가 NPC의 반응 대사 또는 회상 연출이 재생될 수 있다.

# 5. 핵심 시스템 요약

- <b>탐색 기반 악보 조각 수집 퍼즐</b>
- <b>악보 조각 배치 및 회전 정렬 시스템</b>
- <b>조각별 멜로디 힌트 재생(거리 기반 음량 + 공간 잔향)</b>
- <b>정답/오답 사운드 피드백(자연스러운 연결 vs 끊김/불협)</b>
- <b>부분 선율 복원 → 전체 멜로디 완성(풀버전 재생) 구조</b>
- <b>퍼즐 결과가 공연장 변화 및 스토리 진행과 연결됨</b>

# 6. 구현/연동 메모(업데이트)

## 6-1. 3-1 씬 완료 조건(개발 체크)

- 사운드 작업을 레벨에 최종 적용하고(배치/볼륨/거리감) 플레이 루프에서 이상 없는지 확인
- ‘악보 조각 전부 수집’ 트리거로 성공 연출(스포트라이트 → 악보 생성 → 풀버전 재생)이 정상 동작

## 6-2. 제출/공유 체크리스트

- 각 스테이지 기획서 완성 후 팀 공유
- 사용 사이트/에셋 출처(사운드 제작 사이트, Mixamo, Blender, Photoshop, Unity Asset Store 등) 기획서에 업데이트
- 디스코드로 코치님께 업데이트 내역 제출(완료 항목 + 증빙 자료)
