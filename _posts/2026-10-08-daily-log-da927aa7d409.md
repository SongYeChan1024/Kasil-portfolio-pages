## 오늘의 목표

빗자루 조합 스킬의 공통 쿨타임과 다음 타 대기 시간을 분리하여, 동일 스킬이 1·2·3타로 진화하는 연계 규칙을 구현한다.

## 완료한 작업

### 최종 연계 규칙

- 1·2·3자루 모두 공통 기본 쿨타임 10초. Q1 승인부터 계산하며 기존 HASTE 강화 배율은 유지.
- Q1 승인부터 Q2 대기 6초. 3단계에서 Q2를 승인하면 그 시점부터 Q3 대기 6초를 새로 시작.
- Q2·Q3에 개별 쿨타임을 추가하지 않으며, Q1에서 시작한 쿨타임을 다시 시작하지 않음.
- 마지막 해금 타격 또는 다음 타 대기 만료 시 Q1 대기로 복귀. 남은 쿨타임이 있으면 새 Q1은 사용 불가.
- 쿨타임이 먼저 끝나도 유효한 연계가 남아 있으면 다음 입력은 Q3. Q1으로 건너뛰지 않음.
- 선입력 예약·실패 입력·명중·모션 종료로 대기 제한을 갱신하지 않음. 입력이 없어도 자동 만료.

### 시간 예시

- 강화 없이 0초 Q1 후 입력하지 않으면 6초에 순서 초기화, 쿨타임 4초 남음.
- 0초 Q1, 5초 Q2라면 Q3 대기는 11초까지. 공통 쿨타임은 10초에 종료.
- 이 흐름에서 10.5초 Q3를 사용하면 회복 후 새 Q1 가능. Q3 전용 쿨타임 없음.

### 코드·데이터·명세

- PrototypeSkillUseController의 다음 타 대기 기한을 직전 타 승인 시 갱신하도록 수정. 개체 ID별 쿨타임과 분리.
- 엑셀 Stages의 기본 쿨타임을 모두 10초로 통일하고, 타별 대기 6초의 설명을 정리.
- 기존 엑셀 서식·시트·입력 검증을 유지하며 의도한 6개 셀만 변경. JSON 재생성과 최초 엑셀 생성 도구도 일치시킴.
- 종합 기획서와 조합 성장 명세를 최종 규칙으로 보완. 10월 7일의 초기 수치는 과거 작업 이력으로 유지.
- 기존 피해·자원 비용·모션·돌진·유대·성장 보존은 유지. 새 원화나 맵 작업은 하지 않음.

## 문제와 해결

전체 연계를 Q1부터 고정 6초로 제한하면 늦게 사용한 Q2 이후 Q3 입력 시간이 짧아진다. Q2 승인 때 다음 타 대기만 새 6초로 갱신하고, 공유 쿨타임은 Q1 기준으로 유지하도록 수정했다. 중간의 고정 6초 구현은 최종 사양이 아니며 v3 규칙으로 대체했다.

## 검증 결과

- Unity 네이티브 Play 성장 검증 104항목 통과. 별도 검증 복제본의 그래픽 없는 모드에서 실행.
- 엑셀 변환 단위시험 13개 통과. 기록 마감 시 재실행 통과.
- Excel 원본과 생성 JSON 일치 검사 통과.
- Q1 단독 만료 후 약 4초 잔여, 늦은 Q2의 새 6초, 쿨타임 종료 중 Q3 대기 유지, 늦은 Q3 후 새 Q1, 실패 입력의 기한 비갱신과 자동 만료 확인.
- 원본 튜토리얼 씬 두 개의 SHA256 유지 확인. 임시 복제본과 LayoutBackups는 커밋에서 제외.
- 복제본 Unity Search 초기화 예외는 관찰됐으나 게임 코드 컴파일 오류 없이 검증 완료. 화면·실제 조작감과 독립 실행 빌드는 별도 확인.
