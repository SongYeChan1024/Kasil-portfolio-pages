## 기본 정보

- 날짜: 2026-03-06
- 프로젝트: Unity Runner

## 오늘 한 일(요약)

- Unity Runner 2D 러너 게임 기획서 초안 작성 및 요구사항 정리
- 배경 Sky 무한 반복 이동 구현 시도/정리
- 레거시 입력(<code>Input.GetMouseButtonDown/Up</code>)을 New Input System으로 변경
- SpriteAtlas를 활용해 스프라이트 기반 애니메이션 만드는 방법 학습

## 구현한 것

- 배경화면 Sky 무한 반복으로 움직이기(구현/검증 메모)
- 입력 시스템 변경: 레거시 → New Input System

## 배운 것(개념/정리)

- FSM(유한 상태 머신): 상태(State)에서 조건에 의해 다른 상태로 전이하는 구조

## 이슈/버그

- 내용: 배경 무한 반복 동작은 정상. 다만 코드 구조를 더 깔끔하게 리팩터링(가독성/재사용성 개선)하려고 참고 자료를 확인함.
- 다음 액션: 현재 구현과 참고 코드 비교해서 중복/매직넘버 제거, 컴포넌트 분리(예: <code>BackgroundScroller</code>), 변수/메서드 네이밍 정리

## 내일 할 일

- 게임 흐름(시작-진행-실패-재시작) 정리
- UI 구성(점수/최고점수/일시정지) 초안 작성
- 난이도 증가 방식(시간/거리 기반 속도 증가 등) 결정
- 사운드/아트 리소스 목록 정리
