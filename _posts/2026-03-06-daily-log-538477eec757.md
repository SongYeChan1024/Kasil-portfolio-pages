## 배운 것(개념/정리)

- Canvas Scaler
  - Constant Pixel Size: 디바이스 해상도에 따라 UI 크기/간격이 의도와 달라질 수 있음
  - Scale With Screen Size: 다양한 해상도에서도 비율/배치를 안정적으로 유지
  - Reference Resolution을 640x360으로 두고 UI를 배치하면 배율 변화에 자동 대응
- Unity 생명주기
  - Awake → OnEnable → Start → FixedUpdate → Update → LateUpdate
  - Awake/Start는 1회 호출, OnEnable은 활성화될 때마다 호출(오브젝트 풀링에서 특히 중요)
- Input System 메모
  - Fire 액션에 다양한 입력(마우스/터치/패드 등) 바인딩 가능
  - 임시로 마우스 다운 처리한 “재시작”을 추후 OnFire로 교체 예정

## 이슈/버그

- 원인/가설: Constant Pixel Size 사용 시 화면 크기 변화에 대응이 약함
