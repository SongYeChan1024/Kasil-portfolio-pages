## 기본 정보

- 날짜: 2026-05-14
- 프로젝트: ThunderBolt (Unity) — Apache AI(순찰/탐색/공격) 트러블슈팅 & 주석/인코딩 정리
- 작성자: 작성자

## 오늘 한 일(요약)

- 패트롤 포인트가 5개만 잡히던 문제를 찾아 <b>PatrolPoint 순회 로직의 오프바이원(반복문 조건) 버그</b>를 수정했다.
- Apache AI의 순찰→탐색→추적→공격 흐름을 점검하고, <b>탐지 거리/공격 거리 분리</b>와 <b>재탐색 로직</b>을 보완했다.
- 공격(발사) 쿨타임 처리 순서를 정리해 <b>실제 발사가 되도록</b> 수정했다.
- <code>ApacheAI.cs</code>에 이해를 돕는 주석을 추가했고, <code>ApacheCrash.cs</code>의 깨진 한글 주석/로그를 의미 기준으로 복구했다.
- 스크립트 수정 후 <b>빌드 확인</b>까지 진행했다.

## 오늘 진행한 내용(상세)

### 1) PatrolPoint 5개만 생성되던 문제

- 현상: 패트롤 포인트가 끝까지 잡히지 않고 5개만 잡힘
- 원인: 마지막 자식 오브젝트가 순회에서 제외되는 반복문 조건(오프바이원)
- 해결: 루프 범위를 정상 범위로 수정하여 누락 없이 순회되도록 처리

### 2) Apache AI: 타깃 탐색/재탐색 및 상태 전환 정리

- 현상: 탱크를 한 번만 찾고 이후 재탐색하지 않아, 상황이 바뀌면 타깃을 놓침
- 원인: 시작 시 1회 탐색 구조 + 타깃 참조 저장 방식이 부정확
- 개선:
  - 타깃을 지속적으로 갱신/재탐색할 수 있도록 보완
  - <b>탐지 거리(추적 시작)</b> 와 <b>공격 거리(발사 가능)</b> 를 분리해 “추적 후 공격” 흐름이 자연스럽게 이어지도록 정리

### 3) 공격(발사) 쿨타임 로직 수정

- 현상: 공격이 동작하지 않음
- 원인: 쿨타임 값을 먼저 갱신해버리는 순서 문제
- 해결: “가능 여부 체크 → 발사 실행 → 쿨타임 갱신” 순서로 변경해 정상 발사 확인

### 4) 주석/인코딩 정리

- <code>ApacheAI.cs</code>: 로직 이해를 돕는 주석(한글 중심) 추가
- <code>ApacheCrash.cs</code>: 깨진 한글 주석/로그 문자열을 코드 의미 기준으로 재작성해 복구

## 이슈 및 해결(한눈에)

- 패트롤 포인트 누락 → 반복문 조건 수정(오프바이원)
- 탱크 탐색 1회만 수행 → 재탐색/타깃 갱신 구조 보완
- 공격 미동작 → 쿨타임 갱신 순서 수정
- 한글 주석 깨짐 → 인코딩 혼선 확인 후 주석/로그 재작성

## 내일 할 일

- Apache AI의 공격 연출/피격 반응을 실제 플레이 상황에서 추가 점검
- 관련 스크립트 전반 한글 주석/인코딩 상태 재확인
- 필요 시 “추락 이후 리셋 흐름”과 이펙트 연동 보완
