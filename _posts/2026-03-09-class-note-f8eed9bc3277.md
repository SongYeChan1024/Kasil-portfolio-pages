---

## 0. 요약

- 장르/플랫폼: 웨이브형 좀비 탑다운 슈터 (PC)
- 한 줄 소개(피치): 끊임없이 몰려오는 좀비를 처치해 점수를 올리고, 탄약/체력 아이템을 수급하며 최대한 오래 생존한다.
- 타겟 플레이어: 짧은 세션의 액션/서바이벌을 좋아하는 캐주얼\~라이트 코어 유저
- 핵심 재미(3줄):
  - 사방에서 몰려오는 적을 빠르게 처리하는 몰입감 있는 전투
  - 탄약/체력의 부족으로 생기는 선택(위치 이동, 교전/회피, 아이템 루트)
  - 시간이 지날수록 증가하는 웨이브 압박을 버티며 기록을 갱신하는 성취감

---

## 1. 목표

- 학습/포트폴리오 목표:
  - 3D 캐릭터 리깅(인공관절) 적용 및 애니메이션 상태 전환 구현
  - 웨이브 스폰/추적 AI/아이템 스폰 등 게임 루프 구현
- 완성 목표:
  - 1판(5\~10분) 플레이가 가능한 MVP 제작

---

## 2. 핵심 미션(플레이 목표)

- 최대한 오래 생존하며 점수를 누적한다.
- 웨이브가 강화될수록 아이템(탄약/체력)을 찾기 위해 지속적으로 이동한다.

---

## 3. 주요 기능(요구사항)

### 3.1 웨이브/스폰 시스템

- 생성 방식:
  - 좀비는 일정 주기로 스폰된다.
  - 시간이 지날수록 한 웨이브(또는 한 번의 스폰 사이클)에서 생성되는 좀비 수가 증가한다.
- 난이도/랜덤 요소:
  - 웨이브가 진행될수록 스폰 수 증가 + 개체 능력치(속도/체력/공격력) 변동 폭 증가
- 재사용/최적화:
  - 스폰되는 좀비/아이템은 오브젝트 풀링을 사용한다.

### 3.2 적(좀비) 시스템

- 종류(우선 MVP):
  - 기본 좀비(근접 공격)
- 생성 규칙:
  - 속도/체력/공격력은 개체마다 랜덤으로 지정
- 이동/추적:
  - 좀비는 일정 주기로 플레이어 위치를 갱신하고, 항상 최적 경로로 플레이어를 추적한다.
- 시각 피드백:
  - 강하고 빠른 좀비일수록 피부 색깔이 붉어진다.

### 3.3 전투/자원(탄약, 체력)

- 플레이어 공격:
  - 기관총(연사)로 좀비를 처치한다.
- 탄약:
  - 총알은 무한이 아니다.
  - 탄약 아이템으로 보충한다.
- 체력:
  - 자동 회복되지 않는다.
  - 체력 아이템으로 회복한다.

### 3.4 점수/보상 시스템

- 점수 획득 조건:
  - 좀비 처치 시 점수 획득
  - (선택) 웨이브 생존 시간에 따른 보너스
- UI 갱신 규칙:
  - 처치/시간 이벤트 시 HUD에 즉시 반영
- 게임 오버 시 처리:
  - 최종 점수 표시 후 재시작 가능

### 3.5 조작(입력)

- 기본 조작(예시):
  - 이동: WASD
  - 사격: 마우스 좌클릭(또는 자동 사격 방식 선택)
- 게임 오버 후 재시작:
  - R 또는 UI 버튼으로 재시작
- 확장 기능(후순위):
  - 대시, 무기 교체

### 3.6 UI

- HUD 구성:
  - 점수
  - 플레이어 체력(캐릭터를 따라다니는 원형 바)
  - 탄약(현재/보유)
  - 웨이브/생존 시간
- 게임 오버 UI:
  - 최종 점수, 재시작 버튼
- 해상도/스케일 정책:
  - Canvas Scaler 기반으로 다양한 해상도 대응

### 3.7 게임 매니저/게임 흐름

- 상태 값:
  - isGameOver, currentWave(또는 elapsedTime), score 등
- 정지/재시작 처리:
  - 게임 오버 시 스폰/입력 제한, UI 전환
  - 재시작 시 변수 초기화 및 풀 오브젝트 정리
- 씬/스테이트 전환 방식:
  - 단일 씬에서 상태 전환(권장, MVP)

### 3.8 캐릭터/애니메이션(리깅 포함)

- 캐릭터:
  - 3D 캐릭터 리깅(인공관절) 적용
- 상태별 애니메이션:
  - Idle / Run / Hit / Death (MVP 기준)
- 리깅/스프라이트 관리:
  - (3D) 리그-애니메이터 컨트롤러 기반 상태 전환

---

## 4. 게임 흐름(최신)

- 시작:
  - 플레이어 스폰, UI 초기화, 웨이브 타이머 시작
- 진행:
  - 좀비 스폰 → 추적/교전 → 처치로 점수 누적
  - 탄약/체력 부족 시 아이템 루팅을 위해 이동 동선 변화
- 실패(게임 오버):
  - 플레이어 체력 0 → 게임 오버 UI 표시
- 재시작:
  - 변수 초기화 후 즉시 재시작

---

## 5. 아이템 시스템

- 종류:
  - 탄약 아이템
  - 체력 아이템
- 생성 규칙:
  - 주기적으로 플레이어 근처의 랜덤 위치에 생성
  - 생성된 아이템은 일정 시간 뒤에 사라진다.

---

## 6. 구현 메모(기술 결정)

- 입력:
  - Unity New Input System 사용(예정)
- 생성/풀링:
  - 좀비/아이템 오브젝트 풀링
- AI/경로:
  - NavMesh 기반 추적(또는 단순 추적 + 장애물 회피로 대체 가능)
- UI 스케일:
  - Canvas Scaler 설정 고정
- 성능/최적화:
  - 스폰 수 증가에 대비해 풀 크기와 업데이트 주기(플레이어 위치 갱신 주기) 조절

---

## 7. 리스크/이슈 & 대응

- 스폰 수 증가로 인한 성능 저하
  - 대응: 풀링, 업데이트 주기 최적화, 좀비 최대 동시 개체 수 제한(필요 시)
- 경로 탐색 비용 증가
  - 대응: 목표 갱신 주기 조절, 단순 추적으로 폴백

---

## 8. 범위(Scope)

- MVP(필수):
  - 웨이브 스폰(시간 경과에 따른 스폰 수 증가)
  - 좀비 추적/공격, 랜덤 능력치(속도/체력/공격력)
  - 총기 사격, 탄약/체력(자동 회복 없음)
  - 탄약/체력 아이템 스폰(근처 랜덤, 시간 지나면 소멸)
  - 점수/HUD, 게임 오버/재시작
  - 3D 캐릭터 리깅 적용 및 기본 애니메이션 전환
- Nice to have(선택):
  - 좀비 타입 추가(탱커/러너), 무기 업그레이드, 스킬, 랭킹 저장
  - 싱글 → 네트워크 멀티로 전환하는 실습(후속 단계)
- 제외(하지 않음):
  - 스토리/스테이지 캠페인
