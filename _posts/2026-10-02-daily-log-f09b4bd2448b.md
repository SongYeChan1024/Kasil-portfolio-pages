## 오늘의 목표

10월 2일에 만든 훈련검 3단 공격 기반을 다듬고 8방향으로 확장합니다. 이동 중 좌클릭 공격을 우선 처리하고, 빗자루를 플레이어의 손에 붙이지 않는 독립 오브젝트로 표현합니다.

## 작업 내용과 결정

### 1. 몸·검·궤적이 함께 읽히는 3단 기본공격

1타는 좌→우 횡베기, 2타는 우→좌상 올려베기, 3타는 우상→좌하 직선적인 내려베기 후 대기로 복귀합니다. 손에 검만 붙여 돌리는 보정을 폐기하고 몸·팔·검이 통합된 공격 자세를 사용했습니다.

2타가 오른쪽으로 이동한 뒤 수직으로 올라가던 표현은 연속적인 사선 베기로 교정했습니다. 1·3타의 궤적이 잘 안 보이던 문제는 칼끝의 이전 위치를 따라가는 짧은 리본, 청백색 경계와 흰 중심선으로 보완했습니다. 준비·최종 복귀·취소에는 잔상을 숨깁니다.

5개 원본 방향(S/SE/E/NE/N)에 왼쪽 3방향 반전을 연결했습니다. 각 타수 6자세로 8방향×3타×6시간 자세를 구성합니다. 144개는 시간 슬롯 수이며 서로 다른 원화 144장을 생성한 것은 아닙니다. 검손이 바뀌는 후면 후보는 제외하고 승인 자세를 유지했습니다.

### 2. 걷기보다 기본공격 우선

유효한 좌클릭 공격이 승인되면 현재 이동 경로와 잔여 속도를 제거하고 제자리에서 바로 공격합니다. 기존 우클릭 유지 입력은 공격을 취소하지 않으며, 새 우클릭 명령은 남은 타격과 예약을 취소하고 이동을 재개합니다.

우클릭을 계속 누르고 있으면 공격 종료 후 현재 커서를 따라 이동합니다. 유지 입력이 없으면 제자리에 남습니다. 미장착·재사용 대기·정신집중·메뉴·UI 등으로 공격이 거절된 경우에는 이동을 새로 멈추지 않습니다.

### 3. 빗자루 프리팹 이미지와 이펙트 분리

플레이어는 검으로 올려베기·찌르기·내려베기를 수행합니다. 빗자루는 허공의 별도 오브젝트로 출현하고, 프리팹 내부의 이미지가 자체 경로를 따라 움직입니다. 몸과 빗자루를 한 장에 그린 v1은 현재 적용 경로에서 사용하지 않습니다.

- 올려쓸기: 빗 부분을 낮게 대고 좌→우 곡선으로 쓴 뒤 끝에서 올립니다.
- 찌르기: 나무 자루 끝이 앞으로 나가고 빗 부분은 뒤에 남습니다.
- 내려치기: 빗 부분을 위에서 아래로 내려찍습니다.

<code>PrototypeBroomObjectVisual</code>은 프리팹의 이미지·이동을 담당합니다. <code>PrototypeBroomSkillEffects</code>는 별도 월드 루트에서 출현/소멸과 궤적을 처리합니다. <code>PrototypeManifestBroomVisual</code>은 시작·종료만 조정합니다. 이펙트를 꺼도 빗자루 이미지와 동작은 유지됩니다.

찌르기의 궤적 기준은 자루 끝, 나머지 두 스킬은 빗 끝입니다. 이 궤적은 시각 효과이며 피해 콜라이더가 아닙니다. 구조는 v3, 원화·폴더·프리팹 이름은 재사용한 v2입니다.

### 4. 유지한 전투 규칙

- 기본공격 피해 15, 타격 시점 0.20/0.18/0.22초와 기존 클릭 예약·취소 규칙 유지.
- 빗자루 스킬의 단일 피해·중복 타격 방지·비용·재사용 시간 유지.
- 쓸기: 0.90초 실행 / 0.45초 타격 / 비용 60 / 재사용 1.8초.
- 찌르기: 0.55초 실행 / 0.209초 타격 / 비용 45 / 재사용 0.9초.
- 내려치기: 0.72초 실행 / 0.4032초 타격 / 비용 50 / 재사용 1.2초.
- 검 기본공격을 추가 실행하지 않으므로 스킬 피해가 두 번 들어가지 않습니다.
- 바닥 획득용 <code>TestWeapon.prefab</code>의 충돌·상호작용 유지.
- SFX·히트스톱·새 무기 콜라이더 판정은 이번 작업에 추가하지 않았습니다.

## 검증

Unity 6000.3.7f1 별도 배치 검증 프로젝트에서 아래 최종 결과를 확인했습니다. 열린 사용자 Unity 씬은 변경하지 않았습니다.

- 빗자루 오브젝트·이펙트 분리: <code>MANIFEST_BROOM_SMOKE_SUCCESS checks=1689</code>
- 8방향 3단 공격·궤적 회귀: <code>COMBO_BODY_SMOKE_SUCCESS: 2273</code>
- 8방향 걷기 회귀: <code>WALK_EIGHT_KEYPOSE_SMOKE_SUCCESS: 75</code>
- 이동·공격 입력 우선순위 회귀: <code>MOVEMENT_ATTACK_PRIORITY_SMOKE_SUCCESS checks=53</code>
- 모두 종료 코드 0. 원화 UV/알파·피벗, 반전, 타격 끝과 잔상 일치, 비용·단일 피해·종료 복구를 검사했습니다.

이 결과는 원화의 자연스러움이나 실제 튜토리얼에서의 손맛을 보증하지 않습니다. 에디터 검색 인덱서의 기존 초기화 예외는 별도 경고로 남아 있습니다.
