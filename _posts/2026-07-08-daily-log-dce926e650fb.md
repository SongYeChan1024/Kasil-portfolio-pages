## 데일리 로그 (2026-07-08)

### 오늘 한 일 (What I did)

1\) <b>아티팩트(장착형 아이템) 시스템 뼈대 구현</b>

- 기존 인벤토리 흐름에 <code>artifact</code> 카테고리를 추가하고, 아티팩트 전용 데이터(<code>ArtifactItemData</code>, <code>ArtifactEquipEffect</code>, <code>ArtifactCategory</code>, <code>ArtifactEffectType</code>)를 도입했다.[\[1\]][\[2\]]
- <code>LocalJsonItemRepository</code>가 JSON에서 아티팩트 데이터를 로드하고(카테고리/등급/효과 1\~2개), 런타임 데이터베이스에 등록하도록 확장했다.[\[2\]]

2\) <b>루팅(아이템 박스)에서 아티팩트가 실제로 나오게 연결</b>

- ItemBox에 “카테고리 확률(consume/memory/artifact)” 기반 루팅 구조를 넣고, 아티팩트가 선택되면 등급별 가중치로 TID를 선택하도록 연결했다.[\[1\]]

3\) <b>획득 → 장착 → 해제 → UI 표시까지의 플레이어 조작 흐름 구축</b>

- <code>PlayerArtifactEquipment</code>를 추가해 “보유(Inventory)”와 “장착(Equipment)” 책임을 분리했다.[\[1\]][\[2\]]
- 인벤토리 UI 상단에 <code>ArtifactEquipSlotUI</code>를 추가하고, 장착/해제 UX를 <b>더블클릭 해제 + 드래그앤드롭 해제</b>로 정리했다.[\[1\]][\[3\]]
- 빈 장착 슬롯 드롭이 안 되는 문제는 UI Raycast Target 설정 문제로 보고 해결했다(빈 슬롯이 드롭을 받아야 함).[\[3\]]

4\) <b>세이브/로드 및 탈출 정산과 연동 (장착 아티팩트 증발 방지)</b>

- 장착 중 아티팩트가 인벤토리 슬롯에서 빠지는 구조이기 때문에, <code>PlayerSaveData</code>에 <code>artifactSlots</code>를 추가해서 저장/복원 대상에 포함시켰다.[\[1\]][\[2\]]
- <code>ResultManager.InventorySync()</code>에서 장착 상태를 저장하고, <code>GameManager.OnSceneLoaded()</code>에서 장착 상태를 복원하도록 연결해 “장착한 채로 탈출하면 사라지는 문제”를 해결했다.[\[1\]][\[3\]]

5\) <b>회의에서 확인한 일정/우선순위 및 결정 사항 정리</b>

- 목요일 시연(17시) 준비를 기준으로 기능 구현을 우선 진행(최적화는 후순위)하는 방향을 재확인했다.[\[4\]]
- 네트워크(Photon) 구현은 <b>보류</b>로 두고, 강다영 TD의 기간 내 구현 가능성 판단 후 결정하기로 했다.[\[4\]]
- VFX/툰쉐이더 에셋은 금일 요청서 작성, 발표 자료 제작 업무 분담 명확화 필요 등 액션 아이템을 확인했다.[\[4\]]
- 스킬 쪽에서는 <b>프리즘 유탄</b> 동작 순서를 “0.5초 지연 → 폭발/AOE → 2.5초 디코이(총 3초)”로 명확히 합의했다.[\[4\]]

---

### 오늘의 결과 (Outcomes)

- 아티팩트가 <b>데이터로 존재</b>하는 수준을 넘어, <b>루팅 → 획득 → 장착 → UI 표시 → 저장/복원</b>까지 “게임 흐름 안에서 한 바퀴 도는” 기반이 연결되었다.[\[1\]][\[3\]]
- 장착 아티팩트가 탈출 후 증발하던 문제를 저장 구조 확장으로 막아, 반복 플레이/테스트 루프가 가능해졌다.[\[3\]]

---

### 막힌 점 / 리스크 (Blockers & Risks)

- 지금 단계는 ‘장착 상태’까지이며, <b>장착 효과가 실제 능력치에 적용되는 단계</b>(hpRegen/mpRegen/moveSpeedUp 등)가 남아 있다.[\[1\]][\[3\]]
- UI 드래그앤드롭은 Raycast/프리팹 참조 누락이 코드 버그처럼 보이기 쉬워, 슬롯 1\~2개만 이상할 땐 프리팹 직렬화 참조부터 점검하는 습관이 필요하다.[\[3\]]
- 목요일 시연까지 발표 자료/리소스(VFX 등) 진행이 지연되면, 기능 시연 자체는 가능해도 ‘보여지는 완성도’가 흔들릴 수 있다.[\[4\]]

### 내일 할 일 (Next)

- 아티팩트 장착 효과 실제 적용 1차(우선순위: <code>hpRegen</code> → <code>mpRegen</code> → <code>moveSpeedUp</code> …) 설계/반영.[\[1\]]
- 아이템 레어도별 인벤토리 슬롯 이미지 변경/검증, 아이템 버리기 기능 에러 디버깅(목요일 시연 전).[\[4\]]
- 프리즘 유탄 스킬: 마나 소모/데미지 계산 보완 및 시연 가능한 형태로 안정화.[\[4\]]
