- [ ] 2팀: 최종 발표일까지 QA 및 디버깅 작업 지속, 프롬프트 개선

### 1팀 진행 상황

#### FCT 피드백 기반 개선 사항

- 퍼즐 난이도, AI 완성도 및 기본 플레이 개선 작업 진행 중 
- AI 기억 연결 기능 구현 완료 (담당 레이서 작업) 
- 사운드 개별 조정 UI 추가: 초기값 리셋 기능 및 개별 음량 On/Off 기능 구현 
- 마우스 시선 고정 기능과 UI 팝업 연동 구현 
- 캐릭터가 맵을 뚫고 지나가는 문제 해결: 콜라이더 추가로 보정 완료 
- 극장 맵 콜라이더 설정 수정: 메시 콜라이더 재활성화

#### 퍼즐 개선

- 3-2 퍼즐 전면 리뉴얼 진행 중: 의도와 컨셉이 명확하지 않다는 피드백 반영 
- 탑다운 형식의 리듬게임 방식으로 변경 (피아노 타일 유사), WASD 조작 
- 재사용 가능한 리소스 활용하여 제작 중 

#### AI 프롬프트 개선

- 프롬프트 무시 방지 기능 강화: 프롬프트 빌더 내 최상위 규칙 설정 
- "ignore" 등 특정 키워드 감지 시 거부 메시지 출력 
- AI가 자신을 NPC로만 인지하도록 설정 

#### 최종 퍼즐 난이도 조정

- 난이도는 유지하되, 힌트 시스템 추가로 진행 막힘 방지  
- 스위치 조작 시 연속적인 힌트 제공 
- 현재 빌드로도 클리어 가능한 상태 

### 2팀 진행 상황

#### NPC 인터랙션 개선

- FGT 이후 추가 외부 테스트 진행으로 피드백 수집 
- 주요 피드백: 대화가 인위적, 까칠함, 톡식함, 수동적 
- AI 방어벽 고도화로 인한 과도한 제한이 원인으로 파악 
- 프롬프트 개선으로 유의미한 성과 달성, 현재 "봐줄만한 수준" 

#### 프롬프트 정책 변경

- <b>노스트링(No-string) 정책 도입</b>: 정해진 예문 없이 뉘앙스로만 대화하도록 유도  
- API가 특정 문구를 과도하게 고정 출력하는 문제 해결 
- 메타적인 발언을 노이즈로 처리하도록 상세한 프롬프트 작성 

#### 추리 시스템 개선

- <b>이분법 구조 확립</b>: 문서 내용을 완전히 알거나 완전히 모르는 방식으로 변경 
- 개발 코스트 및 시스템 안정성 고려한 결정 
- AI가 모르는 정보를 세계관에 맞게 추론하여 생성 
- 대화를 통한 정보 대조 추리 요소 강화 

#### 스트레스 시스템 개선

- <b>본성 노출 시스템</b>: 당황 시 종족별 본성이 점차 드러남 
- 화내기 외에 추가 추리 요소 제공 

#### 자발적 퇴장 시스템

- 고정 대화 횟수 제한(10회) 방식에서 스트레스 기반 시스템으로 변경 
- 스트레스 수치 1-100 범위, 특정 조건에 따라 유동적 증가 
- 스트레스 100 도달 시 NPC가 자발적으로 퇴장 
- 욕설만 하면 6번 만에 퇴장 가능, 정상 진행 시 10번 이상 대화 가능 

#### UI/UX 개선

- 상호작용 오브젝트 추가: 라디오(배경음악 변경), 선풍기   
- 폰트 변경 및 엔터키 버튼 조작 구현 
- 말풍선 애니메이션 및 SFX 추가 
- NPC 표정 변화가 대사 톤과 일치하도록 개선 

#### 엔딩 시스템

- 4가지 엔딩 분기 모두 구현 완료 
- 5일차까지 전체 플레이 가능 

#### 정산 시스템 개선

- 성공 보수 표시: 기본 100원 × 맞춘 인원수로 변경  
- 워딩 개선으로 직관성 향상 
- 자판기 아이템 효과 설명 추가 
- 모든 아이템 기능 구현 완료 

#### 아이템 시스템

- 모든 아이템은 일회성 
- 동일 아이템 중복 사용 가능 (효과 누적)  
- 경제 시스템: 매 일차 종료 시 200원 차감, 3명 이상 맞추지 못하면 파산 엔딩 
- 뇌물 수령 여부 전략적 선택 필요 

### QA 및 디버깅 프로세스

#### QA 체크리스트 시스템

- 효율적인 QA를 위한 체크리스트 양식 작성 
- 씬 및 기능별 체크 항목 기재 
- 버전별로 Notion에 업로드하여 관리  
- 5가지 결과 분류 항목으로 진행 상황 추적 

#### 버그 리포트 관리

- 진행 및 해결 여부에 따른 상태 표시 
- 정해진 양식에 따라 버그 사항 기록  
- 우선순위를 고려한 유연한 대응 

#### 디버그 로그 시스템

- 빌드 환경에서 로그 미표시 문제 해결 
- Save 파일 경로에 텍스트 로그 자동 생성  
- 에디터 및 빌드 환경 모두에서 문제 추적 가능 

### 기술 및 도구 논의

#### Anti-Gravity (AI IDE) 사용

- VS Code 기반 AI 에이전트 IDE 
- 확장 프로그램 설치 가능 (Continue, MCP 등) 
- <b>무료 사용 가능</b>이 주요 선택 이유   
- 모델 쿼터 5시간마다 초기화 
- 프로젝트 파일 기반 컨텍스트 유지 
- 가이드라인 참조 기능으로 일관된 코드 생성 
- 로컬 모델 연동도 가능 

#### 프롬프트 작성 방법론

- 공통 프롬프트에 상세한 메타 정보 처리 규칙 명시 
- "시스템 절대 원칙", "선택 가이드" 등 강제성 부여 
- 기본 틀을 AI에게 제공하여 최적화 
- 관리된 데이터 외 노이즈로 취급하는 구조 

### Q&A 주요 내용

- 1-2 스테이지 리뉴얼 마감 가능 여부 확인 
- 최종 퍼즐 난이도 개선 방향 논의   
- 메모지 콘텐츠 랜덤화 불가 (코스트 문제)

그것도 혹시 수정이 됐나요? 그 악보 모으는 퍼즐에서도 그 콜라이더가 엄청나게 많이 뚫리는? 엄청 많이 존재했었는데 그 극장 쪽에 컬라이더 설정이 거의 안되어 있었던 걸로 확인이 돼서 그 쪽에 메쉬 컬라이더를 활성하는 것으로 처리를 했습니다. 컬라이더 수정할 때 콜라이드를 한 번 싹 지웠다가 다시 했었는데 그때 다시 안 넣었었나봅니다 그래서 다시 매직 콜라이드를 넣어 주셔서 그 부분은 순정이 됐습니다
