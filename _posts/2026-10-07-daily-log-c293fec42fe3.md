- 프로젝트: 에르고 스퀘어 — 튜토리얼 프로토타입
- 작업일: 2026-10-07 (사용자 지정 마감일)
- 기록 작성·데이터 검증일: 2026-10-08. 엑셀과 이미지 폴더 및 balanceVersion의 실제 생성일은 유지.
- 작성자: 송예찬
- 상태: 이번 작업 마감. 전체 성장 시스템과 밸런스 확정을 의미하지 않음.

## 오늘의 목표

빗자루 파밍·조합으로 1회 → 2회 → 3회 연계 돌진 스킬이 열리도록 구현하고, 함께 성장한 도깨비는 유지한다. 수치는 엑셀을 원본으로 관리하고 JSON으로 게임에 반영한다.

## 완료한 작업

### 동일 도깨비를 유지하는 조합 성장

- 1자루: 짧게 돌진하며 왼쪽 쓸기.
- 2자루 조합: 같은 키를 두 번 눌러 왼쪽 → 오른쪽 쓸기.
- 3자루 조합: 같은 키를 세 번 눌러 왼쪽 → 오른쪽 → 자루 찌르기. QQQ는 예시이며 할당한 스킬 키로 연계.
- 추가 빗자루 획득은 미유대 조합 재료로 저장. 기존 개체 ID·유대·무작위 능력치·내구도·청사진 배치 및 키 할당 유지.
- 3단계 이후 피해·쿨타임·자원 효율 강화는 각각 최대 5단계. 단계 조합과 강화에 재료를 소모.
- 유대가 있거나 이미 조합한 개체를 직접 재료로 소비하지 못하도록 API에서 방어.

### 연계 전투와 편집 UI

- 첫 승인 입력부터 개체 단위 쿨타임 시작. 슬롯을 바꿔도 쿨타임 우회 불가.
- 각 타격 승인 시 자원 소모, 마지막 구간 선입력 1회, 연계 시간 초과 시 초기화.
- NavMesh와 장애물 경계로 돌진 이동 제한. 여러 콜라이더가 있어도 대상별 1회 피해.
- 실제 명중한 타격당 유대 증가. 보스 저항·스킬 중 슈퍼아머는 기존 정책 재사용.
- Tab → 청사진 편집 → 빗자루 선택에서 단계·연계 수·수치·유대·재료 및 조합/강화 확인.
- 조합은 2회 클릭 확인. 테스트 재료 지급 버튼은 Editor/Development Build 전용.
- 기존 독립 빗자루 오브젝트와 8방향 플레이어 이미지를 재사용하여 좌·우 쓸기와 자루 찌르기를 연결.
- 귀환 시 성장 상태와 재료를 메모리로 인계.

### 엑셀 → JSON과 명세

- 엑셀 6시트: 사용안내 / Stages / Actions / Recipes / Enhancements / Branches.
- 데미지, 공격력 계수, 쿨타임, 이동거리, 소모 자원, 판정 범위, 모션 시간, 경직·밀림·넘어짐 데이터 관리.
- Python 변환기·PowerShell 실행기·Unity Editor 재생성 메뉴 추가.
- 필수 값·타입·참조·중복 ID·범위·수식 등을 검증하고 성공할 때만 JSON 교체. 오류가 나면 기존 JSON 보존.
- 종합 기획서, 조합 성장 명세, 밸런스 색인과 데이터 편집 안내 보완.

## 플레이테스트용 임시 수치

확정 밸런스가 아니라 첫 테스트 기준이다.

- 단계별 쿨타임: 4.5 / 5.5 / 6.5초.
- 연계별 소모 정기: 18 / 18 / 24. 3회 완주 기본 합계 60.
- 돌진거리: 1.4 / 1.6 / 2.0.
- 연계 유예 1.2초, 선입력 0.18초.
- 강화 1단계당 피해 +8%, 쿨타임 -4%, 비용 -4%를 해당 강화 축에만 적용. 각각 최대 5단계.

## 발견한 문제와 해결

- 개체 성장과 중복 아이템 소비를 분리하여 같은 도깨비의 유대와 능력치가 재추첨되거나 초기화되지 않도록 처리.
- 스킬 슬롯별 쿨타임 대신 개체 ID별 쿨타임으로 재할당 우회 차단.
- Excel 오입력은 사전 검증과 원자적 출력으로 차단. 긴 필드명은 열 너비와 행 높이 조정.
- 돌진 검증은 캐릭터 높이 오프셋 영향을 제외한 지면 이동거리로 검사.
- 원본 씬과 사용자의 미저장 편집을 보호하기 위해 별도 Unity 검증 복제본에서 시험.
- 복제본 Unity Search 인덱스 초기화 예외는 있었으나 게임 코드 컴파일 오류 없이 시험 완료.

- 실제 사용자 플레이 밸런스와 독립 실행 빌드는 아직 검증하지 않음.
