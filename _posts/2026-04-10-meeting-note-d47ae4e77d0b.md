### AI 시대의 취업 시장 및 준비 전략

- <b>주니어 개발자 채용 트렌드</b>: 최근 시니어 개발자를 대체하여 주니어 개발자를 채용하는 사례 발생 
  - AI 활용 능력을 입증하여 시니어 대비 2배 높은 생산성을 증명한 주니어가 시니어 2명을 대체하여 채용됨 
  - 면접에서 구체적인 생산성 증명이 중요함 
- <b>기본기의 중요성</b>: AI 시대에도 코딩과 알고리즘 등 기본기가 필수  
  - AI가 생성한 코드에도 오류가 있을 수 있어 검증 능력 필요
  - "Garbage In, Garbage Out" - 좋은 질문을 하려면 기본 개념 이해가 선행되어야 함 
- <b>다양한 역량 개발</b>: 디자인, 기획, 코딩을 모두 어느 정도 할 수 있는 인재 선호  
  - 각 분야별로 한 번씩 역할을 바꿔가며 경험해볼 것을 권장 
  - 다양한 경험이 있어야 AI에게 정확한 질문 가능 (예: 3D 모델링의 폴리곤 최적화) 
- <b>최신 기술 트렌드</b>: Co-work, Harness 등 면접에서 자주 질문하는 개념들 
  - Harness: AI 제약 설정 및 빌드-테스트-배포 자동화  
  - 새로운 트렌드를 파악하고 있다는 것을 어필할 수 있어야 함
- <b>면접 준비 조언</b>: 자기소개서는 현재 보유 스킬과 경험 위주로 작성 
  - 학창시절 이야기보다는 실무 능력과 프로젝트 경험 강조
  - 1년 내 시니어 개발자 감축 및 AI 활용 능력 있는 신입 채용 증가 예상 

### 1팀 게임 프로젝트 발표

- <b>개발 현황 및 이슈</b>
  - Git 브랜치 관리 중 충돌 발생으로 이전 버전 기반 재작업 진행  
  - 프로토타입 완성 후 UI 및 연출 개선에 집중 
- <b>구현된 주요 기능</b>
  - <b>사운드 시스템</b>: 마스터 볼륨 및 세부 볼륨(BGM, 환경음, UI음, 효과음) 개별 조절 기능 
  - <b>세이브 시스템</b>: 스테이지별 이미지가 포함된 로드 게임 화면 
  - <b>컷신 연출</b>: 이미지와 텍스트 기반 컷신 구현 
  - <b>AI NPC</b>: 호감도 데이터 연동 및 엔딩 조건 점수 누적 기능  
  - <b>자동 세이브</b>: 진행도에 따른 자동 저장 및 특정 조건 충족 시 데이터 갱신  
  - <b>수동 세이브</b>: 로비에서 게임 데이터 수동 저장 가능 
- <b>게임 디자인 의도</b>
  - 첫 스테이지 화면이 어두운 것은 의도된 설정 
  - 스테이지 진행에 따라 시야 확보 및 색상 표현 변화 예정 
  - 화면 밝기 조절 기능은 추가하지 않을 예정 (의도된 연출) 
- <b>플레이 타임 및 콘텐츠</b>
  - 에피소드당 약 10분 이내, 전체 플레이타임 30-40분 목표  
  - UI/SLC는 거의 최종 상태, 현재 엔딩 로직과 세부 컷신 연출 작업 중 

### Q&A 주요 논의사항

- <b>UI/UX 개선 제안</b>
  - 음량 옵션이 다양한 것은 좋으나, 기본값 초기화 버튼 추가 검토 필요  
  - 감마 조절 기능은 스토리 의도상 추가하지 않기로 결정 
- <b>게임플레이 및 스토리</b>
  - 게임 시작 시 NPC와 자동 대화가 아닌 직접 상호작용 방식 
  - NPC 대화 없이도 진행 가능하나 트루 엔딩은 NPC 대화 필수 
  - 온보딩을 통해 AI NPC의 중요성을 사전에 알려주는 방안 검토 필요 
- <b>Git 충돌 관리</b>
  - 에피소드별 씬 분할 작업으로 충돌 최소화 시도 
  - UI, 사운드 등 여러 씬에 걸친 작업에서 충돌 발생  
  - 매일 한 번씩 충돌 발생 중, 프로세스 정교화 필요 
- <b>AI 툴 활용</b>
  - <b>음악/사운드</b>: Eureka, Muse Hub 사용  
    - 약 1주 반 만에 사운드 작업 완료 
    - 프롬프트 작성에 많은 시간 투입 (천 자 분량) 
    - 프로토타입 먼저 작곡 후 AI로 디테일 추가하는 방식도 활용 
    - SFX는 AI SFX Door에서 검색 
  - <b>UI 이미지</b>: GPT 활용, 나머지는 일러스트레이터로 직접 제작 

### Git 버전 관리 이슈 해결 논의

- <b>현재 상황</b>: 메인 브랜치가 최신 UI 버전이 아닌 상태  
  - 최신 UI 버전은 0.4.1.0 (SFX 조절 가능)  
  - 이전 UI 버전으로 작업한 풀 리퀘스트가 제출된 상태
- <b>해결 방안</b>: 최신 UI 버전을 메인에 먼저 푸시한 후, 다른 작업자들이 이를 기반으로 재작업
