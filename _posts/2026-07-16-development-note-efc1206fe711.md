> 이 문서는 2026-07-16 베타 버전 플레이 피드백을 개발 백로그와 회의 안건으로 전환하기 위해 재정리한 통합 문서다. 하단 이미지는 원문 보존용이 아니라 각 피드백 항목의 화면 증빙으로 사용한다.

# 1. 한 줄 결론

이번 베타 피드백의 핵심은 플레이를 막는 버그, 플레이어가 기능을 오해하는 UX, 전투 보상 부족, UI 일관성 부족이 동시에 드러났다는 점이다. 따라서 먼저 1순위 플레이 방해 요소를 처리하고, 그다음 UX 안내와 전투 보상/타격감, UI 폴리싱 순서로 정리하는 것이 좋다.

# 3. 핵심 이슈 요약

## 3.1 플레이 방해 버그

- 듀얼모니터 환경에서 마우스 포인터가 게임 화면 밖으로 이탈함
- 공중전화 부스 콜라이더 문제로 플레이어 통과 또는 탈출 부스 식별 문제가 발생함
- 상자 사이, 벽 근처 등 좁은 구간에서 벽을 통과하는 현상이 발생함
- 인벤토리 드래그앤드롭이 간헐적으로 정상 동작하지 않음
- 일부 버튼에서 사운드가 출력되지 않음
- 몬스터가 겹쳐 스폰되어 난이도가 급격히 상승하는 상황이 있음

## 3.2 UX 이해도 문제

- 어떤 오브젝트가 탈출 부스인지 명확하지 않음
- 공중전화 부스에 상호작용 대상이라는 표시가 부족함
- 상호작용 불가 문에 잠김 표시가 필요함
- 아티팩트 아이템이 소모품과 구분되지 않아 퀵슬롯 장착 불가 사유가 잘 전달되지 않음
- 안전 금고의 자물쇠 표시가 기능 잠금처럼 보일 수 있음
- 관제실 UI가 어떤 역할의 공간인지 명확하지 않음

## 3.3 UI / 비주얼 폴리싱

- 여러 화면에서 UI 정렬이 일정하지 않음
- 폰트 크기 기준이 통일되어 있지 않음
- 제목에는 볼드체 적용이 필요함
- 뒤로가기 버튼 크기와 디자인을 프리팹 기준으로 통일할 필요가 있음
- 결과 화면 스크롤바 여백이 부족함
- 일부 이미지가 깨진 것처럼 보이는 화면이 있음
- 메인 화면 로고와 인게임/기록 화면 로고의 일관성 검토가 필요함

## 3.4 전투 / 보상 / 타격감

- 몬스터 HP가 높아 전투 부담이 큼
- 몬스터 처치 보상이 부족해 전투 동기가 약함
- 난이도 높은 에너미를 잡아야 하는 이유가 부족함
- 사격/타격 시 피드백이 약해 손맛이 부족함
- Q스킬 쿨타임 UI와 사용 가능 상태 피드백이 필요함

## 3.5 사운드

- UI 클릭 사운드가 랜덤으로 출력되어 버튼 역할이 다르게 느껴질 수 있음
- 모든 버튼에 클릭 사운드가 적용되어 있는지 점검 필요
- 상호작용 불가 상태에는 기본 클릭 사운드가 아니라 블록 사운드가 필요함

## 3.6 후순위 검토 항목

- 로딩 화면 게임 팁 추가
- 탈출 성공 연출 강화
- 성공/실패 결과에 따른 캐릭터 대사 분기
- F키 도발 중 이동 가능 여부 기획 확정
- 네트워크 기능 추가 가능성 검토
- 외부 코치 최종 평가서 작성 및 공유

# 6. 바로 개발 가능한 항목

- 커서 제한 적용
- 공중전화 부스 콜라이더 수정
- 벽/상자 사이 충돌체 보강
- 버튼 사운드 누락 화면 점검
- 잠긴 문 UI 표시 추가
- 드래그앤드롭 Drop 가능 영역 하이라이트
- 뒤로가기 버튼 프리팹 통일
- 결과 화면 스크롤 패딩 추가
- 폰트 크기 기준 임시 적용

# 7. 회의가 필요한 항목

- 몬스터 HP를 어느 정도로 낮출지
- 몬스터 처치 보상을 시간 연장, 전용 드랍템, 특수 아이템 중 무엇으로 잡을지
- 몬스터 겹침 스폰을 의도된 난이도로 유지할지, 최소 거리 제한을 둘지
- F키 도발 중 이동 가능 여부를 어떻게 확정할지
- 아티팩트 식별 방식을 툴팁, 아이콘, 슬롯 프레임, 카테고리 라벨 중 어디까지 적용할지
- 로고 교체를 이번 베타 폴리싱 범위에 포함할지
- 네트워크 기능 검토를 현 개발 범위에 포함할지 별도 리서치로 분리할지

# 8. 추천 처리 순서

1. 1순위 플레이 방해 버그를 먼저 처리한다.
   - 커서 이탈, 벽 뚫림, 콜라이더, 드래그앤드롭, 버튼 사운드 누락
2. 플레이어가 기능을 오해하는 UX를 정리한다.
   - 탈출 부스, 잠긴 문, 아티팩트 식별, 관제실 명칭
3. UI 기준을 임시로라도 통일한다.
   - 폰트 크기, 제목 스타일, 정렬, 뒤로가기 버튼
4. 전투 보상과 밸런스를 회의에서 확정한 뒤 적용한다.
   - 몬스터 HP, 처치 보상, 드랍템, 겹침 스폰
5. 타격감과 사운드 피드백을 보강한다.
   - 사격/타격 VFX, 피격 사운드, Q스킬 쿨타임 UI
6. 후순위 편의 기능과 연출을 처리한다.
   - 로딩 팁, 성공/실패 대사, 탈출 성공 연출, 네트워크 검토

상자와 벽 사이 좁은 구간에서 플레이어가 벽을 통과하는 현상이 있다. 충돌체 보강, 이동 방식 점검, 필요 시 보이지 않는 Collider 또는 Mesh를 추가한다.

기본 버튼 사운드는 통일하고, 특수 버튼만 별도 사운드를 사용하는 편이 좋다. 상호작용 불가 상태에는 블록 사운드를 적용한다. 안전 금고의 자물쇠 표현은 기능 잠금처럼 오해될 수 있으므로 안내를 보강한다.
