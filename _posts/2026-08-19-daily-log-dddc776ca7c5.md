## 오늘의 한 문장

상호작용 대상을 알아보고 <code>G</code>로 실행하는 공통 흐름과 빗자루 스킬의 피해·경직·넉백을 반복 검증할 수 있는 전투 표적을 연결했다.

---

## 오늘의 목표

- [x] 상호작용 가능 오브젝트 위에 <code>G</code> 키 안내 표시
- [x] 기존 빗자루 획득을 공통 상호작용 구조에 편입
- [x] 빗자루 스킬별 피해·경직·넉백 차이 적용
- [x] 체력바와 피격 반응을 가진 테스트용 빗자루 도깨비 제작
- [x] 처치 후 자동 재생성되는 전투 샌드박스 구성
- [x] Git 데일리 로그·개발 일지와 문서 웹 내비게이션 갱신

---

## 진행한 작업

### 1. 공통 상호작용 구조

- 상호작용 문구, 우선순위, 사용 가능 상태, 표시 위치와 실행 메서드를 제공하는 <code>IInteractable</code>을 정의했습니다.
- 플레이어 주변 후보 중 우선순위와 거리를 비교해 현재 대상을 선택하는 컨트롤러를 추가했습니다.
- 기존 <code>낡은 빗자루</code> 획득을 같은 흐름으로 처리하도록 연결했습니다.

### 2. 월드 <code>G</code> 안내

- 현재 대상의 월드 위치를 화면 좌표로 변환해 <code>G</code> 키와 행동 문구를 대상 위에 표시하도록 했습니다.
- 대상 선택은 게임플레이 계층, 안내 표현은 프레젠테이션 계층이 담당하도록 분리했습니다.
- HUD 프리팹 생성 과정에 안내 프레젠터를 포함하고 런타임 자동 추가는 제거했습니다.

### 3. 빗자루 스킬 차별화

- 피해량, 경직 시간, 넉백 방향·거리와 공격 원점을 하나의 타격 데이터로 전달하도록 확장했습니다.
- 내려치기는 높은 피해와 긴 경직, 쓸어치기는 강한 밀어내기, 찌르기는 중간 피해와 직선 압박을 검증하도록 수치 가안을 적용했습니다.

### 4. 테스트용 빗자루 도깨비

- 최대 체력 60의 고정형 테스트 적을 제작했습니다.
- 체력바, 피격 점멸, 경직, 넉백, 처치 축소 연출과 2.5초 후 재생성을 구현했습니다.
- 전투 표적 프리팹과 머티리얼 생성, HUD 보강과 <code>TestMap</code> 배치를 반복할 수 있는 에디터 빌더를 추가했습니다.

---

## 오늘의 결정

- 모든 획득·조사 오브젝트는 <code>IInteractable</code>을 공통 경계로 사용합니다.
- 테스트 적은 AI 완성본이 아니라 스킬 범위·피해·경직·넉백을 빠르게 비교하는 전투 표적입니다.
- 테스트 적은 같은 세션에서 반복 비교할 수 있도록 처치 후 자동 재생성합니다.
- 피해·경직·넉백 수치는 밸런스 확정값이 아닌 프로토타입 가안입니다.

---

## 발생한 문제와 해결

- <b>필드 초기화 시 Unity 객체 생성 예외</b> → <code>MaterialPropertyBlock</code> 생성을 <code>Awake</code>로 옮겼습니다.
- 머티리얼이 잘못된 <code>04.Art</code> 경로에 생성됨 → <code>04.Graphics/Common/Materials/Prototype</code>으로 통일했습니다.
- <b>열린 Unity가 외부 이동 전 경로를 기억함</b> → 실패 작업을 취소하고 에셋 새로고침 후 빌더를 재실행했습니다.
- <b>플레이 종료 후 씬이 변경 상태로 남을 가능성</b> → 런타임 부트스트랩을 제거하고 HUD 프리팹에서 명시적으로 구성했습니다.
