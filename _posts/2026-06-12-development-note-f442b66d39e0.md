# 《침몽도시: 루시드 다이버》 컨셉 기획 요약본 V0.5

## 1. 프로젝트 개요

《침몽도시: 루시드 다이버》는 현실 무기가 통하지 않는 꿈속 도시를 탐사하고, 드림 포지드 무장으로 침식체를 상대하며, 심상기물과 몽유물을 회수해 탈출하는 모바일 2.5D 실시간 협동 익스트랙션 슈팅 RPG이다.

본 프로젝트는 라이트 익스트랙션의 긴장감, 서브컬처 RPG의 캐릭터 편성 매력, 모바일 멀티플레이의 접근성을 하나의 구조로 결합하는 것을 목표로 한다.

---

## 2. 최종 컨셉 한 줄

현실 무기가 통하지 않는 꿈속 도시에서, 루시드 다이버들이 드림 포지드 무장으로 침식체를 상대하고, 고가치 몽유물을 회수해 탈출하는 모바일 실시간 협동 익스트랙션 슈팅 RPG.

---

## 3. 중심 재미

이 게임의 중심 재미는 <b>“더 깊이 들어가 보상을 노릴 것인가, 지금 가진 것을 지키기 위해 탈출할 것인가”</b>를 판단하는 데 있다.

플레이어는 외곽에서 비교적 안전하게 심상기물을 회수할 수 있지만, 더 높은 가치의 몽유물과 보스 보상은 중심부에 존재한다. 중심부로 들어갈수록 전투 위험이 커지고 제한시간 소모 배율이 증가하므로, 플레이어는 매 세션마다 욕심과 생존 사이에서 선택하게 된다.

### 핵심 재미 3가지

| 구분 | 내용 |
| --- | --- |
| 욕심과 탈출의 재미 | 회수품을 더 얻을수록 보상 기대가 커지지만, 강제 각성 시 손실 위험도 커진다. |
| 협동으로 위험을 넘는 재미 | 혼자는 외곽 탐사가 가능하지만, 중심부 침식체와 고가치 보상은 2인 이상 협동이 유리하다. |
| 캐릭터 편성과 성장의 재미 | 메인 캐릭터, 지원 캐릭터, 오퍼레이터를 조합해 자신의 탐사 스타일을 만든다. |

## 4. 장르 정의

### 기존 방향

2.5D 라이트 PvE 익스트랙션 액션 RPG

### 모바일 멀티플레이 반영 후 방향

모바일 2.5D 실시간 협동 익스트랙션 슈팅 RPG

### 주요 구성 요소

- 모바일 조작 기반
- 2.5D 또는 쿼터뷰 전장
- 실시간 탐사
- PvE 중심 전투
- 1\~4인 세션 플레이
- 외곽 솔로 파밍
- 중심부 협동 공략
- 라이트한 손실 구조
- 서브컬처 캐릭터 편성
- 드림 포지드 무장 기반 전투
- 소수 정예 침식체 중심의 선택형 전투

## 5. 컨셉 융합 방향

### 라이트 익스트랙션

획득한 회수품은 탈출에 성공해야 최종 보상으로 확정된다.

제한시간이 모두 소모되면 강제 각성이 발생하며, 일반 회수품은 손실된다.

다만 각성 보존 슬롯에 넣은 아이템은 보호된다.

### 서브컬처 RPG

캐릭터 자체는 손실되지 않는다.

캐릭터의 매력은 편성, 스킬 연출, 지원 호출, 대사, 성장 구조로 표현한다.

### 멀티플레이

멀티플레이는 단순히 딜량이 증가하는 구조가 아니라, 역할 분담과 위험 관리의 이점을 제공해야 한다.

예시 역할:

- 침식체 견제
- 심상기물 회수
- 다운된 팀원 구조
- 탈출 루트 확보
- 고가치 몽유물 운반
- 제한시간 관리

---

## 6. 모바일 플랫폼 설계 방향

모바일에서는 PC 수준의 정밀 조작보다, 짧은 세션과 명확한 판단을 중심으로 설계한다.

### 기본 조작

- 왼쪽 가상 조이스틱: 이동
- 오른쪽 드래그: 조준 방향 지정
- 자동 사격 또는 반자동 사격
- 회피 버튼
- 재장전 버튼
- 메인 스킬 버튼
- 지원 캐릭터 호출 버튼
- 회수 버튼
- 핑 버튼
- 탈출 요청 버튼

### 모바일 설계 원칙

- 조작은 단순하게
- 판단은 명확하게
- 버튼 수는 최소화
- 위험 정보는 아이콘과 색으로 빠르게 전달
- 제한시간 부족 알림을 명확하게 표시
- 세션 길이는 짧게 유지

## 7. 전투 시스템 방향

전투는 고정형 스테이지 슈팅이 아니라, 침몽도시 탐사 공간 안에서 실시간으로 발생하는 협동 전투를 지향한다.

플레이어는 같은 전장 안에서 이동, 조준, 사격, 회피, 회수, 구조, 탈출 판단을 수행한다.

### 전투 한 줄 정의

드림 포지드 무장으로 침식체의 몽막을 무너뜨리고, 노출된 심상핵을 팀원과 함께 공략하는 모바일 실시간 협동 슈팅 전투.

### 전투 핵심 판단

- 침식체를 피할 것인가, 싸울 것인가?
- 피해를 감수하고 보상을 노릴 것인가?
- 회수품을 챙기고 빠질 것인가?
- 팀원을 구조할 것인가?
- 지원 캐릭터를 지금 호출할 것인가?
- 보존 슬롯에 무엇을 넣을 것인가?
- 중심부로 더 들어갈 것인가?
- 탈출 지점으로 이동할 것인가?

---

## 8. 침식체 AI 컨셉 방향

침식체는 많이 몰려오는 좀비형 적이 아니라, 보상과 위험 구역을 지키는 선택형 위협으로 설계한다.

### 적 역할 구분

| 구분 | 역할 |
| --- | --- |
| 잔몽체 | 침몽도시의 불안감과 압박을 만드는 약한 개체 |
| 침식체 | 피할지 싸울지 선택하게 만드는 핵심 전투 대상 |
| 심층 침식체 / 보스 | 협동 공략과 고가치 보상을 제공하는 중심부 위협 |

### 설계 기준

- 침식체는 플레이어를 무조건 처치하기 위한 적이 아니다.
- 침식체는 고가치 보상 앞에서 선택을 강요하는 문지기 역할을 한다.
- 플레이어는 침식체를 회피하거나, 전투하거나, 협동 요청을 보낼 수 있어야 한다.
- 실제 적 배치, 수량, 동선은 레벨디자인 문서에서 구체화한다.

## 9. 멀티플레이 전투 구조

멀티플레이 전투는 같은 체력바를 함께 깎는 것이 아니라, 같은 전장 안에서 서로 다른 목적을 수행하는 구조가 되어야 한다.

### 협동 역할 예시

| 역할 | 기능 |
| --- | --- |
| 브레이커 | 몽막과 보호막 파괴 |
| 딜러 | 심상핵 노출 시 집중 피해 |
| 컨트롤러 | 적 이동 방해, 패턴 차단 |
| 서포터 | 회복, 보호막, 상태이상 해제 |
| 스카우터 | 희귀 기물 표시, 고위험 구역 확인 |
| 캐리어 | 대형 몽유물 운반 |
| 오퍼레이터 | 탈출, 보존 슬롯, 제한시간 관리 |

## 10. 루시드 공명 시스템

루시드 공명은 멀티플레이 협동의 체감을 높이기 위한 확장 시스템 방향이다.

최종 MVP에서는 기본 협동 전투와 역할 분담을 우선 구현하고, 루시드 공명은 개발 범위와 일정에 따라 MVP 이후 확장 기능으로 검토한다.

### 방향성

- 여러 플레이어가 같은 약점이나 몽막을 함께 공격할 때 협동 보너스 발생
- 몽막 붕괴 속도 증가
- 심상핵 노출 시간 증가
- 보스 패턴 일시 중단
- 회수품 오염 정지
- 드림 포지드 무장 강화

---

## 11. 제한시간 시스템

본 프로젝트는 플레이어가 침몽도시에 머무를 수 있는 시간을 제한시간으로 표현한다.

제한시간은 플레이어에게 <b>“더 깊이 들어가 보상을 노릴 것인가, 지금 가진 회수품을 지키기 위해 탈출할 것인가”</b>를 판단하게 만드는 핵심 압박 요소이다.

### 제한시간 방향

- 세션 시작 시 일정한 제한시간을 가진다.
- 제한시간 안에 탈출하면 회수품을 정산할 수 있다.
- 제한시간이 모두 소모되면 강제 각성이 발생한다.
- 강제 각성 시 일반 회수품은 손실된다.
- 각성 보존 슬롯에 넣은 아이템은 보호된다.
- 중심부로 갈수록 제한시간 소모 배율이 증가한다.
- 구체적인 시간 수치와 배율은 추후 밸런싱 단계에서 조정한다.

## 12. 회수품과 각성 보존 슬롯

회수품은 전투 중 획득해도 즉시 안전한 보상이 아니다.

탈출에 성공해야 최종 보상으로 확정된다.

### 회수품 예시

- 소형 심상기물
- 중형 몽유물
- 대형 몽유물
- 보스 심상핵
- 드림 포지드 무장 파편
- 제작 재료

### 각성 보존 슬롯

각성 보존 슬롯은 라이트 익스트랙션의 부담을 낮추는 장치이다.

| 회수품 | 슬롯 |
| --- | --- |
| 소형 심상기물 | 1칸 |
| 중형 몽유물 | 2칸 |
| 대형 몽유물 | 3칸 |
| 보스 심상핵 | 전체 슬롯 사용 |

## 13. 최소 플레이 루프 검증

최소 플레이 루프 검증의 목적은 데모 전체를 구현하는 것이 아니라, 가장 기본적인 플레이 흐름이 실제로 작동하는지 확인하는 것이다.

### 검증할 최소 루프

1. 플레이어가 2.5D 테스트 맵에 진입한다.
2. 플레이어가 맵 위에서 이동한다.
3. 적 1종이 플레이어를 따라온다.
4. 플레이어가 기본 공격을 사용한다.
5. 기본 공격이 적에게 적중한다.
6. 플레이어가 아이템 1종을 획득한다.
7. 플레이어가 탈출 지점으로 이동한다.
8. 탈출 지점에 닿으면 결과창이 출력된다.
9. 결과창에서 획득 아이템과 탈출 성공 여부를 확인한다.

### 제외 범위

- 멀티플레이
- 지원 캐릭터
- 오퍼레이터
- 보스전
- 제한시간 시스템
- 보존 슬롯
- 몽막 / 심상핵
- 루시드 공명
- 정식 보상 정산

### 성공 기준

최소 플레이 루프는 <b>“진입 → 이동 → 전투 → 회수 → 탈출 → 결과 확인”</b> 흐름이 끊기지 않고 1회 이상 반복 가능하면 성공으로 본다.

## 14. 최종 MVP 목표

최종 MVP는 최소 플레이 루프를 기반으로, 모바일 환경에서 2명의 플레이어가 같은 침몽도시 전장에 진입해 침식체와 협동 전투를 벌이고, 심상기물을 회수한 뒤 탈출하는 핵심 경험을 구현하는 것을 목표로 한다.

### MVP 콘텐츠 범위

- 맵 1개: 꿈에 먹힌 시가지
- 플레이 인원: 1\~2인 우선
- 메인 캐릭터 2명
- 지원 캐릭터 2명
- 오퍼레이터 1명
- 잔몽체 1종
- 중형 침식체 1종
- 중심부 보스 1종
- 심상기물 5종
- 드림 포지드 무장 3종
- 탈출 지점 2개
- 각성 보존 슬롯

### MVP 검증 질문

- 모바일 조작으로 실시간 쿼터뷰 전투가 가능한가?
- 2인 협동이 역할 분담으로 느껴지는가?
- 침식체가 피할지 싸울지 선택하게 만드는가?
- 회수품과 탈출 판단이 전투와 연결되는가?
- 제한시간이 욕심과 후퇴 판단을 만드는가?
- 중심부로 갈수록 제한시간 소모 부담이 체감되는가?
