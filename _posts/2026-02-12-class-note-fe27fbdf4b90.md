# 7.TargetGroupCamera

보스몹과 내 플레이어블 캐릭터가 같이 촬영 되는 경우 이 카메라로 손쉽게 구현 가능

- 여러 타겟(플레이어, 보스, NPC 등)을 하나의 그룹(Target Group)으로 묶고,
- 카메라가 그 그룹을 기준으로 <b>구도(프레이밍)와 거리(줌)를 자동 조절</b>해서 모두 화면에 들어오게 만든다.

✅한 줄 요약:

<p>
 <b>“여러 대상이 동시에 화면에 잘 잡히도록 자동으로 구도를 맞춰주는 카메라.”</b>
</p>

### 언제 강력?

- 보스전에서 <b>플레이어 + 보스</b>를 동시에 보여줘야 할 때
- 협동/멀티에서 <b>여러 플레이어</b>를 한 화면에 담을 때
- 컷신에서 <b>두 인물 대화 구도</b> 잡을 때

팁: 타겟마다 <b>Weight/Radius</b>를 다르게 주면

“보스는 크게, 플레이어는 안정적으로” 같은 연출이 가능해져서 게임 느낌이 확 살아난다.

# 8.MixingCamera

여러개의 카메라를 섞어서 하나의 결과물을 만들어 준다.

- 여러 Virtual Camera의 결과를 \*\*가중치(Weight)\*\*로 섞어서
- 하나의 최종 카메라 결과를 만든다.

한 줄 요약:

<p>
 <b>“카메라 A와 B를 0\~1 비율로 섞어서 중간 연출을 만드는 카메라.”</b>
</p>

### 언제 강력?

- 평소는 기본 추적, 특정 순간엔 살짝 클로즈업 등 <b>부드러운 연출 전환</b>
- 공포 장르에서 긴장 구간에 <b>FOV/구도</b>를 은근히 바꾸고 싶을 때
- 플레이 중에도 “연출 카메라” 느낌을 <b>티 안 나게</b> 섞고 싶을 때

팁: 스크립트나 타임라인으로 Weight를 천천히 변화시키면

<p>
컷 전환이 아니라 <b>감정선처럼 스르륵 변하는 카메라</b>가 된다. 
</p>

# 🎯 텍스처 종류 정리

## ✅ Albedo (알베도)

- 객체의 <b>기본 색상(Base Color)</b> 정보
- 조명 영향을 제외한 순수한 표면 색

👉 ❗ "빛 반사율"보다는

<b>물체가 원래 가지고 있는 색상 데이터</b>에 가깝다.

---

## ✅ Metallic (메탈릭)

- 표면이 <b>금속인지 아닌지</b>를 결정하는 값

특징:

- 금속 ↑ → 주변 환경 반사 증가
- 비금속 → 확산 반사 중심

👉 재질의 현실감을 크게 좌우하는 요소.

---

## ✅ Normal Map

- 실제로 모델링하지 않고도
  <p>
  <b>빛 계산을 속여 표면의 요철을 표현</b>하는 텍스처
  </p>

✔ 성능 대비 시각 효과가 매우 뛰어남.

👉 게임 그래픽에서 거의 필수.

---

## ✅ Height Map

- 텍스처의 높낮이 정보를 기반으로
  <p>
  표면이 실제로 돌출된 것처럼 표현
  </p>

Normal보다 더 강한 입체감을 제공.

⚠ 단점:

연산 비용 증가 → 성능 영향 가능

👉 중요한 오브젝트에 선택적으로 사용.

---

## ✅ Occlusion Map

- 간접광이 닿기 어려운 영역을 어둡게 만들어
  <p>
  <b>깊이감과 현실적인 음영</b>을 강화하는 텍스처.
  </p>

👉 평면 모델도 더 입체적으로 보이게 만든다.

---

텍스처를 어떻게 조합하느냐에 따라

같은 모델도 완전히 다르게 보인다.

## 🔥 배운 점 (포트폴리오에 쓰기 좋음)

- Shader는 단순한 그래픽 옵션이 아니라
  <p>
  👉 \*\*"빛을 설계하는 기술"\*\*이라는 것을 이해했다.
  </p>
- Normal / Metallic / Occlusion의 조합이
  <p>
  👉 환경 퀄리티를 크게 끌어올린다는 것을 학습했다.
  </p>

## ✅ Emission (에미션)

- 객체가 <b>외부 광원의 영향을 받지 않고 스스로 빛을 방출</b>하도록 만드는 속성.

👉 즉, 조명이 없어도 밝게 보인다.

---

### ✔ 특징

- 실제 빛을 계산하기보다는 <b>빛나는 것처럼 보이게 하는 효과</b>에 가깝다.
- 어두운 환경에서 시각적 강조 요소로 매우 효과적이다.

---

### ✔ 활용 사례

- 네온사인
- 전광판
- 미래형 장비
- 총구 / 에너지 코어
- 사이버펑크 환경 연출

👉 플레이어의 시선을 유도하는 장치로 자주 사용된다.

---

### ✔ 사용 시 주의점

- Emission 값을 과하게 사용하면 화면이 과포화되어
  <p>
  오히려 가독성이 떨어질 수 있다.
  </p>

👉 \*\*"강조하고 싶은 오브젝트에만 선택적으로 사용"\*\*하는 것이 중요하다.

---

## ⭐ 한 줄 정리

👉 \*\*Emission은 빛을 만드는 기능이 아니라, 시선을 설계하는 도구다.

<b>레벨 디자인 도구</b>이기도 하다.

예:

- 진행 방향 문 → 살짝 발광
- 상호작용 오브젝트 → 은은한 빛
- 위험 지역 → 강한 색 발광

## ✅ Detail Mask (디테일 마스크)

- Secondary Maps(보조 텍스처)가 <b>적용될 영역을 선택적으로 제한</b>하는 마스크 텍스처.

👉 즉,

전체 표면이 아니라 <b>특정 부분에만 추가 디테일을 표현</b>할 때 사용한다.

---

### ✔ 동작 원리

- <b>흰색(White)</b> → 디테일 텍스처 적용
- <b>검정(Black)</b> → 디테일 텍스처 미적용

👉 마스크가 적용 범위를 결정한다.

---

### ✔ 왜 중요한가?

모든 표면에 고해상도 텍스처를 사용하면:

- 성능 저하
- 시각적 노이즈 증가

Detail Mask를 활용하면

👉 <b>필요한 곳만 강조</b>할 수 있다.

---

### ✔ 활용 사례

- 벽의 긁힌 부분만 거칠게 표현
- 무기의 손잡이 부분만 디테일 강화
- 바닥의 균열 영역 강조
- 캐릭터 장비의 마모 표현

👉 현실적인 재질 표현에 매우 효과적.

---

### ✔ 사용 시 팁

- 디테일은 "많을수록 좋은 것"이 아니다.
- 강조 영역을 정해서 사용해야 시각적 완성도가 올라간다.

---

## ⭐ 한 줄 정리

👉 <b>Detail Mask는 디테일을 추가하는 기능이 아니라,"디테일을 어디에 보여줄지 결정하는 설계 도구"다.</b>

## ✅ Skybox 종류 정리

Skybox는 씬 전체를 감싸는 배경으로,

게임의 <b>분위기와 공간감을 결정하는 핵심 요소</b>이다.

---

## 🌌 6 Sided Skybox (CubeMap)

- 6개의 이미지를 사용하여 하늘을 구성하는 방식.

### ✔ 특징

## CubeMap Skybox와 SkyDome 비교 정리

### ✅ CubeMap Skybox

- 큐브맵(CubeMap)은 6개의 면(face)으로 구성된 텍스처로 하늘을 표현한다.
- 6면 이미지는 개별 6장 이미지로 만들 수도 있고, 한 장으로 펼친(Cross/Strip) 형태로 가져올 수도 있다.
- 주변 환경 반사(Reflection)에도 자주 사용된다. (Reflection Probe 등)

<b>성능/렌더링</b>

- 스카이박스는 일반적으로 화면 전체에 한 번 그려지므로
  <p>
  보통 1회 렌더 패스(≈ 1 draw call)로 처리되는 경우가 많다.
  </p>

  <p>
  <i>(프로젝트 설정/렌더 파이프라인에 따라 달라질 수 있음)</i>
  </p>

- 하늘에 구름, 별, 그라데이션 등을 커스텀하기 쉬운 편이다.

using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.InputSystem;

/// <summary>
/// TPS(3인칭 슈팅) 스타일 캐릭터 이동 + 마우스 회전 스크립트
///
/// ✔ CharacterController 기반 이동
/// ✔ 카메라 기준 이동 (TPS 표준)
/// ✔ 마우스 위치 기반 캐릭터 회전
/// ✔ Animator 파라미터 연동
///
/// 핵심 개념:
/// 👉 "입력 → 방향 계산 → 이동 → 회전 → 애니메이션"
/// </summary>
public class Movement_Player : MonoBehaviour
{
    // ================================
    // 컴포넌트 참조 영역
    // ================================

    [Header("각종 컴포넌트와 메인카메라")]

    // CharacterController:
    // Rigidbody 대신 "캐릭터 전용 이동 컴포넌트"
    // - 계단 자동 처리
    // - 충돌 안정적
    // - FPS / TPS에서 매우 많이 사용됨
    [SerializeField] private CharacterController controller;
    //캐릭터 컨트롤러 호출
    
    // Transform 캐싱
    // transform은 내부적으로 GetComponent 호출과 유사하므로
    // 반복 접근 시 변수에 저장해두는 것이 미세하게 효율적
    [SerializeField] private Transform tr;

    // 애니메이션 제어용
    [SerializeField] private Animator animator;

    // 카메라 기준 이동을 위해 필요
    [SerializeField] private Camera mainCam;

    // ================================
    // 마우스 회전용 Plane + Ray
    // ================================

    [Header("가상의 plane(바닥)에 레이캐스팅 하기위한 변수")]

    // Plane:
    // "보이지 않는 가상의 바닥"
    // 마우스가 가리키는 월드 좌표 계산에 사용됨
    [SerializeField] private Plane plane;

    // 카메라 → 마우스 방향으로 쏘는 광선
    [SerializeField] private Ray ray;

    // Ray가 plane과 충돌한 실제 월드 좌표
    [SerializeField] Vector3 hitPoint;

    // ================================
    // 이동 설정
    // ================================

    [Header("이동 속도")]
    public float moveSpeed = 10f;

    // ================================
    // Input System 관련
    // ================================

    [Header("Input")]
    [SerializeField] private PlayerInput playerInput;

    private InputActionMap actionMap;
    private InputAction moveAction;
    private InputAction lookAction;

    private Vector2 moveInput;
    private Vector2 lookScreenPos;

    private void Awake()
    {
        // 컴포넌트 캐싱
        tr = transform;
        animator = GetComponent<Animator>();
        controller = GetComponent<CharacterController>();
        mainCam = Camera.main;

        // 캐릭터 위치 기준으로 Plane 생성
        // 👉 마우스는 2D 좌표이기 때문에
        // "월드에서 어디를 가리키는지" 계산해야 한다.
        plane = new Plane(tr.up, tr.position);

        // Input System 초기화
        playerInput = GetComponent<PlayerInput>();

        // ActionMap 찾기
        actionMap = playerInput.actions.FindActionMap("PlayerActions", true);

        // 이동 / 시점 액션 연결
        moveAction = actionMap.FindAction("URPMove", true);
        lookAction = actionMap.FindAction("URPLook", true);
    }

    private void OnEnable()
    {
        // ActionMap 활성화
        actionMap.Enable();

        // C# 이벤트 방식 입력 구독
        moveAction.performed += OnURPMoveCSharp;
        moveAction.canceled += OnURPMoveCSharp;

        lookAction.performed += OnURPLookCSharp;
        lookAction.canceled += OnURPLookCSharp;
    }

    private void OnDisable()
    {
        // 이벤트 반드시 해제 (메모리 누수 방지)
        moveAction.performed -= OnURPMoveCSharp;
        moveAction.canceled -= OnURPMoveCSharp;

        lookAction.performed -= OnURPLookCSharp;
        lookAction.canceled -= OnURPLookCSharp;
    }

    void Update()
    {
        // 입력은 매 프레임 갱신되므로 Update에서 처리
        Move();
        Turn();
    }

    // ================================
    // C# 이벤트 방식 입력 처리
    // ================================

    private void OnURPMoveCSharp(InputAction.CallbackContext context)
    {
        moveInput = context.ReadValue<Vector2>();
    }

    private void OnURPLookCSharp(InputAction.CallbackContext context)
    {
        lookScreenPos = context.ReadValue<Vector2>();
    }

    // ================================
    // 마우스 방향 회전
    // ================================

    private void Turn()
    {
        // 마우스 위치 기반 Ray 생성
        ray = mainCam.ScreenPointToRay(lookScreenPos);

        float enter = 0.0f;

        // Ray와 Plane의 충돌 거리 계산
        plane.Raycast(ray, out enter);

        // 충돌 지점 월드 좌표
        hitPoint = ray.GetPoint(enter);

        // 캐릭터 → 마우스 방향 벡터
        Vector3 lookDir = hitPoint - tr.position;

        // 몸 전체가 기울어지는 것 방지
        // TPS에서는 보통 Y축 회전만 사용
        lookDir.y = 0f;

        // LookRotation:
        // 👉 "이 방향을 바라보는 회전값 생성"
        tr.localRotation = Quaternion.LookRotation(lookDir);
    }

    // ================================
    // 캐릭터 이동
    // ================================

    private void Move()
    {
        float h = moveInput.x;
        float v = moveInput.y;

        // 카메라 기준 이동 벡터 계산
        Vector3 CameraForward = mainCam.transform.forward;
        Vector3 CameraRight = mainCam.transform.right;

        // 수직 성분 제거 (캐릭터가 뜨지 않도록)
        CameraForward.y = 0f;
        CameraRight.y = 0f;

        // 정규화:
        // 👉 대각선 이동 속도가 빨라지는 현상 방지
        Vector3 moveDir =
            (CameraForward.normalized * v) +
            (CameraRight.normalized * h).normalized;

        moveDir.Set(moveDir.x, 0f, moveDir.z);

        // CharacterController 이동
        controller.SimpleMove(moveDir * moveSpeed);

        // ================================
        // 애니메이션 파라미터 계산
        // ================================

        // Dot Product:
        // 👉 "얼마나 같은 방향인가?"
        float forward = Vector3.Dot(moveDir, tr.forward);
        float strafe = Vector3.Dot(moveDir, tr.right);

        animator.SetFloat("Forward", forward);
        animator.SetFloat("Strafe", strafe);
    }
}
