## 오늘의 요약

청사진 수동·자동 회수를 구현하고 튜토리얼 구간별 이야기·연출 검토안을 작성했습니다. 첫 전투에서 정신집중 대기가 길다는 피드백을 바탕으로 청사진 밖 장비창과 자원 없는 기본 공격을 다음 작업으로 논의했습니다.

## 구현 완료

- Tab HUD에 청사진 회수 버튼 추가.
- 설치 시점의 설계자 격자 중심에서 수평 거리 12m 초과 시 자동 회수. 12m는 임시 조정값.
- 현재 거리와 한계를 표시하고 80%부터 주황색 경고.
- 파츠·편성·스킬 배정·현재 자원·코어 내구도 유지. 코어 자동 생성만 중지하며 회수는 파괴나 수리가 아님.
- 코어는 비활성화해 재사용하므로 재전개로 내구도가 회복되지 않음.
- 회수 후 재전개 가능. 자동 회복 학습 중 회수하면 재전개 안내 표시.

## 문서 작성

- 기존 상세 연출 문서 상단에 R-00\~10 검토안 추가. 새 기획 파일을 늘리지 않고 과거 후보는 보존.
- 기상 → 기억 흔적 → 빗자루와 첫 관계 → 편집·스킬 → 코어·회수 → 토벌팀 → 초가집·월도 → 영혼 해방·복귀.
- 구간마다 시작 조건, 행동, 대사, 시각 연출, 완료 조건, 막힘 처리를 작성.
- 최초 빗자루 획득 순서와 기록 수는 기존안과 차이가 있어 승인 전으로 표시.

## 플레이 피드백과 설계 방향

- 사용자 피드백: 첫 전투에서 에너지를 회복하며 싸우는 대기 시간이 너무 김.
- 장비창은 직접 착용하는 무기·방어구, 청사진은 파츠·재료를 배치·전개하는 공간으로 구분하는 방향에 합의.
- 대원의 무기를 획득·장착하고 코어 자원을 쓰지 않는 좌클릭 기본 공격을 먼저 구현할 계획.
- 초기 범위는 기본 무기 슬롯 1개. 무기 종류·수치·드롭 위치는 미정.
- Tab 화면을 청사진 탭과 장비 탭으로 분리하자는 사용자 제안 기록.
- 입력안: 평상시 좌클릭 공격, 청사진 전개 화면 좌클릭 설치, 장비·편집 화면 좌클릭 UI 조작. 탭 전환만으로 자동 회수하지 않음.
- 여분 장비는 청사진에 보관하고 장비 교체 시 빈 공간을 검사하는 안은 제안 단계.

## 상태 구분

장비 슬롯, 기본 공격, 장비 탭은 아직 구현하지 않았습니다. 오늘 작성한 시나리오 초안도 이후 기본 무기 획득 흐름에 맞춘 재검토가 필요합니다. 초가집·월도·영혼 해방과 실제 적 AI는 미구현 후속 범위입니다.
