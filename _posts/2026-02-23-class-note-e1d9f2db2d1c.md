## 요약


### 실습 과제

- [x] 송카실: Enemy에서 구현한 리로드 시스템을 SWAT 캐릭터에도 동일하게 구현

### 학습 목표

오늘 수업의 주요 학습 목표는 10발을 발사하면 자동으로 Reload 애니메이션이 실행되는 재장전 시스템 구현    

### 무기 소켓 설정

- 캐릭터 리그에서 스파인 → 넥 → 라이트 숄더 → 라이트 핸드로 이동하여 R Hand만 체크  
- 라이트 핸드에 빈 오브젝트를 생성하고 "라이트 웨폰 소켓"으로 명명  
- 웨폰 소켓 하위에 총(Shotgun01) 배치 및 FirePos 설정 
- 수작업으로 위치 조정 완료 

### Avatar Mask 개념 및 활용

<b>Avatar Mask란</b>: 애니메이션이 적용될 신체 부위를 선택적으로 제어하는 기능  

<b>사용 이유</b>:

- 리로드 애니메이션이 앉아서 재장전하는 동작이기 때문에, 하체는 제외하고 상체만 적용하기 위해 사용   
- 달리기(하체)와 사격(상체)을 동시에 재생하기 위해 레이어를 분리하고 상체에만 영향을 주도록 설정
- 옛날에는 서서 재장전/앉아서 재장전 애니메이션을 따로 만들어야 했지만, Avatar Mask로 런타임에서 조합 가능  

<b>설정 방법</b>:

- Animations 폴더에서 Create → Avatar Mask 생성 
- "Enemy\_Reload"로 명명  
- Humanoid 본 구조에서 상체(어깨부터 손까지)만 활성화하고 나머지는 비활성화    

<b>실전 적용 사례</b>:

- 말을 타면서 창을 휘두르는 장면: 서서 창 휘두르는 애니메이션에서 하체를 제외하고 상체만 가져와서 사용   

### Animator Layer 구성

<b>레이어 분리</b>:

- Base Layer를 "Movement Layer"로 이름 변경 (동적인 움직임 담당)   
- 새로운 레이어 추가: "Reload Layer"   

<b>Reload Layer 설정</b>:

- Weight: 1 (완전히 적용)   
- Mask: Enemy\_Reload 선택   
- Blending: Override 모드 선택  
- IK Pass: 현재는 체크하지 않음 (나중에 학습 예정)  

### Blending 옵션 이해

<b>Override (덮어쓰기)</b>:

- 위 레이어가 아래 레이어를 완전히 교체  
- 해당 본을 완전히 바꾸며, Weight가 1이면 아래 애니메이션 무시
- 사격, 재장전처럼 정확한 동작이 필요할 때 사용

<b>Additive (더하기)</b>:

- 아래 애니메이션 위에 변화값을 더함 
- 기본 포즈를 유지하면서 미세한 움직임 추가
- 반동, 숨쉬기, 고개 움직임 등에 적합

### Weight(가중치) 개념

<b>Weight의 역할</b>: IK를 얼마나 세게 적용할지 조절하는 값 (0\~1 범위)

<b>Weight 값별 효과</b>:

- Weight = 0: 애니메이션 원본 그대로, IK 영향 0%
- Weight = 0.3\~0.8: 애니메이션과 IK가 혼합되어 부드럽게 적용
- Weight = 1: 목표 위치에 완전히 고정, IK 영향 100%

<b>Weight 종류</b>:

- Position Weight: 손/발의 위치를 타겟에 얼마나 맞출지
- Rotation Weight: 손/발의 회전(방향)을 얼마나 맞출지
- LookAt Weight: 머리/몸통이 시선 타겟을 얼마나 볼지

<b>활용 예시</b>:

- 총 잡은 오른손: Position Weight = 1, Rotation Weight = 1 (완전 고정)
- 왼손(총 받침): Position Weight = 0.6, Rotation Weight = 0.3 (유연하게)
- 계단에서 발 IK: 평소 Weight = 0, 계단 감지 시 Lerp로 0→1 증가

### IK Pass 이해

<b>IK Pass란</b>: 레이어에서 IK 계산을 허용할지 결정하는 체크박스  

<b>동작 원리</b>:

- 애니메이션 클립 계산 → 레이어 블렌딩 → IK 계산 (IK Pass 활성화된 레이어만) → 최종 포즈 확정
- IK Pass가 꺼져 있으면 <code>OnAnimatorIK()</code>에서 SetIKPosition을 호출해도 무시됨
- 레이어마다 개별 설정 가능

<b>사용 예시</b>:

- Base Layer (이동): IK 불필요 → IK Pass 끔
- Upper Body Layer (총 조준): 손 IK 필요 → IK Pass 켬

### FK와 IK 개념

<b>FK (Forward Kinematics) - 전진 운동학</b>:

- 부모 뼈부터 순차적으로 회전시켜 끝(손/발)을 움직이는 방식  
- 현실 세계의 움직임: 어깨 → 팔 → 손목 → 손가락 순서로 동작  
- 애니메이션 클립의 기본 방식으로 자연스럽고 안정적
- 사람 중심의 움직임

<b>IK (Inverse Kinematics) - 역 운동학</b>:

- 끝 위치를 먼저 정하고 관절을 자동 계산하는 방식  
- 게임 세계의 움직임: 손목 → 팔 → 어깨 (무기 중심)   
- 정확한 위치 고정에 유리 (계단, 벽, 총 조준 등)
- 무기 중심의 움직임   

<b>실무 적용</b>:

- 게임에서는 "FK + IK 조합" 사용
- 기본 애니메이션은 FK, 마지막에 IK로 미세 보정
- FK는 자연스러운 기본 동작, IK는 환경 반응 및 정밀 제어

### 애니메이션 설정

<b>리로드 애니메이션 준비</b>:

- Idle\_Reload\_SMG 애니메이션 사용 (앉아서 재장전하는 동작)   
- 문제점: 앉은 자세로 재장전하면 부자연스러움  
- 해결: Avatar Mask로 하체 제외, 상체만 적용 

<b>Animator 구성</b>:

- Entry → New State → Idle\_Reload\_SMG로 Transition 연결   
- New State 사용 이유: 급격한 전환을 완화하고 시간 여유 제공  
- Parameter에 "Reload" 트리거 추가    

<b>Transition 설정</b>:

- 올라가는 Transition: Has Exit Time 체크 해제, Duration 0.03  
- New State로 올라가는 Transition: Has Exit Time 체크 해제, Duration 0.03 
- Idle\_Reload\_SMG에서 내려오는 Transition: Has Exit Time 유지, Duration 0.03만 설정 

### 코드 구현

<b>변수 선언</b>:

- <code>int hashReload</code>: Animator.StringToHash("Reload")로 초기화 (해시값으로 최적화)   
- <code>float reloadTime = 2f</code>: 재장전 소요 시간 
- <code>int maxBullet = 10</code>: 최대 탄창   
- <code>int curBullet = 10</code>: 현재 탄약  
- <code>bool isReload = false</code>: 재장전 중 여부 플래그  
- <code>AudioClip reloadClip</code>: 재장전 사운드  
- <code>WaitForSeconds wsReload</code>: 코루틴 최적화용  

<b>재장전 플래그 목적</b>:

- 재장전 중 총알 발사 방지  
- 사용자가 재장전 중에도 발사 버튼을 누를 수 있기 때문에 필요
- 예상치 못한 사용자 행동 대비 (테스트 중 발견된 다양한 엣지 케이스)   

<b>Fire 메서드 수정</b>:

- 조건: <code>if (isFire &amp;&amp; !isReload)</code> - 발사 가능하고 재장전 중이 아닐 때만  
- 발사 시 <code>curBullet--</code>로 탄약 감소 
- 탄약 소진 조건: <code>if (curBullet % maxBullet == 0)</code> - 나머지 연산으로 0 확인   
- 조건 충족 시 <code>isReload = true</code> 및 <code>StartCoroutine(Reloading())</code> 호출  

<b>Reloading 코루틴</b>:

- 즉시 애니메이션 트리거: <code>anim.SetTrigger(hashReload)</code>   
- 사운드 재생: <code>soundSource.PlayOneShot(reloadClip)</code> 
- 재장전 시간 대기: <code>yield return wsReload</code>  
- 탄약 재충전: <code>curBullet = maxBullet</code> 
- 플래그 해제: <code>isReload = false</code>  

<b>Start 메서드 최적화</b>:

- <code>wsReload = new WaitForSeconds(reloadTime)</code>를 Start에서 미리 할당 
- 이유: 코루틴 내에서 매번 new로 생성하면 가비지 컬렉션 부담 증가

<b>사운드 설정</b>:

- Resources/Sound에서 P\_UnderBarrel\_Reload 사운드 찾기  
- F2로 복사하여 Sound 폴더에 배치 
- Inspector에서 reloadClip에 할당

- 강사가 Enemy 캐릭터로 시연 후, 학생들이 SWAT 캐릭터에 동일하게 구현

- 제출 시 빌드 불필요, 코드와 작동 화면 캡처만 제출

## Override (덮어쓰기 모드)

> 위 레이어가 아래 레이어를 <b>교체한다</b>

### 특징

- 해당 본(Bone)을 <b>완전히 바꿈</b>
- Weight가 1이면 아래 애니메이션은 무시
- Avatar Mask와 같이 많이 사용

### 예시

- 하체는 달리기
- 상체는 사격

상체 레이어가 Override라면

사격 애니메이션이 상체를 <b>완전히 장악함</b>.

총 쏠 때 팔 모양이 정확히 유지됨

깔끔하고 예측 가능함

---

## Additive (더하기 모드)

> 아래 애니메이션 위에 <b>변화값을 더한다</b>

### ✔특징

- 기본 포즈를 기준으로 “차이값”을 더함
- 원본 애니메이션을 유지하면서 변형
- 미세한 움직임에 좋음

- Additive로 상체에 리코일(반동) 추가
- Additive로 숨쉬기 모션 추가
- Additive로 고개 살짝 기울이기

<p>
 기존 동작은 유지
</p>

<p>
 그 위에 살짝 얹는 느낌

## 언제 동작하냐면

애니메이션 재생 순서는 대략 이런 흐름이야:

1\. 애니메이션 클립 계산

2\. 레이어 블렌딩 (Override / Additive 적용)

3\. IK 계산 (IK Pass가 켜져 있는 레이어만)

4\. 최종 포즈 확정

즉, <b>IK는 애니메이션이 다 계산된 뒤 마지막에 덮어쓴다</b>는 느낌이야.

---

<h2>
 어디서 켜는지
</h2>

Animator 창 →

Layer 선택 →

Inspector →

<p>
 <b>IK Pass 체크</b>
</p>

레이어마다 따로 설정해야 함.

---

<h2>
 왜 레이어마다 따로 있냐면
</h2>

예를 들어:

- Base Layer → 이동 애니메이션 (IK 필요 없음)
- Upper Body Layer → 총 조준 (손 IK 필요)

그럼 상체 레이어에만 IK Pass 켜면 됌.

괜히 전체 레이어에 켜둘 필요는 없음.

<details markdown="1">
<summary>FK<b>(Forward Kinematic)</b>와 IK(Inverse  Kinematic)</summary>


<b>FK(Forward Kinematic) 전진 운동학, 검을 휘두를 때<br />현실세계 : 어깨 -> 팔 ->손목 사람 중심으로 움직인다.</b>

IK (Inverse  Kinematic)  역 운동학, 게임 검을 휘두를 때<br />게임가상세계 :손목 -> 팔-> 어깨 무기 중심으로 움직인다

# FK (Forward Kinematics)

### 개념

부모 뼈부터 차례대로 회전시켜서

끝(손, 발)을 움직이는 방식.

어깨 → 팔꿈치 → 손

위에서 아래로 “전달”되는 구조.

<h3>
 특징
</h3>

<p>
 애니메이션 클립의 기본 방식
</p>

자연스럽고 안정적

예측 가능

계산이 가볍다

<h3>
 단점
</h3>

“손을 정확히 저 벽에 붙여!”

같은 정확한 위치 맞추기는 어렵다.

# IK (Inverse Kinematics)

### 개념

끝 위치를 먼저 정한다.

그 위치에 맞게 관절을 자동 계산한다.

“손을 여기로!”

→ 어깨와 팔꿈치가 자동으로 맞춰짐

### 특징

<p>
 정확한 위치 고정 가능
</p>

환경 반응에 강함 (계단, 벽, 총 조준)

실시간 보정 가능

<h3>
 단점
</h3>

<p>
 계산량이 FK보다 많음
</p>

<p>
 잘못 쓰면 팔이 꺾이거나 튐
</p>

<p>
 Weight 조절 필수
</p>

<h1>
 게임에서의 실제 사용법
</h1>

| 상황 | FK | IK |
| --- | --- | --- |
| 달리기 애니메이션 | ✅ | ❌ |
| 공격 모션 | ✅ | ❌ |
| 총을 정확히 조준점에 맞추기 | ❌ | ✅ |
| 계단에서 발 보정 | ❌ | ✅ |
| 자연스러운 기본 동작 | ✅ | 보조 |

# 중요한 포인트

실제로는 “FK vs IK”가 아니라

<b>FK + IK 조합</b>

1. 기본 애니메이션은 FK
2. 마지막에 IK로 미세 보정

유니티 Animator 흐름도:

애니메이션 계산 → 레이어 블렌딩 → IK Pass → 최종 포즈

<summary>실습 스크린샷</summary>


```cs
        using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class SwatFire : MonoBehaviour
{
    [SerializeField] private GameObject S_bullet;
    public Transform S_firePos;
    private AudioSource source;
    [SerializeField] private AudioClip fireClip;
    [SerializeField] private Transform playerTr;
    [SerializeField] private Transform swatTr;
    private readonly float fireRate = 0.1f;
    private float nextFire = 0.0f;
    private readonly float damping = 10f;
    public bool isFire = false;
    private readonly int hashFire = Animator.StringToHash("Fire");
    private readonly int hashReload = Animator.StringToHash("Reload");
    private Animator animator;
    //재장전
    private readonly float reloadTime = 2.0f;
    private readonly int maxBullet = 10;
    private int curBullet = 10;
    private bool isReload = false;
    private WaitForSeconds wsReload;
    [SerializeField] private AudioClip reloadClip;
    void Start()
    {
        S_bullet = Resources.Load("S_bullet")as GameObject; 
        //Resources.Load는 프로젝트의 Resources 폴더에서 리소스를 로드하는 메서드          //"S_bullet"이라는 이름의 GameObject를 로드하여 S_bullet 변수에 할당.
        source = GetComponent<AudioSource>(); 
        //현재 게임 오브젝트에 부착된 AudioSource 컴포넌트를 가져와서 source 변수에 할당.
        fireClip = Resources.Load<AudioClip>("p_m4_1"); 
        //Resources.Load를 사용하여 "p_m4_1"이라는 이름의 AudioClip을 로드하여 fireClip 변수에 할당.
        reloadClip = Resources.Load<AudioClip>("Sounds/p_shotgun_reload") as AudioClip; 
        //Resources.Load를 사용하여 "Sounds/p_shotgun_reload"이라는 이름의 AudioClip을 로드하여 reloadClip 변수에 할당.
        playerTr = GameObject.FindWithTag("Player").transform; 
        //GameObject.FindWithTag("Player")는 "Player" 태그가 붙은 게임 오브젝트를 찾아서 해당 오브젝트의 Transform 컴포넌트를 가져와 playerTr 변수에 할당.
        swatTr = GetComponent<Transform>(); 
        //현재 게임 오브젝트의 Transform 컴포넌트를 가져와서 swatTr 변수에 할당.
        animator = GetComponent<Animator>(); 
        //현재 게임 오브젝트에 부착된 Animator 컴포넌트를 가져와서 animator 변수에 할당.
        wsReload = new WaitForSeconds(reloadTime); 
        //새로운 WaitForSeconds 객체를 생성하여 reloadTime(2초) 동안 대기하는 wsReload 변수에 할당. 이 객체는 코루틴에서 재장전 대기 시간으로 사용됨.
    }
    void Update()
    {
        if (isFire && !isReload) 
            //isFire가 true이고 isReload가 false인 경우에만 총을 발사할 수 있도록 조건을 설정.
        { 
            if (Time.time >= nextFire) 
                //현재 게임 시간(Time.time)이 nextFire보다 크거나 같은 경우에만 총을 발사할 수 있도록 조건을 설정. 이는 발사 간격을 제어하기 위한 조건입니다.
            {
                Fire(); //Fire() 메서드를 호출하여 총을 발사하는 기능을 수행.
                nextFire = Time.time + fireRate + Random.Range(0, 0.3f); 
                //총 발사 후 다음 발사 가능 시간을 현재 시간(Time.time)에 fireRate(0.1초)와 0에서 0.3초 사이의 랜덤 값을 더하여 계산하여 nextFire 변수에 할당.
                Quaternion rot = Quaternion.LookRotation(playerTr.position - swatTr.position); 
                //playerTr.position - swatTr.position는 플레이어와 스왓의 위치 차이를 나타내며, Quaternion.LookRotation()은 이 벡터를 향하도록 회전을 계산하여 rot 변수에 할당.
                swatTr.rotation = Quaternion.Slerp(swatTr.rotation, rot, Time.deltaTime * damping); 
                //현재 스왓의 회전(swatTr.rotation)과 목표 회전(rot) 사이를 Slerp(구면 선형 보간)를 사용하여 부드럽게 회전시키는 코드입니다. Time.deltaTime * damping은 회전 속도를 제어하는 요소로, 프레임 간의 시간 차이에 따라 회전이 부드럽게 이루어지도록 합니다.

            }
        }
    }
    void Fire() //총 발사 기능을 수행하는 메서드입니다.
    {
        Instantiate(S_bullet, S_firePos.position, S_firePos.rotation); 
        //Instantiate() 메서드를 사용하여 S_bullet 프리팹을 S_firePos의 위치와 회전으로 생성합니다.
        //이는 총알이 발사되는 위치와 방향을 설정하는 역할을 합니다.
        animator.SetTrigger(hashFire); 
        //animator.SetTrigger() 메서드를 사용하여 "Fire" 트리거를 활성화하여 총 발사 애니메이션을 재생합니다.
        //hashFire는 "Fire" 문자열의 해시값으로, 애니메이터에서 해당 트리거를 식별하는 데 사용됩니다.
        source.PlayOneShot(fireClip, 1.0f); 
        //source.PlayOneShot() 메서드를 사용하여 fireClip 오디오 클립을 1.0f 볼륨으로 재생합니다.
        //이는 총 발사 소리를 재생하는 역할을 합니다.

        isReload = (--curBullet % maxBullet == 0); 
        //curBullet를 1 감소시키고, 감소된 curBullet이 maxBullet로 나누어 떨어지는 경우(isReload가 true)가 되도록 설정합니다.
        //이는 총알이 모두 발사된 후 재장전이 필요하다는 것을 나타냅니다.
        if (isReload) //isReload가 true인 경우, 즉 총알이 모두 발사된 후 재장전이 필요한 경우에만 Reloading() 코루틴을 시작합니다.
        {
            StartCoroutine(Reloading()); //Reloading() 코루틴을 시작하여 재장전 과정을 수행합니다.
                                         //이 코루틴은 재장전 애니메이션을 재생하고, 재장전 소리를 재생하며,
                                         //일정 시간 동안 대기한 후 isReload를 false로 설정하여 다시 총을 발사할 수 있도록 합니다.
        }
    }
    IEnumerator Reloading() //재장전 과정을 수행하는 코루틴입니다.
    {
        animator.SetTrigger(hashReload); 
        //animator.SetTrigger() 메서드를 사용하여 "Reload" 트리거를 활성화하여 재장전 애니메이션을 재생합니다.
        //hashReload는 "Reload" 문자열의 해시값으로, 애니메이터에서 해당 트리거를 식별하는 데 사용됩니다.
        source.PlayOneShot(reloadClip, 1.0f); 
        //source.PlayOneShot() 메서드를 사용하여 reloadClip 오디오 클립을 1.0f 볼륨으로 재생합니다.
        //이는 재장전 소리를 재생하는 역할을 합니다.
        yield return wsReload; 
        //yield return을 사용하여 wsReload(2초 동안 대기하는 WaitForSeconds 객체)를 반환하여 재장전 대기 시간을 설정합니다.
        //이 동안 코루틴은 일시 중지되고, 대기 시간이 끝나면 다시 실행됩니다.
        isReload = false; 
        //재장전이 완료된 후 isReload를 false로 설정하여 다시 총을 발사할 수 있도록 합니다.
    }
}
```

<summary>Quaternion.Euler 과 Quaternion.LookRotation</summary>


# <code>Quaternion.Euler</code> 의 정의

<code>Quaternion.Euler(x, y, z)</code> 는

<b>오일러 각(Euler Angles)을 Quaternion 회전 값으로 변환하는 함수</b>이다.

즉,


<blockquote markdown="1">


X, Y, Z 축을 기준으로 각각 회전할 각도를 입력하면

그 회전을 표현하는 Quaternion을 생성한다.

</blockquote>


---

<h3>
 수학적 의미
</h3>

- 입력: (x°, y°, z°) → 각 축 회전 각도
- 출력: 해당 회전을 표현하는 Quaternion (x, y, z, w)

Unity 내부 회전은 Quaternion으로 처리되기 때문에,

사람이 이해하기 쉬운 “각도 기반 회전”을

엔진이 사용하는 “Quaternion 기반 회전”으로 변환하는 역할을 한다.

---

### 사용 예

```txt
transform.rotation=Quaternion.Euler(0f,90f,0f);
```

→ Y축 기준 90도 회전하는 Quaternion 생성

---

<h1>
 <code>Quaternion.LookRotation</code> 의 정의
</h1>

<code>Quaternion.LookRotation(direction)</code> 은

<b>주어진 방향 벡터를 바라보도록 회전하는 Quaternion을 생성하는 함수</b>이다.

즉,

> 특정 방향(Vector3)을 향하도록 오브젝트의 forward 방향을 맞춰주는 회전을 만든다.

---

### 수학적 의미

- 입력: 방향 벡터 (Vector3)
- 출력: 그 방향을 forward 축으로 가지는 Quaternion

내부적으로는:

- forward 축을 입력 벡터 방향으로 설정
- right, up 벡터를 직교하도록 계산
- 그 결과로 회전 행렬 → Quaternion 변환

---

### 사용 예

```txt
Vector3dir=player.position-transform.position;
transform.rotation=Quaternion.LookRotation(dir);
```

→ 오브젝트가 player를 바라보게 됨

---

<h1>
 핵심 차이 정리
</h1>

| 함수 | 기준 | 의미 |
| --- | --- | --- |
| <code>Quaternion.Euler</code> | 각도 | “이만큼 회전해” |
| <code>Quaternion.LookRotation</code> | 방향 벡터 | “저 방향을 바라봐” |

---

# 개념적 차이 한 줄 요약

- <b>Euler는 회전값을 직접 지정하는 방식</b>
- <b>LookRotation은 목표 방향을 기준으로 회전을 계산하는 방식</b>

```cs
    }
}
```
