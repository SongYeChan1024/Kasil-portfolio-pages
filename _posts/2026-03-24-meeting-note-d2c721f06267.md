<b>오전 회의</b> 2026-03-24

## 요약

### 진행 상황 보고

- <b>로비/스테이지 전환 시스템</b>: 로비에서 엔터 버튼으로 정해진 스테이지 이동 기능 기본 구현 완료. 스테이지 체크포인트 선택 후 해당 위치에 유저 스폰하는 기능 구현 필요.
- <b>플레이어 애니메이션</b>: 동굴맵 전용 플레이어 움직임 방식 변경에 따른 애니메이션 작업 진행 중.
- <b>공간 퍼즐 맵</b>: 기능적 구현 완료. 연출 부분 추가 작업 중.
- <b>엔딩 작업</b>: 스테이지 선택 기능 구현 후 엔딩 씬 전환 및 타이틀/게임 종료 흐름 작업 예정. UI는 별도로 반영 예정.

### 액션 아이템

- [ ] 스테이지 체크포인트 선택 시스템 구현 - 선택한 체크포인트에 유저 스폰 기능 추가
- [ ] 동굴맵 플레이어 애니메이션 작업 완료
- [ ] 공간 퍼즐 맵 연출 추가
- [ ] 엔딩 씬 전환 및 게임 흐름 기능 구현
- [ ] 각 팀원이 퍼즐별로 필요한 플레이어 조작 기능/애니메이션 정리하여 공유 (예: 레버 조작 애니메이션 등)

### 주요 결정 사항

- 플레이어 관련 모든 기능을 한 명이 통합 구현하는 방식으로 진행
- 각 팀원은 자신의 퍼즐에 필요한 플레이어 기능 요구사항을 정리하여 전달

# 스토리·퍼즐·탐험형 게임 프로젝트 진행 체크리스트

## 1. 게임 방향성

- [ ] 게임의 핵심 한 줄 소개가 정리되어 있다
- [ ] 게임의 분위기와 감정 톤이 정리되어 있다
- [ ] 플레이어가 무엇을 하게 되는 게임인지 명확하다
- [ ] 이 게임만의 차별점이 정리되어 있다
- [ ] 전체 플레이 흐름이 기승전결로 정리되어 있다
- [ ] 시작, 중간, 끝의 경험이 구분되어 있다

예시:

- “잃어버린 기억/감정/음악 조각을 찾아 퍼즐을 풀며 앞으로 나아가는 감성 탐험 게임”
- “NPC와 상호작용하며 선택에 따라 분위기와 결과가 달라지는 서사형 게임”

---

## 2. 스토리 / 세계관

- [ ] 게임 배경 설정이 정리되어 있다
- [ ] 플레이어의 목표가 명확하다
- [ ] 왜 이 공간을 탐험하는지 이유가 있다
- [ ] 주요 오브젝트와 공간에 의미가 부여되어 있다
- [ ] 스토리 진행에 따라 분위기 변화가 있다
- [ ] 엔딩 또는 마무리 흐름이 정리되어 있다

체크 포인트:

- 플레이어가 “왜 여기서 이 퍼즐을 풀어야 하는지” 이해되는가
- 스토리와 퍼즐이 따로 노는 느낌은 없는가
- 공간 연출이 이야기와 연결되는가

---

## 3. 플레이 구조

- [ ] 기본 플레이 루프가 정리되어 있다
- [ ] 탐험 → 발견 → 상호작용 → 퍼즐 해결 → 다음 구역 진입 흐름이 자연스럽다
- [ ] 플레이어가 해야 할 일이 구간별로 명확하다
- [ ] 막혔을 때 다음 행동을 유추할 수 있다
- [ ] 튜토리얼 없이도 어느 정도 이해 가능하다
- [ ] 필요할 경우 힌트 장치가 있다

예시 루프:

- 주변 조사
- 오브젝트 발견
- 단서 확인
- 퍼즐 해결
- 연출 재생
- 다음 공간 개방

---

## 4. 퍼즐 설계

- [ ] 퍼즐 종류가 정리되어 있다
- [ ] 각 퍼즐의 목표가 한 문장으로 설명 가능하다
- [ ] 퍼즐의 입력 방식이 직관적이다
- [ ] 정답 조건과 실패 조건이 명확하다
- [ ] 퍼즐 난이도가 갑자기 튀지 않는다
- [ ] 퍼즐 해결 후 보상이 있다
- [ ] 퍼즐과 맵 구조가 연결되어 있다
- [ ] 퍼즐이 반복만 되고 있지 않은지 점검했다

퍼즐별 정리 양식:

- 퍼즐 이름:
- 플레이어 목표:
- 필요한 단서:
- 조작 방식:
- 성공 조건:
- 실패 / 리셋 방식:
- 성공 시 변화:

---

## 5. 맵 / 공간 설계

- [ ] 전체 맵 구조가 정리되어 있다
- [ ] 플레이어 동선이 자연스럽다
- [ ] 길 찾기가 너무 어렵지 않다
- [ ] 중요한 오브젝트가 잘 보인다
- [ ] 배경과 상호작용 오브젝트가 구분된다
- [ ] 구역마다 분위기 차이가 있다
- [ ] 스테이지별 테마가 살아 있다
- [ ] 불필요하게 넓거나 비어 있는 공간이 없다

체크 포인트:

- 플레이어가 어디로 가야 하는지 시선 유도가 되는가
- 장식물 때문에 길이 헷갈리지는 않는가
- 퍼즐 공간과 이동 공간이 분리되어 있는가

---

## 6. 상호작용 요소

- [ ] 상호작용 가능한 오브젝트가 정리되어 있다
- [ ] 상호작용 UI가 명확하다
- [ ] 줍기 / 조사 / 작동 / 대화 구분이 된다
- [ ] 상호작용 후 피드백이 즉시 나온다
- [ ] 플레이어가 지금 무엇을 작동시켰는지 알 수 있다
- [ ] 오작동이나 중복 입력 문제를 점검했다

예시 항목:

- 문
- 레버 / 버튼
- 수집 아이템
- 퍼즐 조각
- 메모 / 악보 / 단서
- NPC 대화
- 이벤트 트리거

---

## 7. 연출 / 감정선

- [ ] 시작 연출이 준비되어 있다
- [ ] 퍼즐 성공 연출이 준비되어 있다
- [ ] 중요한 장면에 카메라 / 조명 / 사운드 변화가 있다
- [ ] 감정적으로 강조해야 할 장면이 정리되어 있다
- [ ] 엔딩 연출이 준비되어 있다
- [ ] 연출이 너무 길어서 흐름을 끊지 않는지 점검했다

연출 체크:

- 퍼즐 성공 순간에 성취감이 느껴지는가
- 배경음 / 효과음 / 빛이 장면과 맞는가
- 컷신 없이도 분위기를 전달할 수 있는가

---

## 8. 아트 / 분위기

- [ ] 전체 색감과 비주얼 톤이 통일되어 있다
- [ ] 주요 배경 오브젝트가 준비되었다
- [ ] 퍼즐 오브젝트가 눈에 띄게 디자인되었다
- [ ] 캐릭터 / NPC / 장식물의 스타일이 맞는다
- [ ] 텍스처와 머티리얼이 전체 분위기와 어울린다
- [ ] 라이팅이 게임 감정선과 맞는다
- [ ] 과하게 튀는 에셋이 없는지 점검했다

분위기 체크 예시:

- 몽환적
- 쓸쓸함
- 따뜻함
- 불안함
- 신비로움
- 동화풍
- 폐허 감성
- 음악적 / 감정적 공간감

---

## 9. 사운드

- [ ] 배경음악의 방향성이 정리되어 있다
- [ ] 구간별 BGM 변화가 있다
- [ ] 상호작용 효과음이 들어가 있다
- [ ] 퍼즐 성공 / 실패 효과음이 있다
- [ ] UI 효과음이 있다
- [ ] 공간 분위기에 맞는 환경음이 있다
- [ ] 사운드 크기 밸런스가 맞는다

체크 포인트:

- 퍼즐 성공했는데 소리가 약해서 성취감이 없는가
- BGM이 너무 커서 대사나 효과음을 덮지 않는가
- 정적이 필요한 장면에 소리가 너무 많지 않은가

---

## 10. 프로그래밍

- [ ] 플레이어 이동이 안정적이다
- [ ] 카메라 조작이 어색하지 않다
- [ ] 상호작용 시스템이 안정적으로 작동한다
- [ ] 퍼즐 상태 관리가 된다
- [ ] 이벤트 트리거가 정상 작동한다
- [ ] UI 연결이 완료되었다
- [ ] 씬 전환 또는 구역 전환이 정상 작동한다
- [ ] 저장 또는 진행 상태 관리가 가능하다
- [ ] 디버그용 확인 방법이 있다
- [ ] 예외 상황에서 게임이 멈추지 않는다

특히 체크할 것:

- 퍼즐 완료 후 문이 열리지 않는 문제
- 상호작용 중복 입력
- 트리거 중복 실행
- 애니메이션과 로직 타이밍 불일치
- 사운드가 여러 번 겹쳐 재생되는 문제

---

## 11. QA / 플레이 테스트

- [ ] 처음 하는 사람이 목표를 이해했다
- [ ] 어디서 막히는지 기록했다
- [ ] 퍼즐 난이도가 적절한지 확인했다
- [ ] 이동이나 카메라가 불편하지 않은지 확인했다
- [ ] 분위기는 좋지만 지루하지 않은지 확인했다
- [ ] 연출이 과하게 길지 않은지 확인했다
- [ ] 버그를 우선순위별로 정리했다
- [ ] 빌드 테스트를 진행했다
- [ ] 다른 PC에서 실행 확인을 했다

플레이테스트 질문 예시:

- 무엇을 해야 하는지 바로 이해됐는가?
- 어디에서 가장 오래 막혔는가?
- 어떤 장면이 가장 인상 깊었는가?
- 조작이 불편했던 부분이 있었는가?
- 퍼즐이 재밌었는가, 귀찮았는가?

---

## 12. 발표 / 시연 준비

- [ ] 게임 소개 한 줄이 준비되어 있다
- [ ] 장르 / 핵심 재미 / 차별점이 정리되어 있다
- [ ] 팀원별 담당 역할이 정리되어 있다
- [ ] 구현한 핵심 시스템을 설명할 수 있다
- [ ] 트러블슈팅 사례를 정리했다
- [ ] 시연 순서가 정리되어 있다
- [ ] 발표 자료가 준비되어 있다
- [ ] 발표 대본이 준비되어 있다
- [ ] 최종 빌드가 준비되어 있다

발표에서 강조하면 좋은 것:

- 왜 이런 분위기와 테마를 잡았는지
- 퍼즐과 스토리를 어떻게 연결했는지
- 플레이어 감정선을 어떻게 설계했는지
- 구현 중 가장 어려웠던 문제와 해결 방식

# 팀 프로젝트에서 특히 자주 놓치는 항목

- [ ] 분위기만 있고 할 일이 없는 구간은 없는가
- [ ] 퍼즐 성공 후 보상이 충분한가
- [ ] 플레이어가 길을 잃지 않는가
- [ ] 연출 때문에 템포가 너무 느려지지 않는가
- [ ] 장식물과 핵심 오브젝트가 헷갈리지 않는가
- [ ] 발표 때 보여줄 핵심 장면이 준비되어 있는가

<summary>전체 받아쓰기 펼치기</summary>


이렇게 해서 로비에서 스테이지로 넘어가는 기능을 좀 만져보고 있거든요 일단 로비에서 엔터 버튼을 눌렀을 때 정해진 스테이지에 이동하는 것 까지는 기본적으로는 됐고, 스테이지에서 체크포인트를 골라서 넘어가는 것은 구현을 해줘야 되고요.

스테이지 체크포인트 리스트에서 스테이지랑 체크포인트를 선택해 선택한 체크포인트에 체크포인트에 유저를 스폰하면서 육지침동을 넘어가는게 제일 필요하거든요

다른 분들은 뭐하고 계시죠 지금?
