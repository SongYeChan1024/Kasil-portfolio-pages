## 요약

- 오늘 한 일:
  <ul>
  <li>
  패트롤 테스트 씬(<code>DemoScene Patrol</code>)을 인게임 세션으로 인식하도록 씬 판정 로직을 배열 기반으로 확장(GameManager).  
  </li>
  <li>
  적 AI 트러블슈팅 정리 및 구조 개선 반영:

  - 청각 판정에 벽 차단(Linecast) 로직 추가(EnemyPerception)로 “벽 너머 소리 반응” 문제 보정.
  - 조사(Investigate) 흐름에 <b>이동 제한 시간</b>을 추가해, 도착 실패 시에도 조사 상태가 무기한 유지되지 않게 정리(EnemyNoiseListener).
  - 복귀(Return) 기준을 “공유 순찰 포인트”가 아니라 “이탈 시작 지점(Return Anchor)”으로 변경해 적들이 한 지점에 뭉치는 문제 완화(EnemyMemory/EnemyBrain).
  - 적 HP UI를 전역 이벤트 공유에서 <b>개체별 로컬 이벤트</b> 구독 구조로 분리해 “한 적이 맞으면 전체 UI가 같이 깎이는” 문제 수정(SpawnManager/EnemyStatus/EnemyHealthUI).
  - ExitPoint 타이머 UI 참조 누락 시 예외가 터지지 않도록 자동 탐색 + null-safe 활성화 보정(ExitPoint).
  </li>
  <li>
  회의(07/06) 메모 기준으로 오늘/이번 단계 운영 원칙 확인:

  - 개발일지는 “수정됨” 같은 결론만 쓰지 말고 <b>무엇을/왜/어떻게 수정했는지</b>를 상세히 남기는 방향으로 품질 기준 강화.
  - P0 이후 확장(스킬/장비) 구현은 <b>명세 작성 후 착수</b>로 우선순위/게이트를 명확히 함.
  </li>
  </ul>
- 진행 중:
  - 패트롤 테스트 씬에서 실제 플레이 체감 기준으로 값 튜닝(조사 이동 제한 시간, 복귀 후 순찰 재개 타이밍, 벽 차단 마스크 레이어 적합성 등).
  - (회의 아젠다) 스킬(디코이) 명세/애니메이션/JSON 연동 등 후속 태스크 진행 트랙.
- 이슈/막힌 점:
  - 레이어/프리팹 세팅(hearingObstacleMask 등)이 씬/프리팹마다 누락되면 체감이 흔들릴 수 있어, “기본값 보정”과 “명시적 세팅” 사이의 운영 기준이 필요.
  - 조사/복귀 로직이 자연스러워졌지만, 맵/루트 배치에 따라 여전히 동선이 어색해질 수 있어 플레이 테스트로 반복 검증 필요.
- 내일 할 일:
  - 패트롤 씬에서 실제 플레이 테스트로 아래 항목 집중 검증:
    - (1) 조사 이동 제한 시간(maxInvestigateMoveTime) 체감 적정성
    - (2) 복귀 앵커 기반 복귀가 루트/스폰 배치에서 자연스럽게 보이는지
    - (3) 벽 차단 청각(Line of Hearing)이 맵 레이어 구조와 일치하는지
    - (4) HP UI가 개체별로만 갱신되는지 회귀 테스트
  - (필요 시) 관련 명세/문서(특히 AI/스킬/시간 페널티 규칙) 업데이트 반영 위치 확정

## 작업 로그 (시간순)

- 패트롤 테스트 씬이 인게임 루프에 안 들어오는 원인 파악 → GameManager 플레이 씬 판정 확장
- 적 AI 트러블 이슈(벽 너머 청각, 조사 무한 유지, 복귀 뭉침, HP UI 동기화) 원인 분해 → 책임 위치별로 수정
- 예외/참조 누락(ExitPoint 타이머) 방어 로직 보강
- 07/06 회의 메모 확인 → 개발일지 품질 기준/스코프 통제(명세 선행) 원칙 재확인

## 상세 기록

### 1) DemoScene Patrol 씬 연동

- 목표: 테스트 패트롤 씬에서도 플레이어/적 스폰 등 인게임 세션 초기화가 동일하게 타도록 만들기
- 결과: 플레이 씬 판정을 단일 문자열에서 배열 기반으로 확장하여 <code>DemoScene Patrol</code>도 인게임 세션으로 인식하게 수정
- 메모:
  - 테스트용 임시 분기 대신, “플레이 씬 판정” 자체를 확장해 유지보수 비용을 줄이는 방향

### 2) 청각(hearing) 벽 차단 판정 추가

- 목표: 벽 너머 총성/노이즈에도 적이 반응하는 문제 해결
- 결과: EnemyPerception.CanHear에 Linecast 기반 차단 판정 추가(requireLineOfHearing, hearingObstacleMask, soundSampleHeight)
- 메모:
  - 마스크가 비어 있을 때 기본 Wall 레이어를 쓰는 보정 로직을 둬서, 세팅 누락의 리스크를 완화

### 3) 조사(Investigate) 종료 조건 구조화

- 목표: 조사 지점에 도착 못 하면 조사 상태가 길게 유지되어 복귀가 지연되는 문제 해결
- 결과: 이동 제한 시간(maxInvestigateMoveTime / investigateMoveEndTime) 추가로 “도착 실패”에서도 조사 상태가 종료되도록 보정
- 메모:
  - 조사 흐름을 “이동 단계”와 “도착 후 탐색 단계”로 분리해서 상태 전이가 더 예측 가능해짐

### 4) 복귀(Return) 뭉침 문제 해결: Return Anchor 도입

- 목표: 어그로 해제 후 적들이 공유 순찰 포인트로 뭉치는 현상 완화
- 결과: EnemyMemory에 returnAnchor(이탈 시작 지점 + 당시 patrolIndex)를 저장하고, EnemyBrain이 복귀 목적지를 ReturnAnchorPosition으로 사용하도록 변경
- 메모:
  - 플레이어 재발견 시에도 “복귀 기준점 자체”는 유지하여, 추적-이탈 반복에도 복귀 일관성 확보

### 5) 적 HP UI 개체별 분리

- 목표: 한 적이 맞았을 때 모든 적 HP UI가 같이 갱신되는 문제 해결
- 결과: SpawnManager에서 런타임 ID 재부여 + EnemyStatus 로컬 이벤트(OnLocalHealthChanged) 발행 + EnemyHealthUI가 로컬 이벤트만 구독
- 메모:
  - 전역 이벤트는 유지하되(UI 외 다른 시스템 호환), UI는 개체별 로컬 구독으로 안전하게 분리

### 6) ExitPoint 타이머 예외 대응

- 목표: 테스트/병합 과정에서 timerCanvas 참조 누락 시 플레이가 막히는 예외 방지
- 결과: 자식 EscapeTimer 자동 탐색 + null-safe 활성화(SetTimerCanvasActive)로 방어
