## 오늘의 목표

보스 처치 뒤의 이야기를 마무리하고 게이트를 나와 실제 플레이 가능한 첫 귀환 구역으로 연결합니다. 기관 본부를 바로 크게 만드는 대신, 게이트 밖 임시 통제·구호 구역에서 생환 확인과 사건 보고를 진행하도록 구성합니다.

## 완료한 작업

- 초가집에 열린 중앙 대청·목재 기둥·마루·기록 소품이 보이도록 도트 이미지를 개편했습니다. 집 전체가 걸어 들어갈 수 있는 실내가 된 것은 아니며, 실제 기록 상호작용은 이동 가능한 대청 앞에 둡니다.
- 보스 처치 → G 영혼 해방 → 다시 G 월도 획득 → 대청 기록 G → 명시적 기록 확인 → 집 옆 은빛 출구 G → 귀환 확인 순서를 연결했습니다.
- 기록을 닫는 것만으로는 읽음 처리하지 않고, 확인해야 출구가 열리도록 했습니다. 대화 중 이동·공격과 기존 전투 HUD·G 안내를 숨기고 종료 후 복원합니다.
- 기록에는 조사관의 마지막 현장 기록과 팀장의 철수 메모를 넣고, 게이트 폭주의 이면 해석은 귀환 구역의 현장 조사실에서 설명하도록 나눴습니다.
- 첫 귀환 씬 <code>Tutorial_Stage03_ReturnField</code>를 만들고 보스 출구의 이동 목적지를 연결했습니다. 최종 흐름은 로비 복귀가 아니라 플레이 가능한 현장 귀환입니다.
- 약 30×48m 구역에 통제선 → 구호소 → 현장 조사실을 배치하고 우클릭 이동용 NavMesh·별도 충돌 기반·스폰 지점을 구성했습니다.
- 구호소 천막·조사실·바리케이드·현장 요원 도트 아틀라스를 새로 생성하고 투명 알파를 유지해 씬 소품으로 적용했습니다. 그림과 이동 판정은 분리했습니다.
- 세 요원에게 G로 대화하고 확인 버튼으로 한 단계씩 진행합니다. 순서가 안 된 지점은 막고, 완료한 대화는 다시 읽을 수 있도록 했습니다.
- 검 장비·빗자루/코어/월도 파츠·청사진 배치·스킬 배정·체력·정기·남은 내구도를 메모리 스냅샷으로 한 번 인계합니다. 무료 회복이나 파츠 재지급을 하지 않습니다.
- 안전 구역에서는 기본 공격·전투 스킬을 막되 우클릭 이동과 Tab 장비/청사진 편집은 유지했습니다.
- 종합 기획서·튜토리얼 콘텐츠·상세 연출 명세에 귀환 흐름과 구현 화면을 보충했습니다.

## 발견한 문제와 해결

- 생성 아틀라스를 정확한 2×2 절반으로 자르면 천막의 밧줄과 요원 머리 일부가 잘렸습니다. 실제 투명 여백에 맞춰 가로 54%·세로 53% 분할을 사용하고 PNG 원본은 재도색하지 않았습니다.
- HUD 목표 글자와 요원 이름표의 위치가 맞지 않아 여백·짧은 목표 문구·카메라 기준 이름표 위치를 조정했습니다.
- 검증 중 기록 창 초기화가 중복 호출되면서 잔여 모달이 생겼습니다. 초기화를 한 번만 수행하도록 만들어 반복 호출에도 중복 창을 생성하지 않도록 했습니다.
- UI가 나중에 추가하는 공격 컴포넌트도 안전 구역 정책에 따라 차단하도록 초기화 순서와 첫 LateUpdate를 처리했습니다.
- 기존 사용자 편집 씬을 덮어쓰지 않기 위해 별도 Unity 복제 프로젝트에서 생성·검증했습니다. 저장된 기존 튜토리얼 두 씬의 해시가 유지됐습니다.

## 결정한 규칙

- 첫 귀환 장소는 기관 본부가 아닌 게이트 밖 임시 통제·구호 구역입니다.
- 구호소 대화는 상태 확인이며 체력·정기·내구도 자동 회복 기능이 아닙니다.
- 해방된 사람의 영혼과 물건에 깃든 월도 도깨비를 같은 존재로 취급하지 않습니다. 모든 피해자가 즉시 살아났다고 확정하지 않습니다.
- 본부 검사·각성 등록·다음 임무·합성/강화·영구 저장은 후속 범위입니다.

## 검증 결과

- 별도 Unity 6000.3.7f1 프로젝트의 최종 귀환 흐름 검사: 96개 통과.
- 보스 실제 G 입력 회귀: 17개 통과.
- 월도 보상·편집·전개·스킬 회귀: 43개 통과.
- 최종 세 실행 총 156개 항목 통과, 종료 코드 모두 0.
- 실제 G 입력·비동기 씬 이동·인계 상태 복원·각 요원 NavMesh 도달·대화 취소/확인·보고 완료·실제 Tab 접근을 확인했습니다.
- 이전 대청/종료 구간의 43개 검사는 중간 결과이며 최종 96개에 확대 반영됐습니다. 재실행/중복 항목을 별도 기능 수로 합산하지 않습니다.
- 기존 Unity Editor Search 인덱서의 시작 예외는 게임 코드와 구분해 기록했습니다. 수동 전체 완주·독립 실행 빌드·모든 해상도 검수는 아직 남아 있습니다.
