## 오늘 한 일

- <b>EP.3-2 리듬 퍼즐 채보 정리</b>
  - 채보를 끝까지 완성한 뒤, 후반부 비어 있던 구간을 보완했다.
  - 전체 길이가 길다는 피드백을 반영해 <b>후반 8마디를 컷</b>하고, 추가로 <b>약 1마디를 더 축소</b>했다.
  - 노트가 특정 레인에 몰리지 않도록 <b>레인 분산을 재조정</b>하고, 레인별로 음표를 달리 배치해 시각적으로 구분되게 했다.
- <b>입력/판정 시스템 정리</b>
  - 입력을 <b>D / F / Space / J / K의 5레인 구조</b>로 확정했다.
  - 판정 체계를 <b>Excellent / Good / Bad / Wrong / Miss</b>처럼 등급이 나뉘는 값 기반 구조로 변경했다.
- <b>시각 피드백 & UI 개선</b>
  - 각 레인을 반투명 검은 박스로 깔아 오선지 느낌을 만들고, 입력 시 해당 레인의 색으로 피드백이 들어오게 했다.
  - <b>판정 상태 + 남은 실수</b>를 표시하는 정보 박스를 추가해 플레이 중 상태를 확인할 수 있게 했다.
- <b>점수/라이프 규칙 수정</b>
  - 10000점마다 최대 라이프 증가 방식 대신, <b>이미 깎인 라이프를 1칸 회복</b>하는 방식으로 바꿨다.
- <b>퍼즐 종료 연출 개선</b>
  - 음악이 갑자기 끊기지 않도록 <b>짧은 페이드아웃</b>을 넣어 마무리 감을 자연스럽게 했다.
- <b>퍼즐 이후 연출 흐름 보강</b>
  - 퍼즐 완료 → 바로 컷씬/문 오픈으로 넘어가던 구조 사이에, <b>“완료 지점까지 이동” 연출</b>을 추가했다.
  - 오선지 프리뷰를 띄우고 플레이어가 그 위를 따라 <b>자동 이동하는 시퀀스</b>를 넣었다.
  - 단순 미끄러지는 이동에서, <b>걷는 애니메이션이 보이도록 수정</b>해 더 자연스럽게 개선했다.
  - 이동 완료 후에는 엔딩 컷씬과 문 상호작용으로 이어지도록 정리했다.
- <b>버그 수정</b>
  - 컷씬 관련 <b>NullReferenceException</b>과 컴파일 오류를 해결해 전체 흐름이 끊기지 않게 보완했다.

## 문제점

- 리듬 퍼즐은 입력 규칙만 맞추는 것으로 끝나지 않고, <b>싱크/속도/피드백/연출 연결</b>이 함께 맞아야 완성도가 나온다.
- 채보에서:
  - 초기에는 음악과 <b>싱크가 어긋나는 구간</b>이 있었고,
  - 특정 레인에 노트가 <b>과도하게 몰려 난이도가 불필요하게 빡세게</b> 느껴졌으며,
  - 후반부 <b>노트가 비어 흐름이 끊기는 구간</b>이 있어 여러 번 재작업이 필요했다.
- 이동 연출에서:
  - 초기에는 위치 보간 위주라 <b>“걸어가는 느낌”이 부족</b>했고, 그 결과 플레이 흐름의 감정 연결이 약하게 느껴졌다.

## 오늘의 배운 점 (회고)

- “리듬 퍼즐”은 <b>정답 입력 규칙</b>이 아니라 <b>플레이 감각(체감 난이도) + 시각/연출 흐름</b>으로 완성된다.
- 후반부를 잘라내는 선택은 콘텐츠를 줄이는 게 아니라, <b>집중도와 완성도를 올리는 편집</b>이라는 걸 체감했다.
- 이동 연출은 기능적으로 “이동한다”가 아니라, <b>애니메이션/속도/연출 맥락</b>까지 포함해 설계해야 자연스럽다.

## 내일 할 일

- 오선지 위 자동 이동 연출을 더 다듬고, 필요하다면 <b>이동 중간에 텍스트 컷씬/짧은 연출</b> 삽입을 검토한다.
- 리듬 퍼즐 채보를 다시 테스트하면서:
  - 음악 싱크가 더 정확한지,
  - 특정 구간이 과하게 빡센지/밋밋한지
  - 세밀하게 조정한다.
- 판정 UI와 레인 시각 효과를 더 읽기 쉽게 정리해, 성공/실패가 한눈에 들어오도록 완성도를 높인다.
