## 기본 정보

- 날짜: 2026-04-03
- 프로젝트: MosAIc / Moz.A.I.c (EP.3 사운드 시스템)
- 작성자: 작성자

## 오늘 한 일(요약)

- 프로젝트 사운드 관리 구조(BGM / Ambient / UI / SFX) 전반을 설계하고 분류 기준을 정리했다.
- <code>SoundManager</code> 스크립트를 작성해 씬 로드 시 자동으로 BGM/Ambient가 전환되도록 구성했다.
- EP.3 중심으로 enum 네이밍(공간/구간 기준)과 전용 SFX 항목을 정리했다.

## 구현한 것

- <code>SoundManager</code> 싱글톤 + <code>DontDestroyOnLoad</code> 적용으로 씬 전환에도 매니저가 유지되도록 구현
- 사운드 역할 분리: BGM / Ambient / UI / SFX 전용 AudioSource 구조
- 인스펙터 등록 리스트 → Dictionary 변환(BuildDictionaries)으로 런타임 조회 구조 정리
- <code>SceneManager.sceneLoaded</code> 기반 <code>OnSceneLoaded()</code> 자동 전환 로직 구현
  - 씬 이름에 따라 BGM/Ambient 자동 재생
  - <code>Episode4_Finale</code>은 연출 의도에 따라 Ambient 제외(BGM만)
- SFX 재생 유틸
  - 2D: <code>PlaySFX()</code> + 랜덤 피치 옵션
  - 3D: <code>PlaySFX3D()</code>로 위치 기반 재생(임시 오브젝트 생성)

## 배운 것(개념/정리)

- 사운드는 “추가”보다 “관리 구조”가 핵심이라서, 역할/기준(BGM·Ambient·UI·SFX)을 먼저 분리해두면 이후 확장/수정이 훨씬 쉽다.
- enum 네이밍은 짧게보다 “용도가 즉시 보이는 이름(씬/구간/상황 기준)”이 유지보수에 유리하다.
- 씬 전환과 연출까지 고려해 예외 규칙(예: 피날레는 BGM만)을 명확히 두는 게 전체 시스템 안정성에 도움이 된다.

## 이슈/버그

- 내용: Ambient / SFX 네이밍이 재료 중심으로 섞여 있어서, 인스펙터에서 클립 연결 시 헷갈릴 가능성이 있었다.
- 원인/가설: 분류 기준(공간/구간 vs 재료/소리 종류)이 혼재되어 있었고, 에피소드 전용/공용 구분이 명확하지 않았다.
- 해결/시도: Ambient는 공간/구간(씬 단위) 기준으로, SFX는 에피소드+상황이 드러나도록 enum을 재정리했다.
- 다음 액션: 인스펙터에 실제 오디오 클립을 연결하면서 “공용/전용” 분리가 더 필요한 항목이 있는지 추가 점검한다.

## 내일 할 일

- <code>SoundManager</code> 인스펙터에 실제 오디오 클립 연결하기
- 씬별 BGM / Ambient 자동 재생 테스트 및 볼륨 밸런싱
- 주요 오브젝트(문/포탈/퍼즐 발판 등)에 SFX 연결하기
- UI 버튼에 Click / Hover / Confirm 사운드 적용하기
- 발자국 사운드를 별도 구조로 분리할지(플레이어 전용) 설계 검토
