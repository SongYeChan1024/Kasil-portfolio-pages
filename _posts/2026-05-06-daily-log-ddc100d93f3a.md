## 기본 정보

- 날짜: 2026-05-06
- 프로젝트: VR\_Test (Unity 6.x + OpenXR + XRI Toolkit 실습)
- 작성자: 작성자

## 오늘 한 일(요약)

- Unity 6.x LTS + Universal 3D로 VR 프로젝트를 생성하고 OpenXR/XRI Toolkit/Starter Assets를 세팅했다.
- XR Origin(VR) 프리팹을 배치하고 Left/Right Controller에 Tracked Pose Driver(Input System) 기반 트래킹을 연결했다.
- Right Controller에 XR Ray Interactor를 만들고 XR Simple Interactable(Cube)과 Hover 이벤트를 연결해 상호작용을 테스트했다.
- XR Interactor Line Visual + Line Renderer로 Ray를 Game에서 보이게 커스터마이징했다(Gradient/Width/Material=Default Line).
- Locomotion(Move/Turn) 구조를 만들고 Dynamic Move Provider + Snap Turn Provider로 “왼손 이동/오른손 회전” 컨트롤을 완성했다.
- Teleportation Provider를 추가하고, 텔레포트 기능을 위한 Area/Anchor가 필요하다는 것까지 준비했다.

## 구현한 것

- Ray Interactor 이벤트 기반 상호작용
  - Cube에 <code>XR Simple Interactable</code> 추가
  - Hover Entered 이벤트에 <code>ColorChange</code> 함수를 연결해 Ray가 닿으면 색이 바뀌도록 구성
  - Hover/Select/Activate 이벤트 차이를 정리하고, Hover 상태에서 Activate를 쓰기 위한 옵션을 세팅함
    - Keep Selected Target Valid, Allow Hover to Activate 체크
    - Activate Input / Activate Value를 <code>XRI Right Interaction &gt; Activate</code> / <code>XRI Right Interaction &gt; Activate Value</code>로 지정
- Ray 시각화
  - XR Ray에 <code>XR Interactor Line Visual</code> 추가
  - Line Renderer를 통해 Gradient/Width 조정
  - Material을 <b>Default Line</b>으로 바꿔야 색상이 정상 적용되는 점 확인
- Locomotion 이동/회전
  - Locomotion 오브젝트 구성: <code>Locomotion Mediator</code>(중재) + Provider들(Move/Turn/Teleport)
  - Move: <code>Dynamic Move Provider</code>
    - Forward Source / Head Transform = Main Camera
    - Left Hand Move Input = <code>XRI Left Locomotion Move</code>
    - (표준 방식 적용) Right Hand Move Input은 제거해서 “왼손 이동만” 되게 설정
  - Turn: <code>Snap Turn Provider</code> (Turn Amount 45도)
    - Right Hand Turn Input = <code>XRI Right Locomotion Snap Turn</code>
    - (표준 방식 적용) Left Hand Turn Input은 제거해서 “오른손 회전만” 되게 설정
  - Transformation Priority(우선순위) 설정
    - Turn=1, Teleportation=2, Move=3 (Turn이 가장 우선)

## 배운 것(개념/정리)

- OpenXR vs XR Interaction Toolkit
  - OpenXR: 하드웨어/런타임과 통신하는 표준 프로토콜
  - XRI Toolkit: 입력(Action)과 상호작용(Interactor/Interactable) 구현을 위한 프레임워크
- Starter Assets의 의미
  - 기본 Input Action(예: XRI Left/Right Locomotion Move/Turn, Activate 등)이 준비되어 있어서 세팅 난이도를 크게 낮춰줌
- Interactor / Interactable
  - Interactor: 상호작용을 “하는 쪽”(Ray, Direct 등)
  - Interactable: 상호작용을 “받는 쪽”(XR Simple Interactable 등)
- Locomotion 구조
  - Locomotion Mediator가 여러 이동 방식(Move/Turn/Teleport)을 중재하고 우선순위를 관리함
  - Provider는 실제 변환(이동/회전/텔레포트)을 수행하며, Priority로 충돌을 방지함
- Snap Turn vs Continuous Turn
  - Snap Turn: 끊어서 회전(예: 45도) → 멀미 방지에 유리해서 기본값으로 많이 사용
  - Continuous Turn: 부드럽게 연속 회전 → 자연스럽지만 멀미 유발 가능성이 커짐
- Teleportation 기초
  - Teleportation Provider만으로는 부족하고, Teleportation Area/Anchor 같은 “텔레포트 대상” 구성이 필요함

## 이슈/버그

- 내용: Line Renderer 색상이 적용되지 않거나 Ray가 Game View에서 잘 안 보이는 문제
- 원인/가설: Line Renderer Material이 기본(Unlit 등)으로 되어 있어 색상/그라디언트가 의도대로 적용되지 않음
- 해결/시도: Material을 <b>Default Line</b>으로 변경
- 다음 액션: Game View에서 Ray 시각화 옵션(라인 설정/거리/렌더링 설정) 체크리스트로 정리

## 내일 할 일

- Teleportation Area / Teleportation Anchor를 실제로 배치해서 텔레포트까지 동작 확인
- Snap Turn과 Continuous Turn을 각각 적용해 UX/멀미 체감 비교
- Locomotion Provider 구조를 내 프로젝트 구조에 맞게 정리(왼손잡이 옵션까지 고려)
