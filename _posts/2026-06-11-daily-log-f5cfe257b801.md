[관련 기록]({% endraw %}{% post_url 2026-06-11-development-note-ce8451478813 %}{% raw %}) - 내가 만들었던 기획서 초안

<b>날짜:</b> 2026/06/11<br />

<b>주요 이벤트:</b> 3차 팀 프로젝트 기획서 제출 & 프로젝트 선정 회의

## 오늘 한 일

- 3차 팀 프로젝트 기획서 각자 제출
- 팀 내 기획서 리뷰 및 3차 프로젝트 주제 선정 진행
- 결과: 내 기획서는 최종 선정되지 않음
- 최종 선정: <b>장수영(레이서) 님 기획서</b> 채택 → 해당 기획을 기반으로 본격 제작 진행 결정

## 선정된 기획서 요약 (침몽도시: 루시드 다이버)

<ul>
<li>
<b>장르/키워드:</b> 2.5D 라이트 PvE 익스트랙션 액션 RPG
</li>
<li>
<b>한 줄 핵심:</b> <i>“혼자서는 외곽을 털고, 함께하면 중심부의 꿈을 부순다.”</i>
</li>
<li>
<b>세계관:</b> 현실 도시를 덮은 초월적 꿈 ‘침몽도시’ 탐사. 현실 무기는 무효이며, 도시 내부에서 획득한 <b>총기형 심상무장(드림 포지드)</b>만 유효.
</li>
<li>
<b>코어 루프:</b> 준비 → 진입 → 파밍 → 협동 공략(중심부) → 탈출/정산 → 성장
</li>
<li>
<b>멀티 구조:</b> 한 세션 최대 4인 / 외곽 솔로 파밍 가능 / 중심부는 협동 보스 공략 권장 + 즉석 협동 요청(핑)
</li>
<li>
<b>라이트 손실 구조:</b> 체력 0 = 강제 각성(사망 X). 기본 장비 보존, 일반 인벤토리 대부분 손실, <b>각성 보존 슬롯</b>만 안전 귀환
</li>
<li>
<b>편성 구조:</b> 1 메인 + 2 지원 + 1 오퍼레이터  

<ul>
<li>
지원: 전투 중 짧게 호출되는 스트라이커(수동 액티브/패시브 자동 발동)  
</li>
<li>
오퍼레이터: 필드에 직접 등장하지 않고 세션 규칙/정보/추출 등에 영향
</li>
</ul>
</li>
</ul>

## MVP(데모) 목표/범위 정리

- 맵 1개: 꿈에 먹힌 시가지(청몽 교차로)
- 인원: 1\~2인 우선(추후 4인 확장)
- 캐릭터: 메인 2, 지원 2, 오퍼레이터 1
- 적: 일반 적 1\~2종 + 중심부 보스 1종
- 핵심 기능:
  - 2인 멀티 동기화
  - 이동/총기 전투/피격 피드백
  - 심상기물 파밍
  - 각성 보존 슬롯
  - 탈출/정산
  - 지원 캐릭터 호출 + 오퍼레이터 패시브
  - 협동 요청 핑 + 보스 협동 공략

## 오늘의 결론/결정 사항

- 3차 팀 프로젝트는 <b>장수영(레이서) 님 기획서</b>로 확정
- 이후 작업은 해당 기획의 <b>MVP 범위 기준으로 역할 분담 및 제작 일정 수립</b> 방향으로 진행

## 느낀 점 / 회고

- 내 기획이 선정되지는 않았지만, 팀 프로젝트에서 “선정 → 합의 → 같은 방향으로 실행”이 얼마나 중요한지 체감
- 선정된 기획서가 <b>범위(MVP)와 차별점이 명확</b>해서 다음 단계(역할/일정)로 바로 넘어가기 좋다고 느낌
- 앞으로는 개인 기획도 “데모로 증명 가능한 한 줄 가치 + 구현 범위”를 더 선명하게 잡는 방향으로 보완 필요

## 내일 할 일 (다음 액션)

- 선정된 기획서 기반으로:
  - 기능 우선순위(1\~6) 확인 및 담당 파트 후보 정리
  - 필요한 에셋/기술 리서치(2.5D 전장, 총기 전투, 멀티 동기화, 핑/협동 시스템)
  - 팀 내 역할 분담/일정 논의 준비
