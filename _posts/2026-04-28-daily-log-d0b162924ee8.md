## 오늘 한 일

- <b>EP.3 전반 안정화 (3-1 / 3-2 / 3-3)</b>
  - 씬 전반의 상호작용 흐름을 점검하고, 퍼즐/키워드/심볼/피아노 상호작용이 의도한 순서로 이어지도록 정리했다.
- <b>3-1 상호작용 버그 수정</b>
  - 퍼즐 클리어 전에도 피아노 상호작용이 열려 바로 맵을 빠져나갈 수 있던 문제를 수정했다.
  - <b>악보 조각을 모두 수집한 뒤에만</b> 피아노 상호작용이 활성화되도록 변경했다.
  - 조각을 모두 모은 직후 상호작용이 <b>즉시 열리도록 타이밍</b>을 조정했다.
- <b>3-3 상호작용 우선순위/연출 정리</b>
  - 책상, 하모니 심볼, 피아노/악보 상호작용의 <b>우선순위</b>를 재정리했다.
  - 하모니 심볼이 <b>책상 상호작용 이후에만</b> 나타나도록 흐름을 맞췄다.
  - 하모니 심볼 클릭 시 중앙에 <b>키워드 텍스트가 뜨는 UI</b>를 보강했다.
- <b>3-2 리듬 퍼즐(탑다운) 플레이 감각 개선</b>
  - 노트 처리, 레인 피드백, 점수 시스템, 후반부 채보를 여러 차례 조정했다.
  - 라이프 규칙을 <b>10000점마다 최대 라이프 증가 → 깎인 라이프 1칸 회복</b>으로 변경했다.
  - 점수 UI를 <b>오른쪽 위</b>에 배치해 규칙이 한눈에 들어오게 했다.
  - 퍼즐 클리어 후 음악이 갑자기 끊기지 않도록 <b>페이드아웃</b>을 추가했다.
  - 오선지 프리뷰 위를 따라 완료 지점까지 이동하는 <b>후속 이동 연출</b>을 추가했다.
    - 빠른 위치 보간 방식에서, <b>걷는 애니메이션을 동반한 이동</b>으로 수정해 자연스러움을 개선했다.
- <b>Episode 3 씬 파일 무결성/직렬화 문제 해결(중요)</b>
  - 카메라 세팅 과정에서 씬(Episode3\_Scene, Ep3\_3\_ReturnedLobby 등)에 시네머신 컴포넌트가 중복으로 들어가 <b>fileID 충돌 → 씬이 열리지 않는 오류</b>가 발생한 원인을 확인했다.
  - 씬 YAML을 직접 확인해 중복된 Cinemachine3rdPersonFollow 블록과 끊어진 참조를 제거했고, 3-1 씬까지 함께 정리했다.
  - 3-2 리듬 퍼즐 스크립트에서 더 이상 쓰지 않는 필드를 제거해 경고를 줄였다.
  - 최종적으로 <b>Assembly-CSharp / Assembly-CSharp-Editor 빌드가 오류 없이 통과</b>했고, 추가적인 중복 object id / 깨진 PPtr 문제도 확인되지 않았다.

## 문제점

- 기능 하나를 수정하면 상호작용/컷씬/UI/씬 직렬화가 서로 얽혀 있어 <b>연쇄적으로 다른 문제가 튀어나오는 경우</b>가 많았다.
- Episode 3는 가상 카메라(컷씬), 상호작용 심볼, 키워드 UI, 퍼즐 후속 연출이 촘촘히 연결되어 있어 <b>흐름이 조금만 어긋나도</b> 예상 밖의 오류로 이어졌다.
- Unity 씬 YAML을 직접 수정한 뒤에는 겉보기엔 정상처럼 보여도, 실제로는 <b>fileID 중복</b> 또는 <b>끊어진 참조가 남아</b> 씬 로딩 에러가 발생할 수 있어 검증 부담이 컸다.

## 오늘의 배운 점 (회고)

- 상호작용/연출/퍼즐/카메라는 기능 단위가 아니라 <b>‘플레이 흐름 단위’로 묶여 있다</b>는 걸 다시 확인했다. (한 부분만 고치면 다른 부분이 바로 영향을 받음)
- 씬이 안 열리는 급한 상황에서는:
  - “Unity에서 뭐가 깨졌지?” 감으로 보기보다, <b>YAML에서 중복/참조 끊김을 직접 확인</b>하는 게 가장 빠른 길일 수 있다.
- 점수/라이프/피드백은 규칙 자체보다도, 플레이어가 바로 이해할 수 있게 <b>UI로 드러내는 것</b>이 중요하다.

## 내일 할 일

- 3-1 \~ 3-3 상호작용 흐름을 다시 한 번 플레이 스루로 점검해서, 특정 상황에서 우선순위가 꼬이거나 UI가 누락되는 케이스가 없는지 확인한다.
- 3-2 리듬 퍼즐을 실제 플레이 기준으로 재테스트하면서:
  - 노트 처리/레인 피드백이 일관적인지
  - 점수-라이프 회복 규칙이 과하거나 부족하지 않은지
  - 클리어 후 이동 연출이 템포를 끊지 않는지
  - 추가 조정 포인트를 정리한다.
- 씬 직렬화 관련 재발 방지를 위해, 시네머신/카메라 프리팹 및 씬 구성 규칙(중복 방지 체크리스트)을 간단히 메모로 남긴다.
