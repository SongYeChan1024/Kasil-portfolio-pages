## 기본 정보

- 날짜: 2026-05-07
- 프로젝트: Unity 6 VR (XRI 3.0) — Climb / Grab / UI Interaction 실습
- 작성자: 작성자

## 오늘 한 일(요약)

- Teleportation Anchor와 Multi Anchor Volume 구조를 복습하고, 사다리(Ladder) 이동이 “앵커 기반 위치 이동”으로 구성된다는 흐름을 정리했다.
- 샘플 Ladder 프리팹을 분석한 뒤, Handles(손잡이) 쪽에 <code>XR Climb Interactable</code>을 붙여 등반 상호작용을 구성했다.
- XR Origin의 Locomotion에 <code>Climb Provider</code>를 세팅하고, 등반 중 Move/Jump Provider를 비활성화하도록 설정했다.
- <code>XR Grab Interactable</code>을 이용해 오브젝트 Grab을 실습하고, Attach Transform을 만들어 잡는 위치/화면 가림을 보정했다.
- World Space Canvas에 <code>Tracked Device Graphic Raycaster</code>를 추가하고, Event System을 XR UI 입력 모듈로 교체해 XR Ray로 UI 상호작용이 되도록 구성했다.

## 구현한 것

- Climb(사다리 타기) 기본 구현
  - Ladder(Handles)에 <code>XR Climb Interactable</code> 구성
  - XR Origin(Locomotion)에 <code>Climb Provider</code> 설정
  - Provider to Disable에 Move / Jump 지정 → 등반 중 다른 이동과 충돌 방지
  - 테스트: XR Device Simulator 기준 T(이동) / R(회전) / G(잡기)
- Grab(잡기) + Attach 보정
  - 오브젝트에 <code>XR Grab Interactable</code> 추가(자동 Rigidbody 생성)
  - Attach용 빈 오브젝트를 만들어 “그립 위치”로 배치한 뒤 Attach Transform에 지정
  - 화면 가림 문제는 Attach를 뒤쪽으로 배치해 카메라 가림을 줄임
  - <code>Attach Ease In Time</code>으로 잡히는 전환 속도(스냅 느낌) 조절
  - (원거리 잡기 관련) Far Attach Mode를 Near로 바꿔 가까이서 잡히게 조정
- XR UI Interaction 기본 세팅
  - Canvas를 World Space로 만들고 Event Camera에 Main Camera 연결
  - Canvas에 <code>Tracked Device Graphic Raycaster</code> 추가
  - Event System: <code>Input System UI Input Module</code> 제거 → <code>XR UI Input Module</code> 추가(+ XR UI Event System)
  - Button/Toggle/Dropdown/ScrollView 등 UGUI 요소 배치 후 Ray로 상호작용 테스트

## 배운 것(개념/정리)

- Climb locomotion의 핵심
  - <code>XR Climb Interactable</code>은 “잡을 수 있는 등반 대상”을 제공하고,
  - 실제로 XR Origin을 움직여 등반 이동을 만드는 건 <code>Climb Provider</code>가 담당한다.
  - 체감 동작은 손(컨트롤러)이 움직인 방향의 <b>반대 방향으로 XR Origin이 이동</b>해야 “몸이 올라가는” 결과가 나온다.
- Grab에서 Attach Transform을 잡아줘야 하는 이유
  - Attach를 지정하지 않으면 기본 부착점(오브젝트 기본 기준점)으로 스냅되면서 잡는 순간 위치/회전이 튀는 느낌이 생길 수 있다.
  - Attach Transform을 명시하면 “손에 자연스럽게 잡히는 그립 위치”를 의도대로 고정할 수 있다.
- XR UI 상호작용 구성 요소
  - <code>Tracked Device Graphic Raycaster</code>(Canvas) + <code>XR UI Input Module</code>(Event System) 조합이 핵심이다.

## 이슈/버그

- 내용: Grab 시 오브젝트가 손에 “툭” 붙는 스냅 느낌 / 화면을 가리는 문제
- 원인/가설: 기본 Attach 기준점이 그립 위치와 달라서 발생 + 전환이 너무 즉시 적용됨
- 해결/시도: Attach Transform을 만들어 위치를 보정하고, 필요 시 Attach Ease In Time으로 전환 속도 조절
- 다음 액션: 오브젝트 타입(총/검/방패 등)별로 기본 Attach/Secondary Attach 프리셋 만들어두기

## 내일 할 일

- 오늘 만든 사다리(Climb) 구성을 “샘플 삭제 후 새로 만들기” 방식으로 다시 한 번 재현해서 완전 내 것으로 만들기
- UI 상호작용을 더 보기 좋은 UI 에셋으로 재구성해서 버튼/슬라이더/스크롤까지 안정적으로 테스트
- Grab: 양손 잡기(Secondary Attach / Select Mode Multiple)를 총/검 에셋으로 적용해보기
