## 오늘 한 일

### 1. 집 PC 개발 환경 세팅

- 원래 쓰던 <code>C:\GitHubProjects</code>의 게임·문서 저장소를 최신으로 받았다. 게임은 NCAI에서 올린 PC 간 공유용 <code>CLAUDE.md</code> 커밋(<code>7befc22</code>)까지 반영했다.
- <code>Project_DOB</code> 저장소를 받아 <code>C:\GitHubProjects</code>로 옮겼다. 홈 폴더에 따로 받은 에르고스퀘어 중복 사본 2개는 아직 지우지 않았다.
- GitHub CLI, Blender, Claude in Chrome 확장을 설치했다. Claude Code 기본 설정(<code>~/.claude/settings.json</code>)을 만들었다.
- Unity 6000.4.0f1을 설치했다. Hub에서 6000.6.4f1(6.6)이 함께 받아진 것을 확인했다.
- 게임 저장소에 <code>upgrade/unity-6000.4</code> 브랜치를 로컬로 만들고 6.4로 열었다. 버전 변경과 <code>com.unity.ai.assistant</code> 추가는 아직 커밋하지 않았다.
- 처음에 수업 메모 기준으로 CoplayDev Unity MCP를 넣었다가, NCAI에서 쓴 것이 공식 <code>com.unity.ai.assistant</code>임을 확인하고 되돌렸다. 공식 relay(<code>relay_win.exe --mcp</code>)를 Claude Code에 <code>unity-mcp</code>로 등록했고, 시험 연결에서 Unity 도구 목록을 받았다.

### 2. 오늘 밤, 던전 식당 기획 방향 정리

- 기존 기획이 브로테이토 + 데이브 더 다이버 + 오버쿡처럼 읽히는 이유를 정리하고, 뱀서라이크 + 타이쿤으로 비중을 옮기는 방향을 잡았다.
- 핵심 결정: 직접 영업이 기본, 브로테이토식 투자 상점(사냥도구·조리도구·레시피 카드, 리롤·잠금·무기 되팔기), 5일 진행, 스승의 인수인계 튜토리얼, 예약 장부(내일 예보)와 숙성통 음료 담그기, 평판에 따른 다음 날 손님 수.
- 재료·몬스터·종족을 4종씩 1:1로 묶었다. 엘프(채소)·수인 용병(고기)·드워프(버섯)·인간 마법사(마력)이며, 마나 슬라임을 원거리형 몬스터로 정했다.
- 사냥은 90초, 마지막에 다음 날 몬스터가 몰아치면 긴급탈출 스크롤을 찢고 나온다. 영업 길이는 손님 수에 따라 달라진다(최대 150초). 선택 화면에는 제한 시간을 두지 않는다.
- 무료 증강은 "단골의 선물"로 확정했다. 드워프는 무기, 엘프는 술통, 수인 용병은 일손, 마법사는 레시피·마법 부여를 준다.
- 날짜별 손님·몬스터 비중을 정했다. 마법사는 희귀 손님으로 4일차 30, 5일차 20이다.
- 건물 확장은 11일 일정에서 빼고 추가 계획으로 옮겼다.

### 3. 에르고스퀘어 Unity 6.4 전환과 검 기본공격 모션 개선 (22일 밤 \~ 23일 0시 40분)

- 6.4 업그레이드를 커밋하고 <code>codex/tutorial-foundation</code>과 함께 <code>main</code>에 합쳤다. 앞으로 <code>main</code>을 기준으로 브랜치를 나눠 작업한다. <code>com.unity.ai.assistant</code>는 Unity MCP 서버라 필수 패키지로 남겼고, 두 저장소의 안내 문서 브랜치·버전 표기와 PC별 MCP 연결 절차를 고쳤다.
- 6.4에서 사용 중단된 Find API를 VarcoAcd 검수 스크립트 40개에서 새 API로 바꿨다.
- 검 일반공격을 모션 위주로 고쳤다. v6(2단 베기 구간별 시간 재배치) → v7(VARCO 원본 3종으로 3타) → v8(크게 베고 끝 자세에서 정지, 검 궤적 강화) → v9(칼날 올려베기와 돌린 뒤 찌르기) → v10(타 사이 몸 방향·디딘 발 맞추기, 연타 시 끝 정지 생략) → v11(1타를 되짚는 2타, IK 찌르기)까지 비교안을 만들었다. 플레이 중 <code>Tools → ERGOSQUARE → Comparison → Attack Motion</code> 메뉴로 바꿔 볼 수 있다.
- 원인은 Unity MCP로 클립을 샘플링해 수치로 찾았다. 원본 1타는 시작 0.65초 동안 검이 거의 움직이지 않았다. v8 2타는 칼날 비율 0.50으로 넓적한 면이 앞장서 끌리는 동작이었다. 타가 바뀔 때 몸이 0.1초에 165° 되감겼고, 찌르기는 다른 원본 팔 회전을 섞어 위팔이 147° 비틀렸다(리깅 오류 아님).
- VARCO 애니메이션은 글 프롬프트가 아니라 정해진 동작 목록에서 고르는 방식이었다. 검 동작 3개(회전 베기·양손 내려치기·점프 찌르기)를 0포인트로 생성했지만 기본공격에 맞지 않아 스킬 후보로 남겼다.

## 오늘의 결정

플레이타임은 사냥·영업처럼 직접 조작하는 구간만 관리하고, 정산·상점·담그기처럼 선택이 들어가는 화면에는 제한 시간을 두지 않는다. 직접 영업이 핵심 기능이므로 1\~2일차 프로토타입에서 사냥보다 먼저 검증한다.

에르고스퀘어 게임 저장소는 Unity 6000.4.0f1과 <code>main</code> 기준으로 전환한다. 검 기본공격은 3타(사선 내려베기 → 올려베기 → 돌려 찌르기)로 가고, 다음 타가 예약돼 있으면 끝 자세 정지를 건너뛴다. 기본값은 기존과 같아 다른 시퀀스 동작은 바뀌지 않는다.
