## 2026-03-05 Unity: 씬 관리/병합 + 씬 로딩(동기·비동기) + Fade 전환

- 목표: 역할 분담을 위해 씬을 분리해 작업하고, 최종 실행 시에는 필요한 씬들을 Additive로 병합해 하나의 게임처럼 동작시키기
- 로딩이 길어질 수 있는 구간에서 Fade 전환을 넣어 사용자 경험(UX)을 개선하기

## 1) 씬을 나누고(분리) 다시 합치는 이유(병합)

- 개발 단계에서 각 파트가 독립적으로 작업하기 위해 씬을 분리
  - UI 담당: UI 씬
  - 레벨 담당: 맵 배치/라이트 베이킹/라이트 프로브
  - 메인 개발: 플레이어/적/게임 매니저 등 로직
- 완성된 씬을 병합(Additive)해 최종 씬 구성

## 2) 씬 분리 작업(실습 흐름)

- 메인 씬을 복제해 백업 씬 생성(예: 메인 씬\_백업)
- 메인 씬을 한 번 더 복제해 레벨 씬으로 사용(예: Level)
- MainScene: 스테이지(맵) 요소는 제거하고 게임 로직 오브젝트는 유지
- Level: 스테이지만 남기고 플레이어/카메라 등 로직 요소는 제거
  - 필요 시 Directional Light, Main Camera도 레벨 씬에서 삭제

## 3) 라이트맵(베이킹) 재작업 포인트

- 씬 분리 후 기존 베이킹 정보가 깨질 수 있어 Level 씬에서 다시 베이킹
- Window > Rendering > Lighting에서 Generate Lighting
  - 라이트맵/라이트 프로브 재생성

## 4) Start Scene(UI) 구성

- 게임 첫 화면을 별도 씬(Start Scene)으로 구성
  - Canvas(예: Start Scene UI)
  - Background(검정), 타이틀 텍스트, Play/Quit 버튼 배치
- 버튼 OnClick 이벤트를 UIManager의 메서드에 연결

## 5) UIManager: 버튼으로 씬 전환/종료 트리거

- 씬 병합 기본 아이디어
  - SceneManager.LoadScene("Level")
  - SceneManager.LoadScene("MainScene", LoadSceneMode.Additive)
- 종료 처리(에디터/빌드 분기 필요)
  - 에디터: UnityEditor.EditorApplication.isPlaying = false
  - 빌드: Application.Quit()

## 6) LoadSceneMode 정리

- LoadSceneMode.Single: 기존 씬 제거 후 새 씬만 로드(교체)
- LoadSceneMode.Additive: 기존 씬 유지 + 새 씬 추가 로드(병합)

## 7) 동기 로딩 vs 비동기 로딩

- 동기: SceneManager.LoadScene() → 로드 완료까지 멈춘 느낌이 날 수 있음
- 비동기: SceneManager.LoadSceneAsync() → 로딩 중에도 다른 작업/연출 가능
- 씬 크기가 크거나, 서버/다운로드 등 대기 시간이 길면 Fade 같은 시각적 피드백이 중요

## 8) Scene Loader 씬으로 로딩/병합을 통합 관리 + Fade 처리

- 구조 개선: 씬 병합 로직을 UIManager에서 직접 처리하기보다 SceneLoader에서 전담
  - 중복 호출 방지 + 관리 포인트 단일화
- 구현 구성
  - SceneLoader 씬: Canvas + 전체 화면 Image(검정) + CanvasGroup(알파로 페이드 제어)
  - Dictionary\<string, LoadSceneMode>로 로드할 씬 목록/모드 관리
  - 코루틴으로 씬을 순차 로드하고, 로드 후 SetActiveScene으로 활성 씬 지정
  - FadeIn(알파 1 → 0): Mathf.Abs / MoveTowards / Approximately 활용
  - 페이드 중 입력 차단: CanvasGroup.blocksRaycasts 제어
  - 완료 후 UnloadSceneAsync("SceneLoader")로 SceneLoader 씬 제거(메모리 최적화)
- 라이트맵 깨짐 방지 팁
  - 병합/활성 씬 전환 순서를 의도적으로 설정(예: Level 씬을 먼저 활성화)

## 9) Build Settings(씬 순서)

- File > Build Settings에서 씬을 등록하고 실행 순서 확인
  - 예: Start Scene을 Index 0(첫 씬)으로

## 10) 네비게이션 베이킹(문제 해결 체크)

- 적/AI 이동이 이상하면 네비게이션 베이킹 누락 가능
  - Level 씬에서 Floor 선택 → Navigation > Bake
  - 박스/장애물도 Static 설정 후 재베이킹

## 요약

### 씬 병합 개념

- 게임 개발 시 각 개발자가 독립적으로 작업: UI 개발자는 UI 씬, 레벨 디자이너는 레벨 씬, 메인 개발자는 메인 씬을 각각 제작   
- UI 개발자는 UI 씬만 담당하여 UI 요소들을 제작  
- 레벨 디자이너는 플로어, 벽, 배럴, 박스 등 배치 및 라이트 맵핑, 라이트 프로브 작업 수행  
- 메인 개발자는 적, 플레이어 주인공 등 게임 로직 담당  
- 완성된 씬들을 하나로 병합하여 최종 게임 완성  

### 씬 분리 작업

- 메인 씬 백업 생성: 메인 씬을 복제하여 "메인 씬\_백업"으로 저장  
- 레벨 씬 생성: 메인 씬을 한 번 더 복제하여 "레벨"로 이름 변경  
- 메인 씬에서는 스테이지 관련 요소만 제거하고 게임 로직 요소(게임 매니저, 풀링 매니저 등) 유지  
- 레벨 씬에서는 스테이지만 남기고 플레이어, 카메라 등 모두 제거  
- 디렉셔널 라이트와 메인 카메라도 레벨 씬에서 삭제 

### 라이트 맵핑 재작업

- 레벨 씬에서 포인트 라이트 전체 활성화  
- Window > Rendering > Lighting 메뉴 접근   
- Generate Lighting 실행하여 라이트 맵핑 및 라이트 프로브 재생성  
- 기존 베이킹은 메인 씬에서 제거됨  

### 스타트 씬 생성

- 새로운 Start Scene 생성   
- Canvas 추가 후 "Start Scene UI"로 명명  
- Background 이미지 추가하여 검은색으로 설정 (R:0, G:0, B:0)   
- 타이틀 텍스트 추가: "Space Shooter", OpenSans Bold 폰트, 크기 60, 흰색, Y축 250 위치    
- Play 버튼 생성: SF Window 스프라이트 사용, 크기 200x60, 텍스트 크기 30    
- Quit 버튼 생성: Play 버튼 복제(Ctrl+D)하여 생성 후 하단 배치  

### UIManager 스크립트 구현

- 빈 오브젝트 생성 후 "UI Manager" 명명  
- UIManager 스크립트 작성  
- <code>using UnityEngine.SceneManagement</code> 네임스페이스 추가 필요 
- OnClickPlayBtn() 메서드: 씬 병합 로직 구현  
  - <code>SceneManager.LoadScene("Level")</code> - 레벨 씬 로드
  - <code>SceneManager.LoadScene("MainScene", LoadSceneMode.Additive)</code> - 메인 씬을 기존 씬에 추가로 병합 
- OnClickQuitBtn() 메서드: 게임 종료 로직  
  - <code>#if UNITY_EDITOR</code> 전처리기 지시자 사용  
  - 에디터: <code>UnityEditor.EditorApplication.isPlaying = false</code>
  - 빌드: <code>Application.Quit()</code> 

### 씬 로딩 모드

- <b>LoadSceneMode.Single</b>: 기존 씬 제거 후 새로운 씬 로드  
- <b>LoadSceneMode.Additive</b>: 기존 씬 유지하며 새 씬 추가 병합   

### 동기 vs 비동기 로딩

- <b>동기(Synchronous)</b>: A 작업이 완전히 끝나야 B 작업 시작 가능, 순서대로 진행   
  - <code>SceneManager.LoadScene()</code> - 씬이 완전히 로드될 때까지 게임이 멈춤
- <b>비동기(Asynchronous)</b>: A 작업과 관계없이 B 작업 동시 진행 가능  
  - <code>SceneManager.LoadSceneAsync()</code> - 씬 로드 중에도 다른 작업 수행 가능

### 빌드 설정

- File > Build Settings 메뉴 접근  
- 씬 순서 설정: 
  - Start Scene (Index 0)
  - Main Scene (Index 1)
  - Level Scene (Index 2)
- 빌드는 나중에 실행 가능 

### UI 버튼 이벤트 연결

- Play 버튼 선택 후 OnClick 이벤트에 UI Manager 오브젝트 드래그 
- UIManager.OnClickPlayBtn 함수 선택 
- Quit 버튼에도 동일하게 UIManager.OnClickQuitBtn 함수 연결 

### 네비게이션 베이킹

- 레벨 씬에서 바닥(Floor) 선택  
- Navigation 윈도우에서 Bake 실행  
- 박스 오브젝트도 Static 설정 후 재베이킹  

### 씬 전환 Fade In/Out 구현

- <b>목적</b>: 씬 크기가 크거나 다운로드할 데이터가 많을 경우 로딩 시간 동안 사용자 경험 개선  
- 네트워크/MMORPG 게임에서 서버 데이터 로드 시 특히 중요  
- 중간에 튜토리얼 이미지 표시 또는 검은 화면으로 암전 후 점진적으로 밝게 처리  
- 패치 대기 시간이 길면 사용자가 이탈할 수 있으므로 시각적 피드백 필수  

### Scene Loader 구현

- 새 씬 생성: "Scene Loader"   
- Canvas 추가 
- Fade In용 Image 추가: Stretch 설정으로 전체 화면 채우기, 검은색(0,0,0)   
- 빈 오브젝트 "Scene Loader" 생성 
- Scene Loader 스크립트 작성  
  - <code>using UnityEngine.SceneManagement</code> 추가 
  - <code>CanvasGroup fader</code> 변수: 알파값으로 페이드 제어   
  - <code>Dictionary&lt;string, LoadSceneMode&gt; loadScenes</code> 변수: 씬 이름과 로드 모드 저장   
  - <code>IEnumerator CoFadeLoad()</code> 코루틴: 페이드 효과와 씬 로딩 처리  
  - 초기 알파값 1로 설정 (완전 불투명) 

### 주요 개념 설명

- <b>전처리기 지시자</b>: 컴파일 전에 미리 처리되는 기능, 유니티 에디터에서만 작동하는 코드 작성 시 사용   
- <b>SceneManager.CreateScene()</b>: 새로운 씬을 런타임에 생성
- <b>Dictionary</b>: 리스트와 유사하지만 여러 자료형을 동시에 받을 수 있는 컬렉션  

### 테스트 및 검증

- Ctrl+S로 저장 후 플레이 모드 진입  
- Quit 버튼 클릭 시 정상 종료 확인 
- Play 버튼 클릭 시 레벨 씬과 메인 씬이 병합되어 로드되는지 확인  
- 하이어라키에서 Level 씬과 Main 씬 두 개가 동시에 존재하는지 확인 
- Play Focused 모드에서도 테스트 가능  

### 문제 해결

- 적 캐릭터가 제대로 움직이지 않는 경우: 네비게이션 베이킹 누락  
- 바닥 재베이킹 및 박스 Static 설정 후 재베이킹 필요

### 씬 매니저 및 딕셔너리 구조

- Scene Manager의 LoadScene 함수 사용법 설명  
  - 첫 번째 파라미터: string sceneName (씬 이름)
  - 두 번째 파라미터: LoadSceneMode (로드 씬 모드)
- LoadScenes 딕셔너리 자료형 도입 
  - 여러 개의 자료를 동시에 받을 수 있는 멀티 리스트 구조
  - Key-Value 쌍으로 구성: Key는 씬 이름, Value는 씬 모드 

### 코루틴을 통한 씬 로딩 구현

- yield return 구문 사용  
- IEnumerator LoadScene 함수 생성 (string sceneName, LoadSceneMode loadSceneMode 파라미터) 
- StartCoroutine으로 LoadScene 호출 
- 여러 개의 씬을 foreach 루프로 처리 
  - 딕셔너리의 Key에는 씬 이름, Value에는 씬 모드 저장
  - StartCoroutine 통해 각 씬 순차적으로 로드

### 비동기 씬 로딩 (Async Scene Loading)

- 동기 방식 vs 비동기 방식 차이점 설명 
  - 동기적 방식: A가 끝나야 B를 시작할 수 있음
  - 비동기 방식: A와 상관없이 B가 독립적으로 실행 가능
- SceneManager.LoadSceneAsync 사용  
- SceneManager.UnloadSceneAsync로 씬 삭제   

### 페이드 인/아웃 효과 구현

- Fade In/Out 개념: 어두운 화면에서 점점 밝아지거나 흐릿한 화면에서 선명해지는 효과 
- 구현 요소  
  - Fade CG: 이미지 컴포넌트
  - BlockRaycast: 이벤트 수신 여부 제어
  - Fade Speed: 페이드 속도 조절 변수 
- 알파값 조정 로직  
  - Mathf.Abs를 사용한 절대값 계산 (양수만 처리)   
  - FadeDuration (지속 시간) 설정 
  - StartCoroutine으로 페이드 효과 실행 

### 알파값 보간 처리

- Mathf.MoveTowards 함수 사용 (색상 보간 함수) 
  - 현재 알파값에서 최종 알파값으로 점진적 변경

- Mathf.Approximately로 알파값 비교  
  - 현재 알파값과 최종 알파값이 같은지 체크
  - 같지 않으면 계속 알파값 조정  
- yield return null로 다음 프레임까지 대기

이때 다음 화면으로 넘어가지 않고 그냥 멈춰 있다는 느낌을 받을 수 있기에 중간에 게임의 튜토리얼 이미지를 넣거나 검은색으로 암전 시켰다가 화면이 로드 되면 다시 밝게 처리한다.

<details markdown="1">
<summary>씬 로더 스크립트</summary>

```cs
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.SceneManagement; //씬 관리 기능을 사용하기 위한 네임스페이스
public class SceneLoader : MonoBehaviour
{
    public CanvasGroup fadeCG; //씬 전환 시 페이드 효과를 위한 CanvasGroup 컴포넌트
    // Fade In, Fade Out 효과를 구현하기 위해 CanvasGroup 컴포넌트를 참조하는 변수, CanvasGroup는 UI 요소의 투명도와 상호작용을 제어하는 데 사용
    [Range(0.5f, 2f)] public float fadeDuration = 1f; //페이드 효과의 지속 시간, Range 어트리뷰트를 사용하여 인스펙터에서 조절 가능하도록 설정

    public Dictionary<string, LoadSceneMode> loadScenes = new Dictionary<string, LoadSceneMode>(); //씬 이름과 로드 모드를 저장하는 딕셔너리
    // Dictionary<>는 키와 값의 쌍으로 데이터를 저장하는 자료구조, 여기서는 씬 이름을 키로 하고 로드 모드를 값으로 저장
    
    public void InitSceneInfo() //호출 할 씬의 정보 설정
    {
        //호출 할 씬의 정보를 딕셔너리에 추가하는 코드, 씬 이름과 로드 모드를 지정하여 딕셔너리에 저장
        loadScenes.Add("Level", LoadSceneMode.Additive); // "Level"이라는 이름의 씬을 Additive 모드로 로드하도록 딕셔너리에 추가
        loadScenes.Add("MainScene", LoadSceneMode.Additive); // "MainScene"이라는 이름의 씬을 Additive 모드로 로드하도록 딕셔너리에 추가
    }
    private IEnumerator Start()
    {
        InitSceneInfo(); // 씬 정보 초기화
        fadeCG.alpha = 1f; // 초기 알파값 설정
        foreach (var _loadScene in loadScenes)
        {

            yield return StartCoroutine(LoadScene(_loadScene.Key,_loadScene.Value)); //씬 로드
            //여러개의 씬을 코루틴으로 호출
        }
        StartCoroutine(FadeIn(0.0f)); // FadeIn 함수 호출
    }
    IEnumerator LoadScene(string sceneName,LoadSceneMode mode)
    { 
        yield return SceneManager.LoadSceneAsync(sceneName, mode); //씬 로드 시작
        //비동기 방식으로 씬을 로드하고, 로드가 완료 할 때 까지 대기

    IEnumerator FadeIn(float finalAlpha) //Fade In and Out 효과를 적용 하는 함수
    {
        //라이트 맵이 깨지는 것을 방지 하기 위해 스테이지 씬을 활성화
        SceneManager.SetActiveScene(SceneManager.GetSceneByName("Level")); //씬 활성화
        fadeCG.blocksRaycasts = true; // 블락 레이캐스트 활성화

        float fadeSpeed = Mathf.Abs(fadeCG.alpha - finalAlpha) / fadeDuration; //페이드 속도 계산
        while (!Mathf.Approximately(fadeCG.alpha, finalAlpha)) // 현재 알파 값이 최종 알파값과 거의 같은지 체크
             // 현재 알파 갑과 최종 알파값이 같지 않다면
        {
            fadeCG.alpha = Mathf.MoveTowards(fadeCG.alpha, finalAlpha, fadeSpeed * Time.deltaTime);
            //알파값을 최종 알파값으로 이동
            // MoveTowards : 색상이나 벡터값을 점진적으로 변경하는 함수
            yield return null; //다음 프레임 까지 대기
        }
```
