## 목표와 문제

첫 전투에서 정신집중으로 에너지를 모은 뒤 스킬을 사용하는 대기가 길었습니다. 청사진과 별개인 착용 장비 슬롯 및 자원 없는 기본 공격을 구현해 전투를 이어갈 수 있게 했습니다.

## 구현한 내용

- 직접 착용 무기 슬롯 1개와 고유 시험 무기 ‘대원의 훈련검’ 보유 상태를 추가했습니다.
- 동굴 안쪽의 쓰러진 대원을 G로 조사하고 기록 창에서 무기를 챙긴 뒤 Tab → 장비 → 무기 장착으로 사용합니다. 획득 즉시 자동 장착하지 않습니다.
- Tab에 청사진/장비 탭을 분리했습니다. 청사진은 기존 편집·전개, 장비는 장착·해제를 담당합니다.
- 장비 탭에서는 전개 격자·미리보기를 닫고 이동·집중·스킬·상호작용을 차단합니다. Tab 닫기는 유지합니다.
- 평상시 좌클릭은 커서 방향 기본 공격, 청사진 전개 중 좌클릭은 설치, UI 위 클릭은 UI 조작으로 구분했습니다.
- 기본 공격은 코어 자원을 쓰지 않으며 코어 파괴 후에도 가능합니다. 벽 차폐와 중복 콜라이더 타격을 검사합니다.
- 시험 수치: 피해 15, 공격 간격 0.65초, 사거리 2m, 전방 100도. 최종 밸런스가 아닙니다.
- 빗자루 스킬과 기본 공격의 중복 실행을 제한하고 스킬 실행 중 기본 검 표현을 숨깁니다.
- 튜토리얼 목표 문구에 무기 획득·장착과 기본 공격 안내를 연결했습니다.
- 종합 기획서에 구현 규칙·범위·검증 결과를 반영했습니다.

## 구현 구조

- PrototypeEquipment: 무기 보유·착용 및 시험 수치.
- PrototypeWeaponPickup: 공용 G 상호작용 획득.
- PrototypeBasicAttack: 자원 풀과 독립된 피해·사거리·각도·간격·벽 판정.
- PrototypeEquipmentPresenter: Canvas 탭·장비 UI, 화면 포인터 투영, 임시 무기 표현.
- 기존 입력·전개 모드·스킬·튜토리얼 진행기: 탭 상태와 입력 충돌 방지 연결.

## 검증

- Gameplay·Presentation·TutorialDokkaebi 컴파일 통과.
- 별도 Unity 자동 시험 17항목 통과, EQUIPMENT\_SMOKE\_SUCCESS 확인.
- 미장착 공격 거부, 획득 중복 방지, 자동 장착 없음, 장비 탭 차단과 Tab 닫기, 피해 15 단일 적용, 자원 미소모, 간격 제한, 장비/전개 화면 공격 차단, 장착 해제, 벽 차폐, 코어 파괴 후 기본 공격을 확인했습니다.
- 코드 호출 기반 시험이므로 실제 키보드·마우스 조작, HUD 겹침, 해상도별 가독성은 수동 검증이 필요합니다.
- 검증용 에디터 검색 인덱서 예외는 별도 발생했지만 진행 시험은 성공 종료했습니다.
- 구현 당시 문서 링크 검사 92개 오류 0건, MkDocs 엄격 빌드 통과.

## 제한과 미구현

무기와 획득물은 런타임 생성 임시 메시이고 모션도 임시 표현입니다. 대원 시체, 정식 모델·애니메이션·SFX, 방어구, 다종 무기 교체, 여분 장비의 청사진 수납, 저장/로드는 구현하지 않았습니다. 현재 해제한 훈련검은 고유 무기 보유 상태로 돌아오며 일반 무제한 보관함을 뜻하지 않습니다.
