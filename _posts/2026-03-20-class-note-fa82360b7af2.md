<b>Convai Unity 플러그인 및 GitHub Copilot 수업</b> 2026-03-20


## 요약


### 주요 내용

- <b>Convai Unity 플러그인 소개</b>: 기존 방식에서 WebRTC 기반으로 완전히 재설계된 새로운 플러그인 소개
- AI가 자동으로 입모양, 헤어, 스킨 등을 조정하여 개발자가 수동으로 작업할 필요가 없어짐
- 실시간 상호작용, 초저지연 대화, 핸드프리 대화 기능 지원
- VR 프로젝트 시 해당 플러그인을 활용할 예정

### Convai 로그인 문제 해결

- 다수의 학생들이 Convai 사이트 로그인에 어려움을 겪음
- 브라우저 문제가 99%의 원인으로 파악됨
- 해결 방법:
  - 시크릿 모드(Incognito)로 접속하여 확장 프로그램 충돌 확인
  - 캐시 및 쿠키 삭제 (최근 24시간 동안의 데이터)
  - 인증 방식 확인 (소셜 로그인 vs 이메일)
  - 이메일 인증 확인

### 시스템 요구사항

- Unity 6.0 이상 필요
- URP 설정 필요
- XR 툴킷 설치 필요 (VR용)
- 현재 프로젝트 진행 중이므로 VR 과정 때 본격적으로 진행 예정

### GitHub Copilot 실습

- Visual Studio 2022에서 GitHub Copilot 설정 방법 안내
- 탱크 게임에 GitHub Copilot을 활용하여 레이캐스트 방식의 발사 시스템 구현
- LineRenderer를 이용한 레이저 빔 시각화 작업
- 코드 맥락을 읽어 큐(Queue) 방식의 오브젝트 풀링 구현
- 이펙트 매니저 생성 및 폭발 이펙트 적용

### GitHub Copilot 사용 시 주의사항

- Copilot이 완벽한 코드를 생성하는 것은 아니며, 검수가 필수적임
- 어느 정도 구조를 이해한 후 사용해야 효과적임
- 불필요한 기능이 포함되거나 잘못된 부분이 있을 수 있음
- 개발자는 코드를 검수하고 수정하는 역할을 해야 함
- 대규모 프로젝트에서는 List 대신 Queue(FIFO) 방식을 사용해야 함

### 다음 단계

- Copilot으로 생성한 코드를 삭제하고 최적화된 코드로 다시 작성 예정
- 현재 생성된 코드는 중급 수준이며, 더 최적화 가능함
- 2차 프로젝트 진행 예정

## 수업 내용 정리(요약)

### 1) Convai Unity 플러그인 핵심

- 기존 방식에서 <b>WebRTC 기반으로 재설계된 신규 플러그인</b> 소개
- AI가 자동으로 <b>입모양/헤어/스킨 등 표현을 보정</b>해 개발자 수동 작업을 줄여줌
- <b>실시간 상호작용, 초저지연 대화, 핸즈프리 대화</b> 지원
- 향후 <b>VR 프로젝트에서 활용 예정</b> (Unity 6 / URP / XR Toolkit 요구)

### 2) Convai 로그인 트러블슈팅(실전용)

- 원인: 브라우저/확장 프로그램 영향 가능성이 큼
- 해결 순서: 시크릿 모드 → 캐시/쿠키 삭제 → 로그인 방식 확인 → 이메일 인증 확인

### 3) GitHub Copilot 실습 정리(무엇을 만들었나)

- Visual Studio 2022에서 Copilot 설정/사용 흐름 학습
- 탱크 게임 예제로 구현/보강한 요소
  - 레이캐스트 기반 발사 시스템
  - LineRenderer로 레이저(빔) 시각화
  - Queue(FIFO) 기반 오브젝트 풀링(맥락 기반 코드 생성 사례)
  - 이펙트 매니저 + 폭발 이펙트 적용
